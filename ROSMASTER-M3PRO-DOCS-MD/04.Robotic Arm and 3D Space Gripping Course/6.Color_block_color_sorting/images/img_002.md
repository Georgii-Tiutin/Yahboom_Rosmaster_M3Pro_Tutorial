## Description
Screenshot of an OpenCV window titled "frame" showing a top-down camera view of the robot's gripper (bottom) and four colored blocks on a light wood surface: red (top left), yellow (top right), blue (lower left), green (lower right). In the top-left, blue text reads "blue" with green text "OK !!!" below it. At the top center, blue text reads "lowerb : (55 ,129 ,186)" and "upperb : (125 ,253 ,255)". These are the HSV lower and upper bounds for blue. On the blue block, a green rectangle with a blue diagonal line marks the region selected by mouse drag, and the mouse cursor is at its bottom-right corner. This step is part of the color block sorting tutorial: the user selects a color region with the mouse to calibrate the HSV range for that color.
