## Caption
Diagram illustrating Docker's architecture showing the relationship between containers, images, volumes, and the host Linux system.

## Description
This diagram depicts the core Docker architecture with three layers:

1. **Top layer - Containers**: Three containers are shown side by side, each containing a '目录 (target)' (directory/target) block. The containers are connected to images below via 'run' arrows, indicating that containers are running instances of images.

2. **Middle layer - Images and Volumes**: Multiple 'image' blocks (shown in orange/red) sit between the containers and the host system. On the left side, a '数据卷 (volume)' (data volume) element is shown with 'mounts' arrows connecting it to the containers above. On the right side, another 'mounts (挂载)' connection links to a source directory.

3. **Bottom layer - Linux Host**: A dashed blue rectangle represents the 'Linux (宿主机)' (Linux host machine), containing two '目录 (Source)' (directory/source) blocks that serve as mount points for the volumes and bind mounts.

The diagram illustrates how Docker containers run from images, how data volumes provide persistent storage mapped from the host filesystem, and how bind mounts connect host directories directly to container target directories. This is a foundational concept diagram for understanding Docker's storage and execution model.
