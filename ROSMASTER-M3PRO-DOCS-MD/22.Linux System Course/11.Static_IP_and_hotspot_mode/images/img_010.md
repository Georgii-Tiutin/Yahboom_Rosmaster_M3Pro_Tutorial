## Description
This screenshot shows the 'Editing Wi-Fi connection 1' dialog window in Ubuntu's Network Manager GUI. The dialog has multiple tabs: General, Wi-Fi, Wi-Fi Security, Proxy, IPv4 Settings, and IPv6 Settings. The IPv6 Settings tab is currently selected (highlighted with a red box labeled '1'). The Method dropdown is set to 'Ignore' (highlighted with a red box labeled '2'), indicating that IPv6 will be disabled for this connection. Below are empty fields for Address/Prefix/Gateway, DNS servers, Search domains, IPv6 privacy extensions (set to Disabled), and IPv6 address generation mode (set to Stable privacy). A checkbox option 'Require IPv6 addressing for this connection to complete' is unchecked. The Save button in the bottom-right corner is highlighted with a red box labeled '3', indicating the user should save the settings. This is part of a static IP configuration tutorial where IPv6 is being disabled to simplify network setup on the robot platform.
