## Caption
WinSCP file transfer session connected to a Jetson board at 192.168.2.93, showing local Windows desktop files on the left and the remote /home/jetson/ directory on the right.

## Description
The image shows the WinSCP application window used for remote file transfer via SFTP. The title bar reads 'jetson - jetson@192.168.2.93 - WinSCP'. The interface is split into two panes:

- Left pane: Local Windows filesystem (C:\Users\Administrator\Desktop) listing various shortcut files (.lnk) and executables such as 研发部 (yahboom...), 360安全卫士.lnk, Beyond Compare, Delta-3A.exe.lnk, DiskGenius.exe.lnk, FlyMcu.exe.lnk, Google Chrome.lnk, Keil uVision5.LNK, putty.exe.lnk, rpi-imager.exe.lnk, SDFormatter.exe.lnk, and others.

- Right pane: Remote Jetson board filesystem (/home/jetson/) showing typical Linux home directories including Desktop, Documents, Downloads, Music, Pictures, Public, Rosmaster, software, Templates, Videos, yahboomcar_ws, and an examples.desktop file. File permissions (rwxr-xr-x) and timestamps are visible.

The status bar at the bottom shows an active SFTP-3 connection. This screenshot demonstrates how to use WinSCP to remotely connect to the Jetson development board for transferring files between a Windows PC and the robot's onboard computer, which is a common workflow when developing and deploying ROS2 packages to the ROSMASTER M3 Pro platform.
