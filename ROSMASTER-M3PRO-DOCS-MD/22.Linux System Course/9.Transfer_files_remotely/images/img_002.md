WinSCP login dialog showing SFTP connection settings for remote file transfer to the robot.

## Description
The image shows the WinSCP application open on Windows with its Login dialog displayed. The dialog contains a 'New Site' entry in the left panel and a 'Session' configuration form on the right. The form fields include: File protocol (set to SFTP), Host name, Port number (default 22), User name, and Password. The bottom of the dialog has Tools, Manage, Login, Close, and Help buttons. This screenshot demonstrates the initial setup step for establishing an SFTP connection to the robot's onboard computer (such as Jetson or Raspberry Pi) to transfer files remotely, which is a common task when working with ROS2 robotics platforms.
