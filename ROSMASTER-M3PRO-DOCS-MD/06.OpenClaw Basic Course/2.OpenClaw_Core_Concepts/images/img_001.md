## Description
Dark-themed grid of 4 columns by 4 rows (last row has 3 cards) showing messaging channel integrations, each card with an icon, title, and gray subtitle. Row 1: WhatsApp – "QR pairing via Baileys"; Telegram – "Bot API via grammY"; Discord – "Servers, channels & DMs"; Slack – "Workspace apps via Bolt". Row 2: Signal – "Privacy-focused via signal-cli"; iMessage (Apple logo) – "iMessage via imsg (AppleScript bridge)"; iMessage (chat bubble icon) – "iMessage via BlueBubbles server"; Microsoft Teams – "Enterprise support". Row 3: Nextcloud Talk – "Self-hosted Nextcloud chat"; Matrix – "Matrix protocol"; Nostr – "Decentralized DMs via NIP-04"; Tlon Messenger – "P2P ownership-first chat". Row 4: Zalo – "Zalo Bot API"; Zalo Personal – "Personal account via QR login"; WebChat – "Browser-based UI". The bottom-right slot is empty. It illustrates the messaging channels the Open Claw assistant can connect to.
