Dark-themed code editor view of a JSON configuration (OpenClaw). Visible structure:

  "defaults": {
    "model": {

      "bailian/qwen3.5-plus": {},
      "bailian/qwen3.6-plus": {},

A red rectangle highlights the "models" block (from "models": { through the last entry "bailian/kimi-k2.5": {}). This shows the list of available models that can be switched to; the "primary" value under "model" sets the currently active default model (bailian/qwen3.6-plus). In the tutorial on switching models, the user edits the primary model or adds/removes entries in this models list.
