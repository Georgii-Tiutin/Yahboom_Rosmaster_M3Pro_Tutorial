## Description
Left-to-right flow diagram on a light beige background with rectangular boxes and arrows. On the left, a box labeled "Chat apps + plugins" has an arrow pointing to a center box labeled "Gateway". From the Gateway, five arrows go to boxes in a right-hand column, from top to bottom: "OpenClaw agent" (curved arrow), "CLI" (curved arrow), "Web Control UI" (straight horizontal arrow), "macOS app" (curved arrow), and "iOS and Android nodes" (curved arrow). The diagram shows the Gateway as the central hub connecting chat channels and plugins to the agent, command-line interface, web UI, desktop app and mobile nodes. It comes from the "Introduction to Open Claw" tutorial, page 2.
