## Description
Screenshot of a workflow Studio app named "multi_brains_en" (top bar: Explore, Studio, Knowledge, Tools, Plugins, Preview, Features, Publish; hint "Scroll to selected node"). The canvas shows nodes: START/INPUT (variable {x} robot_feedback) -> FEEDBACK JUDGMENT (IF: in... / ... / {x} robot_fee... is True; OR: ... / {x} files is not empty; ELSE) -> TASK ROUTING (model qwen-max-latest, CHAT) with three outputs: CLASS 1 "Complex Tasks 1. Tasks that need ...", CLASS 2 "Simple actions or single actions; t...", CLASS 3 "Personal Intent Includes the user'...". Below is INTENT MAPPING (file "Intent mapping.xls..."). The Task Routing node is highlighted with a red rectangle. The right panel "Task Routing" (tabs SETTINGS, LAST RUN) lists class definitions. Class 1 (partially visible): 1. Tasks that need to be broken down into multiple simple steps for execution; 2. Tasks involving logical judgment; 3. Long-process tasks; 4. Object tracking. Examples: 1. Go to XX and find XX for me; 2. Track the XX in front of you. CLASS 2 (200 chars): Simple actions or single actions; the task does not require multiple steps to complete, only a single step. No robot action is required, only conversational responses. Self-introduction, chat and Q&A. CLASS 3 (56 chars, highlighted with red box): "Personal Intent. Includes the user's personal intentions." Below are "+ Add Class", ADVANCED SETTING, OUTPUT VARIABLES, NEXT STEP. Bottom-left: "View cached variables", "Clear"; zoom 115%. It illustrates how to configure the task routing classification node, especially adding the Class 3 personal intent category, in the intention estimation tutorial.
