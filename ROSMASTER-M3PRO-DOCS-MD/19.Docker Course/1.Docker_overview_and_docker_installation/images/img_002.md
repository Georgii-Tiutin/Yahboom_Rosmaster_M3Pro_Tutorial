## Caption
Comparison diagram showing the architectural differences between traditional virtual machines (VMware, Parallels) and Docker container technology.

## Description
The image presents a side-by-side architectural comparison between virtual machine platforms and Docker containers. On the left side, it shows the VM architecture with VMware and Parallels as examples, where multiple virtual machines each contain their own applications, libraries, and full guest operating system (VM OS), all running on top of a Hypervisor (虚拟机监控程序) layer and the host operating system and hardware infrastructure. On the right side, it shows the Docker architecture, where multiple containers each contain applications and libraries but share the host OS kernel through the Docker Engine layer, eliminating the need for separate guest operating systems. The diagram uses colored blocks (pink/red for applications, green for libraries/dependencies, blue for OS layers) to visually distinguish the layers. Chinese text labels identify each component. This diagram illustrates why Docker containers are more lightweight and efficient than traditional VMs — a foundational concept in the Docker overview tutorial.
