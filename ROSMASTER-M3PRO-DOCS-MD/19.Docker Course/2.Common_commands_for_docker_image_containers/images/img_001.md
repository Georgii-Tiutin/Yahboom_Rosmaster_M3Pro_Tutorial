## Caption
Docker lifecycle diagram showing the relationships between images, containers, and their state transitions with associated commands.

## Description
The diagram illustrates the complete Docker workflow and container lifecycle. On the left side, it shows Docker Images with associated commands (images, rmi, tag, history). Images can be created via 'build' from a Dockerfile, 'load'/'save'/'import' from Tar files, or 'pull'/'push' from a Registry (with search, login, logout commands). In the center, the container lifecycle is depicted with three main states represented as colored circles: Running (green), Stop (red/orange), and Pause (yellow). Arrows show state transitions: 'create'/'run' to start containers, 'start' to resume stopped containers, 'kill'/'stop' to halt running containers, 'pause'/'unpause' between running and paused states, and 'rm' to remove containers. The Running state has associated commands: wait, logs, inspect, attach, port, cp, top, and exec. A Host box shows file/folder exchange with the container via 'cp'. The bottom-right corner shows Engine-level commands: version, info, events. The diagram uses a dark blue background with color-coded elements to organize the Docker ecosystem visually.
