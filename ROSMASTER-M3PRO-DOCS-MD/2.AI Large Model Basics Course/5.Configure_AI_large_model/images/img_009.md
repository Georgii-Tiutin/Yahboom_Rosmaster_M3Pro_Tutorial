Baidu AI speech synthesis (TTS) API online debugging interface showing configuration parameters for text-to-speech conversion.

## Description
The image shows a screenshot of the Baidu AI Open Platform's online debugging/testing interface for the Short Text Online Speech Synthesis API. The left panel contains the API configuration fields including:
- Header section with Content-Type set to 'application/x-www-form-urlencoded'
- Body section with parameters such as 'tex' (input text), 'tok' (token), 'cuid' (client ID), 'ctp', 'lan' (language), and 'spd' (speed), 'pit' (pitch), 'vol' (volume) sliders
- Audio format selection showing options: mp3, pcm-16k, pcm-8k, wav
- A 'per' parameter for voice selection and 'aue' for audio encoding

The right panel displays a grid of available voice options (speakers) with Chinese names, including various male and female voices categorized as standard and premium (精品) voices. This page is used in the tutorial to demonstrate how to configure and test the Baidu TTS API, which is part of setting up AI large model capabilities on the ROSMASTER M3 Pro robot platform.
