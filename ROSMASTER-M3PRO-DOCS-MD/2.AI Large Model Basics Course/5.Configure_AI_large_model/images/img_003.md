## Description
The image shows a modal dialog from the Alibaba Cloud Bailian (阿里云百炼) large model platform. The header states that to continue using the Bailian large model service, the user needs to activate the listed products and create a model API-KEY.

Key elements include:
- A notice explaining that usage is billed per token, with a promotional offer of 1,000,000 free tokens per new model activation.
- Three tab-like categories at the top: '阿里云百炼大模型推理 (303)', '阿里云百炼大模型部署 (303)', and '阿里云百炼大模型训练 (303)'.
- A scrollable list of available AI models with their internal identifiers, including:
  - 通义千问-Plus (qwen-plus) variants (2024-07-23 and 2024-08-06)
  - 人物实例分割 (image-instance-segmentation)
  - 图像擦除补全 (image-erase-completion)
  - FLUX-merged (flux-merged)
  - Dolly2-开源版-12B (dolly-12b-v2)
  - Paraformer语音识别-v2 (paraformer-v2)
  - Paraformer实时语音识别-v2 (paraformer-realtime-v2)
  - StableDiffusion文生图模型-3.5-large variants
- Bottom buttons: a checkbox to agree to terms, '计费详情' (billing details), '取消开通' (cancel), and a blue '确认开通，并领取免费额度' (confirm activation and claim free quota) button.

This screenshot is from the tutorial's step guiding users through activating the Alibaba Cloud Bailian API service, which is required for the robot's AI large model features.
