## Caption
Dify knowledge base chunk settings and indexing configuration for the AI large model RAG system.

## Description
The screenshot shows the Dify platform's Knowledge datasource configuration page within yahboom's workspace. The page is divided into several sections:

1. **Chunk Settings** - Set to 'General' mode for general text chunking, where retrieved and recalled chunks are the same. Configuration includes: Delimiter (\n\n), Maximum chunk length (1024 characters), and Chunk overlap (50 characters).

2. **Text Pre-processing Rules** - Two options are shown: 'Replace consecutive spaces, newlines and tabs' (enabled) and 'Delete all URLs and email addresses' (not enabled). There is also an option to 'Chunk using Q&A format in English'.

3. **Parent-child** - An alternative chunking mode where child-chunks are used for retrieval and parent-chunks are used for recall/context.

4. **Index Method** - Two options shown: 'High Quality' (highlighted with a red box, using an embedding model to process documents for more precise retrieval) and 'Economical' (using keyword-based retrieval). A note indicates that if embedding is unavailable in High Quality mode, it reverts to Economical mode.

5. **Embedding Model** - Set to 'text-embedding-v1'.

6. **Retrieval Setting** - Shows 'Vector Search' selected (using embedding and search for the best chunk match similar to vector representations), with a 'Rerank Model' option and a 'git search' option below.

This page is part of the tutorial on configuring a RAG (Retrieval-Augmented Generation) knowledge base in Dify for the robot's AI large model capabilities.
