Screenshot of the OpenRouter web interface (openrouter.ai) showing the Models browsing page. The left sidebar contains filter options for Input Modalities (Text, Image, File), Context length (with a range slider), and Prompt pricing (with a range slider and Reset button). The main content area displays a list of 60 available models with a search/filter bar at the top. Two free models are visible: 'Venice: Uncensored (free)' with 12.5M tokens capacity, described as a fine-tuned variant of Mistral-Small-24B-Instruct-2501 by Eric Hartford and Venice.ai (33K context, $0/M input and output tokens); and 'Google: Gemma 3n 2B (free)' with 3.8M tokens, described as a multimodal instruction-tuned model by Google DeepMind (8K context, $0/M input and output tokens). This screenshot is from a tutorial guiding users through selecting an AI model on OpenRouter for configuring AI large model integration with the robot platform.
