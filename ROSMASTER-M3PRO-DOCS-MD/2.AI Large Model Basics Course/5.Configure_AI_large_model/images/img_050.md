## Description
Screenshot of the Dify AI platform's Knowledge Base creation workflow (Step 1: Data Source). The interface is accessed under yahboom's Workspace and shows the top navigation bar with Explore, Studio, Knowledge, and Tools tabs. The 'Knowledge' section is active. Three data source options are displayed: 'Import from file' (highlighted with a red rectangle), 'Sync from Notion', and 'Sync from website'. Below, an 'Upload file' area shows a drag-and-drop zone with a 'Browse' button (also highlighted with a red rectangle). Supported file formats are listed: TXT, MARKDOWN, MDX, PDF, HTML, XLSX, XLS, DOCX, CSV, VTT, PROPERTIES, MD, HTM, with a max size of 15MB each. This step is part of configuring a RAG (Retrieval-Augmented Generation) knowledge base for the AI large model on the Yahboom ROSMASTER robot platform.
