## Caption
Architecture diagram of SenseVoice speech AI model showing both the Small and Large variants with their processing pipelines.

## Description
The image presents two architecture diagrams stacked vertically for the SenseVoice AI speech model.

The top section shows 'SenseVoice Small' which processes audio input (LID, ASR, AED, SER, ITN) through a Task Embedder and Speech Encoder, feeding into a SAN-M Encoder and then a CTC module. The output produces multiple result types on the right side: Languages (zh, en, ja, etc.), Emotions (happy, disgusted, angry, fearful), and Events (sing, noise, bgm, applause), along with text transcription.

The bottom section shows 'SenseVoice Large' which takes Speech input through a Feature Extractor, then into a SAN-M Encoder, followed by a Transformer Decoder with auto-regressive format. It uses Start Prompts with task tags (LID, ASR, AED, ASR) and language/special tokens.

Both architectures share colored token blocks representing different task identifiers. The diagram illustrates how SenseVoice handles multiple speech understanding tasks simultaneously including automatic speech recognition, language identification, emotion detection, and audio event detection. This is presented in the context of configuring AI large models for the Yahboom ROSMASTER M3 Pro robot platform's voice interaction capabilities.
