## Caption
Flowchart showing the decision logic after a robot action execution, branching on success or failure to handle voice requests, feedback, and task completion.

## Description
This flowchart depicts the post-action decision process in the embodied intelligence system. It starts with a diamond decision node asking 'Was Action Successful?' (动作执行是否成功?). On the 'No' branch (right side): it publishes feedback info (发布反馈信息), stops the robot (停止机器人), resets the combo mode flag (重置组合模式标志位), then publishes completion info (发布执行完成信息). This path can lead to either publishing error info and aborting the task (发布错误信息,中止任务) or returning success info (返回成功信息). On the 'Yes' branch (left side): it sends a voice request (发送语音请求), then returns success info (返回成功信息). Both branches converge at the 'End' (结束) node at the bottom. The flowchart uses standard symbols: rectangles for processes, a diamond for the decision, and a rounded rectangle for the end node. All labels are bilingual (Chinese and English).
