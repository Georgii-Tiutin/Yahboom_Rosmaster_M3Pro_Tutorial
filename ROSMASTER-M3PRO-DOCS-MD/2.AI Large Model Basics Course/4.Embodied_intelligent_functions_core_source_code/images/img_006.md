## Caption
Flowchart depicting the embodied AI instruction processing pipeline, from audio synthesis and playback through TTS callbacks to dual/single model inference and action execution.

## Description
This is a detailed flowchart diagram showing the core processing loop of the embodied intelligent system. The flow moves generally left to right and includes several key stages:

1. **Synthesize & Play Audio** (left section): Begins with checking if an audio reply message is initialized, then determines whether an audio file exists. If yes, it plays the audio file; if no, it proceeds to a TTS (Text-to-Speech) callback path.

2. **TTS Processing** (center-left): A TTS callback checks if TTS was successful. If successful, TTS audio is played. After playback, the system sends feedback to the executor and starts a new instruction cycle.

3. **Model Inference** (center-right): A decision diamond checks the message type, branching into whether 'Dual Model Mode' is enabled. If yes, it routes to 'Dual Model Inference'; if no, it routes to 'Single Model Inference'.

4. **Action Execution** (right section): After inference, the system extracts action and reply information, then sends the action to a server and constructs a response message.

The diagram uses purple/lavender diamond shapes for decision points, rounded rectangles for process steps, and directional arrows showing the control flow. Labels are in both Chinese and English. This flowchart represents the core source code logic for the robot's embodied AI interaction system, showing how voice commands are processed, inferred upon, and acted out by the robot.
