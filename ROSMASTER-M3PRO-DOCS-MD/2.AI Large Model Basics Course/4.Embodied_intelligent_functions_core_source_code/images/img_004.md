Flowchart showing the voice interaction processing pipeline for an embodied AI robot, covering VAD recording, ASR speech recognition, and ROS2 message publishing.

## Description
This is a flowchart diagram depicting the core voice interaction loop of the embodied intelligent system. The flow begins at the top-left with three parallel initialization steps: 'Send Initial Response' (发送初始响应), 'Sleep 0.1s' (休眠0.1秒), and 'Shutdown ROS2' (关闭ROS2), with the rightmost path leading to 'End' (结束). The main processing path flows downward: 'Start VAD & Recording' (开始VAD和录音) captures user audio, then 'Perform ASR' (进行ASR识别) converts speech to text. A diamond decision node 'Is ASR Result Valid?' (ASR结果是否有效) branches into two paths: if valid (是), the system publishes the ASR result (发布ASR结果) via ROS2; if invalid (否/No), it publishes an error response (发布错误响应). Both paths converge at 'Wait for User Speech' (等待用户说话), which loops back to continue listening. The diagram uses standard flowchart symbols with Chinese labels and English translations, illustrating the continuous speech recognition and response cycle within the ROS2 framework.
