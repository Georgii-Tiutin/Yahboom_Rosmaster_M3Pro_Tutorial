## Caption
Flowchart showing the action list processing logic for the embodied intelligent robot node, from initialization through parsing and executing single or combo actions.

## Description
This is a vertical flowchart depicting the core control flow of the robot's embodied intelligence action execution system. It begins with 'Start' at the top, flows to 'Initialize Node', then 'Wait for Action List Request'. A diamond decision block checks 'Is the Action List Empty?' — if Yes, it loops back to waiting. If No, another diamond checks 'Is Action List Length 1?'. If Yes (single action), it sends a voice request, then parses and executes the single action. If No (multiple actions), it sends a voice request, enables Combo Mode, then parses and executes each action in order. Both paths loop back to the waiting state. All labels are bilingual (Chinese with English translations). The flowchart uses standard shapes: rounded rectangles for start/process steps, diamonds for decisions, and directional arrows for flow.
