## Caption
Architecture flowchart showing the core source code modules and data flow for the embodied intelligent voice/text interaction system on the ROSMASTER M3 Pro robot.

## Description
The diagram is a system architecture flowchart illustrating how the embodied AI interaction pipeline is structured across multiple Python modules and configuration files. On the left side, mic_serial.py (Microphone driver) feeds into asr.py (Voice interaction function), which connects to a 'Choose one input method' decision point alongside text_chat.py (Text interaction function). User instructions are sent to model_service.py (Model server functionality) at the center. model_service.py calls large_model_interface.py (Model interface) which interfaces with promote.py (Execution layer model / role instructions). Configuration is handled by large_model_interface.yaml and yahboom.yaml for node parameters. model_service.py sends action requests to action_service.py (Action server functionality) on the right, which outputs control parameters to a Robot Entity. action_service.py also loads map configuration via map_mapping.yaml for navigation. Arrows indicate the data flow direction between components, showing the full pipeline from voice/text input through LLM processing to robot action execution.
