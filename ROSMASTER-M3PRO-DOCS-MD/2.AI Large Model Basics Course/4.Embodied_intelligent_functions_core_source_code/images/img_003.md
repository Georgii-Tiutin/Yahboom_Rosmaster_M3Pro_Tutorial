## Caption
Flowchart showing the initialization and main loop sequence of an embodied AI ROS2 node with LLM, ASR, and wake word detection components.

## Description
This is a vertical flowchart depicting the startup and runtime flow of a ROS2-based embodied intelligent system. The flow begins with 'Start' (开始) and proceeds through a sequential initialization phase:
1. Initialize ROS2 Node (初始化ROS2节点)
2. Initialize Parameters (初始化参数配置)
3. Initialize LLM Interface (初始化大模型接口)
4. Initialize Wake Word Detection (初始化语音唤醒)
5. Initialize ASR Model (初始化ASR模型)
6. Initialize Language Settings (初始化语言设置)
7. Initialize WebRTC VAD (初始化WebRTC VAD)
8. Create Service Clients and Publishers (创建服务客户端和发布者)
9. Print Initialization Info (打印初始化完成信息)

After initialization, the flow enters a main loop with a decision diamond: 'Is Audio Request Queue Empty?' (音频请求队列是否为空). If not empty (No), it goes to 'Get Audio Request' (获取音频请求). If empty (Yes), it proceeds to 'ROS2 Spin Once' (ROS2自旋一次). Both paths loop back to the decision point. A Ctrl+C interrupt path leads to 'Destroy Node' (销毁节点) which terminates the program. All labels are bilingual in Chinese and English. The chart uses standard flowchart symbols: rounded rectangles for start/end, rectangles for processes, and a diamond for the decision point.
