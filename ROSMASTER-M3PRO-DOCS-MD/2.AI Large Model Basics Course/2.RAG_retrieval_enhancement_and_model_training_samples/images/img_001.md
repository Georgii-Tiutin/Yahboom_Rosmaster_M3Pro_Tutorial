## Caption
Flowchart illustrating the RAG (Retrieval-Augmented Generation) pipeline, showing how user queries retrieve relevant vector fragments from a private knowledge base and combine them with prompts to generate knowledge-grounded AI responses.

## Description
The diagram shows a RAG (Retrieval-Augmented Generation) workflow with the following components and flow:

1. A 'user' icon (top-left) provides 'User instructions' via a speech bubble.
2. The user's query flows in two directions:
   - Rightward into a 'Splicing text' pipeline consisting of three chevron-shaped stages: 'prompt', 'User instructions', and 'Vector fragment'. These are combined and fed into the 'AI Large Model' (represented by an OpenAI-style logo icon).
   - Downward to a 'RAG Private Knowledge Base' (depicted as a database cylinder at the bottom-left), labeled 'Stored as a vector'.
3. From the knowledge base, an upward arrow labeled 'Retrieve related snippets' leads to a 'Vector fragment' box, which feeds into the splicing text pipeline.
4. The AI Large Model outputs 'Answers based on the RAG knowledge base' (shown as a text box on the right).

The layout flows left-to-right and top-to-bottom, clearly illustrating how RAG augments a large language model by retrieving relevant document fragments from a private vector database and injecting them into the prompt context before generating a response. This is used in the ROSMASTER M3 Pro robot's AI large model tutorial to explain how the robot's knowledge system works.
