## Caption
Flowchart showing how an embodied intelligent robot system processes user instructions through a decision-making layer model and an execution layer model using conversation history context.

## Description
The diagram illustrates a two-layer architecture for an embodied AI robot system. At the top, user instructions enter and are added along with task steps to the conversation history context (which includes Prompt Tips). An initialization history feeds into a Decision-making layer model (depicted with an LLM/OpenAI-style logo). This model disassembles the user command into numbered quest steps (e.g., step 1, step 2). Each step is then sent to an Execution layer model (shown with a robot/gear icon on the right). The execution model's replies are added back to the conversation history context, creating a feedback loop. The bottom portion shows the iterative process: after execution, feedback is added to conversation history, and the next step is processed. The diagram uses arrows to show data flow between components, with conversation history context boxes appearing at multiple stages to show how context accumulates. Chinese text appears in the user command examples and some labels, consistent with the bilingual nature of the Yahboom robotics tutorials. This represents page 4 of the 'Embodied intelligent robot system architecture' tutorial, explaining the core prompt-chaining mechanism that enables the robot to break down complex commands into executable steps.
