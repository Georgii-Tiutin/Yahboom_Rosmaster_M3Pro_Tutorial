The image is a flowchart diagram illustrating how the embodied intelligent robot system handles task termination and conversation reset. On the left side, three trigger cases are shown in rounded boxes:

1. Case 1: The user requests to end the current task cycle.
2. Case 2: The robot fails to perform an action twice in a row.
3. Case 3: The robot encounters an impossible task.

Arrows from all three cases point to a central element labeled 'Execution layer model' (represented by a 3D cube icon). From this central model, an arrow points right with the label 'The large model calls the finish_dialogue() function to reset the conversation history context.' This leads to two output boxes on the right: 'Conversation history context' and 'Prompt Tips', collectively labeled as 'Initialization history'. The diagram explains the conditions under which the AI large model resets its dialogue state, returning conversation context and prompt tips to their initial values.
