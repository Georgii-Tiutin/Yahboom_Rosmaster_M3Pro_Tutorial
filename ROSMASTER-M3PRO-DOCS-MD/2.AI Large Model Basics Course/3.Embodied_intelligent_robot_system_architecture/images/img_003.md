## Caption
Diagram showing how an embodied intelligent robot uses a large language model to decompose a user's natural language request into sequential task steps.

## Description
The image illustrates the system architecture for an embodied intelligent robot processing a natural language command. On the left, a user icon speaks the request: 'Could you please get me a bottle of mineral water from the kitchen?' An arrow leads to a robot icon and then to a brain/AI icon labeled 'decision-making level Large Model.' From the large model, an arrow points right to a list of disassembled task steps:
1. Record your current location
2. Navigate to the tea room
3. Check the location of your bottle of mineral water
4. Grab the bottle of mineral water
5. Return to your starting location
6. Place the bottle of mineral water

The flow moves left to right: user → robot → Large Model → Disassembly task steps. This demonstrates how the LLM serves as the decision-making core that breaks down high-level human instructions into concrete, sequential robotic actions.
