## Caption
Diagram showing the voice input pipeline where user speech is converted to text via a speech recognition model before being sent to a large text generation model.

## Description
A left-to-right flow diagram illustrating the voice interaction pathway in an embodied intelligent robot system. On the left, a user icon with a speech bubble labeled 'User instructions' initiates the process by sending a 'Voice message' (indicated by an arrow) to a central 'Speech Recognition Model' (depicted as a circular icon with audio waveform graphics). The speech recognition model converts the voice input and outputs a 'Text message' (indicated by a second arrow) to a 'Large text generation model' on the right (represented by a stylized knot/logo icon resembling the OpenAI/ChatGPT logo). This diagram demonstrates how the robot system processes voice commands: first transcribing speech to text, then feeding the text into a large language model for understanding and response generation.
