## Caption
System architecture diagram showing a single task cycle for an embodied intelligent robot, illustrating the flow from user instructions through decision-making and execution levels.

## Description
This diagram depicts the architecture of a single task cycle in an embodied intelligent robot system. It is divided into two main sections separated by a dashed vertical line: the Decision-Making Level (left) and the Execution Level (right).

On the decision-making side, the flow begins with 'User instructions' on the far left, which feed into a 'Large text understanding and instruction generation model' that interprets the user's intent. This model generates 'Task steps (several subtasks)' through a planning process. A 'RAG Database prompt' feeds into this planning stage from below, providing contextual knowledge. The task steps are then passed to a 'Multimodal large model' which processes them further.

On the execution side, the multimodal model generates an 'action list and reply content' that is sent to the robot for execution. The robot interfaces with a 'Robot motion function library' (shown at the bottom on both sides), which provides the available motion primitives. Action execution status feedback and visual information feedback flow back from the execution level to the decision-making level (shown as return arrows at the top), enabling dynamic feedback reasoning until the task steps are completed.

The diagram illustrates a closed-loop control architecture where language understanding, task planning, multimodal perception, and physical robot execution work together in a continuous cycle, characteristic of embodied AI systems that combine large language models with robotic control.
