## Caption
Diagram showing how an AI large model controls a physical robot by calling API functions from a robot motion function library to perform actions like movement, observation, dancing, gripping, and navigation.

## Description
This is a left-to-right flow diagram illustrating the embodied AI robot system architecture. On the far left, an AI Large Model (represented by the OpenAI-style logo) connects via an arrow to a 'Robot motion function library' box. From there, an arrow labeled 'AI calls API functions to control physical robots' leads to a central robot icon. The robot then branches out to multiple action capabilities shown on the right side, each with an icon: move (directional arrows), observe the environment (human figure with eye), dance (dancing figure), robotic arm gripping (robotic arm icon), and navigation (map pin icon), with an ellipsis indicating additional possible actions. The diagram demonstrates how the AI model serves as the brain that selects and invokes predefined motion functions to command the robot's physical behaviors.
