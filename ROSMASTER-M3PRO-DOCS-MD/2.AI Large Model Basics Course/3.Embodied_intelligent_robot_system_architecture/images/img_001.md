## Caption
System architecture diagram of the embodied intelligent robot, showing the three-tier structure from user input through cloud AI decision-making to hardware execution on the end-side robot.

## Description
This diagram illustrates the full system architecture of the ROSMASTER M3 Pro embodied intelligent robot, organized into three horizontal tiers:

1. **User instructions** (top): The entry point where user commands are received.

2. **Decision-making level** (middle, labeled 'Cloud AI large model'): Contains the core AI processing pipeline including Speech Recognition, Large Text Generation Model, Multimodal Large Model, and Speech Synthesis Model. These cloud-based AI modules handle natural language understanding, multimodal reasoning, and response generation.

3. **Execution level** (bottom, labeled 'End-side robot'): Shows the local robot hardware and software components. On the input side, there is Keyword Awakening, VAD Detection, and a Voice/Dynamic Recording module feeding into the ROS Master node. The ROS Master communicates with the STM32 control board via Hardware Status and Control Parameters. Connected to the system are various hardware peripherals shown at the bottom: motors, servos, speakers, camera, LiDAR, IMU, and other sensors including a depth camera.

The data flow moves from user speech input down through cloud AI processing, back to the robot's ROS Master for execution, and out to the physical actuators and sensors. Dashed red boxes group related functional modules. This diagram provides a comprehensive overview of how voice commands are processed through large language models in the cloud and translated into physical robot actions locally.
