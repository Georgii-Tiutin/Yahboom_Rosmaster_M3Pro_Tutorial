MoveIt2 Setup Assistant screen for defining robot end effectors, showing a configured gripper end effector linked to a planning group.

## Description
The image shows the MoveIt2 Setup Assistant GUI application. The left sidebar contains a navigation menu with items: Start Screen, Self-Collisions, Virtual Joints, Planning Groups, Robot Poses, End Effectors (currently selected/highlighted), Passive Joints, ros2_control URDF Modifications, ROS 2 Controllers, MoveIt Controllers, Perception, Launch Files, and Author Information. The main content area is titled 'Define End Effectors' with a description explaining that end effectors are planning groups corresponding to grippers or tools attached to a parent planning group (an arm). A table shows one configured end effector with columns: End Effector Name ('gripper'), Group Name ('grip_group'), Parent Link, and Parent Group ('arm6'). Below the table are buttons for 'Add Selected', 'Delete Selected', and editing options. On the right side, there is a 3D visualization panel showing the robot model with the robotic arm and gripper rendered in a viewport with visual and collision display options.
