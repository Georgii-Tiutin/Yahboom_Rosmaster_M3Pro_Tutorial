## Caption
RViz2 MoveIt2 MotionPlanning interface showing the robot arm model and planning configuration panel.

## Description
The image shows a screenshot of the RViz2 visualization tool with the MoveIt2 MotionPlanning plugin active. On the left side is the Displays panel containing Global Options (with Global Status: Ok), a Grid display, and MoveIt2-specific settings including Move Group Namespace, Robot Description (set to 'robot_description'), and Planning Scene Topic (set to 'monitored_planning_scene'). Below that is the MotionPlanning panel with multiple tabs: Planning, Joints, Scene Objects, Stored Scenes, and Stored States. The Planning tab is active, showing Query Options with Planning Group set to 'arm_group', Start State set to '<current>', and Goal State set to 'init'. Additional options include Planning Time, Planning Attempts, Velocity Scaling, Accel. Scaling, Use Cartesian Path, Collision-aware IK, and Approx IK checkboxes. On the right side is a 3D viewport displaying the robot arm model rendered with colored coordinate frames (red, green, blue axes) and the robot's mechanical structure visible in a dark background. This screenshot demonstrates how to configure MoveIt2 motion planning parameters in RViz2 for the ROSMASTER M3 Pro's 6-DOF robotic arm.
