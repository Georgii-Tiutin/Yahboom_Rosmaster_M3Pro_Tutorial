## Description
The image is a screenshot of the MoveIt2 Setup Assistant GUI application. The left sidebar shows navigation steps including Start Screen, Self-Collisions, Virtual Joints, Planning Groups, Robot Poses, End Effectors, Passive Joints, ROS 2 Controllers, MoveIt Controllers, Perception, Launch Files, and Author Information. The main panel is on the 'Define Planning Groups' step, displaying an 'Edit arm_group Joint Collection' dialog. On the left side under 'Available Joints' are listed joints including Camera_Joint, arm1_Joint, arm2_Joint, arm3_Joint, arm4_Joint, arm5_Joint, DOFBOT_arm, Gripper_gripper, and link1_Joint, with some highlighted in blue. On the right side under 'Selected Joints' are the joints that have been added to the arm group: arm1_Joint, arm2_Joint, arm3_Joint, arm4_Joint, and arm5_Joint. Arrow buttons between the two lists allow moving joints between available and selected. A 3D robot visualization is shown in the bottom-right corner displaying the robot model with a red highlight on the arm joints. Save and Cancel buttons appear at the bottom of the dialog.
