## Caption
MoveIt Setup Assistant interface for editing the 'grip_group' planning group by selecting links from the robot's link collection.

## Description
The image shows the MoveIt Setup Assistant GUI, specifically the 'Define Planning Groups' section. The left sidebar lists configuration steps including Start Screen, Self-Collisions, Virtual Joints, Planning Groups, Robot Poses, End Effectors, Passive Joints, ROS 2 Controllers, MoveIt Controllers, Perception, Launch Files, and Author Information. The main panel is editing 'grip_group' as a Link Collection, with two columns: 'Available Links' on the left showing link names (Gripping, base_link, fl_link1 through fl_link4, fr_link1, and others partially visible including arm_base_link and others), and 'Selected Links' on the right showing the links already added to the group (link1 through link6). Arrow buttons between the columns allow moving links between available and selected. Save and Cancel buttons appear at the bottom right, along with 'visual' and 'collision' toggle options.
