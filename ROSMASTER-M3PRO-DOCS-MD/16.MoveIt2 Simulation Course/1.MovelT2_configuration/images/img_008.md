MoveIt2 Setup Assistant interface showing the Define Planning Groups configuration panel for a robotic arm.

## Description
The image shows the MoveIt2 Setup Assistant GUI application. On the left side is a vertical navigation menu with options including Start Screen, Self-Collisions, Virtual Joints, Planning Groups (currently selected and highlighted), Robot Poses, End Effectors, Passive Joints, ros2_control URDF M, ROS 2 Controllers, MoveIt Controllers, Perception, Launch Files, and Author Information. The main panel on the right is titled 'Define Planning Groups' and explains that users can create and edit 'joint model' groups based on joint collections, link collections, kinematic chains or subgroups. Below the description is a 'Current Groups' tree showing an 'arm_group' with joints (arm1_joint through arm6_joint, all marked as Revolute), Links, and Subgroups sections. At the bottom are buttons: Expand All, Collapse All, Delete Selected, Edit Selected, and Add Group. On the right side is a 3D visualization panel showing a dark rendering of the robot model with 'visual' and 'collision' toggle options.
