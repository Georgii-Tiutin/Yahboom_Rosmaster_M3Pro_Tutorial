## Description
The image shows the MoveIt2 Setup Assistant GUI with the 'Define Robot Poses' section selected in the left navigation panel (highlighted as 'Robot Poses'). The left sidebar lists configuration steps: Start Screen, Self-Collisions, Virtual Joints, Planning Groups, Robot Poses, End Effectors, Passive Joints, ros2_control URDF M, ROS 2 Controllers, MoveIt Controllers, Perception, Launch Files, and Author Information. The main content area displays a table of defined poses with columns for Pose Name and Group Name. Four poses are listed: 'up' (arm_group), 'down' (arm_group), 'relax' (grip_group), and 'close' (grip_group). Below the table are buttons: Show Default Pose, MoveIt, Edit Selected, Delete Selected, and Add Pose, along with Visual and Collision toggle options. On the right side, a 3D visualization shows the robot model with a red gripper/end effector mounted on top of the arm assembly.
