## Caption
RViz Displays panel showing MoveIt2 MotionPlanning configuration with a MarkerArray display added for the /plan_point topic.

## Description
The image shows the RViz Displays panel from a MoveIt2 workspace located at /home/yahboom/moveit2_ws/install/te. The panel lists the display hierarchy including Global Status (Ok), Grid, and MotionPlanning with its sub-settings: Move Group Namespace, Robot Description (robot_description), Planning Scene Topic (monitored_planning_scene), Scene Geometry, Scene Robot, and Planning Request configured for the arm_group planning group. Various color settings are visible for start state (green, 0;255;0), goal state (orange, 250;128;0), colliding links (red, 255;0;0), and joint violations (blue, 255;0;255). At the bottom, highlighted with a red rectangle annotation, is a MarkerArray display subscribed to the /plan_point topic, which is used to visualize the Cartesian path waypoints. A tooltip at the bottom explains it subscribes to visualization_msgs::MarkerArray.
