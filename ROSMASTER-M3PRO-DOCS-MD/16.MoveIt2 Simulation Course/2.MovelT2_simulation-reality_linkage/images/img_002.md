## Description
The screenshot shows the RViz visualization tool with MoveIt2 motion planning configured for the Yahboom ROSMASTER M3 Pro robot arm. On the left side is the Displays panel showing Global Options, Grid, and MotionPlanning plugin with settings including Move Group Namespace, Robot Description (robot_description), and Planning Scene Topic (monitored_planning_scene). The center viewport displays a 3D model of the robot arm mounted on the mobile chassis. On the bottom, the MotionPlanning panel is open on the Planning tab, showing options such as Planning Group, Planning Time, Planning Attempts, Velocity Scaling, Accel Scaling, Use Cartesian Path, Collision-aware IK, Approx IK Solutions, External Comm., and Sensor Positioning. The Commands section includes buttons like 'Plan & Execute'. This demonstrates the MoveIt2 simulation-reality linkage setup in RViz for controlling the robotic arm.
