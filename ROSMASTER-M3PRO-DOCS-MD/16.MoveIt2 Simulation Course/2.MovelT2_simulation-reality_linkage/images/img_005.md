## Description
This is a ROS2 computation graph (rqt_graph style) depicting the node architecture for MoveIt2 simulation-reality linkage. The central red-bordered box contains the arm_group_controller node cluster, which includes sub-nodes: arm_group_controller/state, arm_group_controller/follow_joint_trajectory, and arm_group_controller/follow_joint_trajectory_action/feedback. On the left side, joint_state_broadcaster and arm_group_controller feed into the system. On the right side, outputs connect to joint_states, robot_state_publisher, /tf, transform_listener_impl nodes, and /rviz_node. Below the main cluster, additional nodes include arm_group_controller/follow_joint_trajectory_action/status, /grip_group_controller, /grip_group_controller/gripper_cmd, /moveit_simple_controller_manager, and /execute_trajectory. The diagram illustrates how MoveIt2 coordinates the arm and gripper controllers with ROS2 topics and action interfaces for real robot control.
