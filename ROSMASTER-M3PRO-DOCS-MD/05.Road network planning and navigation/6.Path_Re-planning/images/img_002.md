## Caption

## Description
Screenshot of RViz2 for route graph editing. Left Displays panel lists: Global Options, Global Status: Warn, Route Graph, Map, TF, LaserScan, Grid (all checked), with buttons Add, Duplicate, Remove, Rename. Below is the Route Tool panel with tabs Add, Edit, Remove. The Add tab is selected, with radio options Node and Edge (Edge selected). Under "Connections:" the fields are highlighted by a red rectangle: Start Node ID: 6, End Node ID: 1, and a Create button. Load and Save buttons are at the bottom. The right 3D view shows a grey occupancy map with black obstacles and dark green-grey building areas. Green route graph edges connect red numbered nodes 0 to 7, with edge cost labels: 6–5 is 1918, 5–2 is 1716, 2 to the right is 2726, 2–1 is 1413, 1–0 is 1115, 6–7 is 2120, and a newly created, semi-transparent diagonal edge from 6 to 1 is labelled 32. A vertical edge goes up from node 2. The image shows how to add a new edge between two existing nodes for path re-planning.
