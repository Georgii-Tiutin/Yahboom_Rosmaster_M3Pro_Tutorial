## Description
Screenshot of RViz (ROSMASTER M3 Pro SLAM pose map tutorial, "Build A Pose Map", page 3). Top toolbar: Interact, Move Camera, Select, Focus Camera, Measure, 2D Pose Estimate, 2D Goal Pose, Publish Point, plus/minus icons. Left Displays panel lists: Global Options, Global Status: Ok, Grid, LaserScan, Map, RobotModel, TF, and MarkerArray (all checked). The MarkerArray row is highlighted with a red rectangle, indicating it should be added/enabled to display the pose graph. Buttons below: Add, Duplicate, Remove, Rename.

SlamToolboxPlugin panel: "Create Map Tool" section with Interactive Mode (checked) and Accept New Scans checkbox (unchecked); buttons Clear Changes, Save Changes, Save Map (with empty text field), Serialize Map (empty text field), Deserialize Map (text field "/home/jetson/map/map"). Radio options: Start At Dock, Start At Pose Est. (selected), Start At Curr. Odom, Localize. Pose fields: X 2.05, Y -0.51, θ -0.02. Button Clear Measurement Queue. "Merge Map Tool" section: Add Submap (with text field), Generate Map.

Right 3D view: a grey occupancy grid map with black obstacle walls, laser scan points (magenta, green, orange, cyan), the small robot model near center, and a pose graph drawn by MarkerArray: many red sphere nodes connected by thick blue lines (including loop-closure constraints forming a web of connections). A yellow line extends from the robot to a point at right.
