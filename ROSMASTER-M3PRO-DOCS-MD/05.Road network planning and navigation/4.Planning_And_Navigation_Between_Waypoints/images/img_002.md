## Caption
RViz2 window during waypoint navigation, with the RobotModel display item highlighted by a red box in the Displays panel and the robot shown on a costmap with green waypoint paths.

## Description
Screenshot of RViz2 for the ROSMASTER M3 Pro. Top toolbar: Move Camera, Select, Focus Camera, Measure, 2D Pose Estimate, Publish Point, Nav2 Goal, plus add/minus icons. Left Displays panel: Global Options (Fixed Frame: map; Background Color: 48; 48; 48; Frame Rate: 30), Global Status: Ok, Grid, RobotModel (checked, highlighted with a red rectangle), TF, LaserScan, Bumper Hit, Map, Global Planner, Controller, MarkerArray, RoadNet, all checked. Buttons below: Add, Duplicate, Remove, Rename. Below that is the SlamToolboxPlugin panel: Create Map Tool, Interactive Mode (checked), Accept New Scans, Clear Changes, Save Changes, Save Map, Serialize Map, Deserialize Map, radio buttons Start At Dock (selected), Start At Pose Est., Start At Curr. Odom, Localize, X/Y/θ fields, Clear Measurement Queue, Merge Map Tool, Add Submap, Generate Map. The 3D view shows a costmap with dark purple obstacles, cyan inflation areas, magenta/pink cells, grey map areas, and thick green path lines connecting red numbered waypoint markers (1, 2, 5). The small robot model sits at the bottom of the vertical green path below waypoint 1. The red box shows the user where to enable or check RobotModel to display the robot.
