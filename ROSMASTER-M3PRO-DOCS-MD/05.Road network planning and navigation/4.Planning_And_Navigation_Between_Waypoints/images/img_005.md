## Description
Two RViz screenshots (window title "/root/volumes/code_ws/install/road_net_route/share/road_net_route/rviz/nav2_view.rviz* - RViz"; menu: File, Panels, Help; toolbar: Move Camera, Select, Focus Camera, Measure, 2D Pose Estimate, Publish Point, Nav2 Goal). The bottom image is a slightly later/zoomed view with the toolbar partly cut off. Used in the tutorial to illustrate waypoint-to-waypoint navigation visualization with the road_net_route package.
