## Caption
ASCII-art vertical flow diagram of the reply-bridge audio pipeline, from OpenClaw through the reply-bridge Plugin, MCP Server, openclaw_bridge and TTS Engine to a USB Audio Device.

## Description
A text-based (monospace box-drawing) architecture diagram with six boxes stacked top to bottom, linked by vertical lines and downward arrows (▼). Order: "OpenClaw" -> "reply-bridge Plugin" -> (arrow labeled "MCP Protocol") -> "MCP Server" -> "openclaw_bridge" -> "TTS Engine" -> "USB Audio Device". It shows how a reply from OpenClaw is passed by the reply-bridge plugin over the MCP protocol to an MCP server, then to the openclaw_bridge node, then to a text-to-speech engine, and finally played out through a USB audio device (speaker). Only the link between the Plugin and MCP Server carries a label ("MCP Protocol").
