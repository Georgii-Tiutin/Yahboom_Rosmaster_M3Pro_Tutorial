## Description
Screenshot of the OpenClaw agent management web page. Top tabs: Overview, Files, Tools, Skills (66) (highlighted with a red box), Channels, Cron Jobs. The Skills panel header reads "Skills" with subtitle "Per-agent skill allowlist and workspace skills. 16/66". Buttons at the top right: Enable All, Disable All, Reset, Reload Config, Refresh, and Save (pink/disabled-looking, highlighted with a red box). A blue info banner says "This agent uses a custom skill allowlist." Below is a Filter box with placeholder "Search skills" and "66 shown". A collapsible section "WORKSPACE SKILLS" (red box) shows count 5. Skill cards listed, each with a green toggle switch and tags "openclaw-workspace" and "eligible": 
1. arm-pick-and-place – description in Chinese "使用机械臂完成物体抓取/放置功能" (use robot arm to grab/place objects); its toggle is highlighted with a red box. 
2. comprehensive-task – "A comprehensive task that includes garbage sorting, cargo sorting, goods handling between shelves, as well as out-of-stock inspection and restocking. Reference disposal procedures for scenarios involving multiple tasks". 
3. robot-navigation – Chinese description "在地图中按照路线规则导航到目标位置，并支持地图点记录与读取" (navigate to target positions on the map following route rules, supports recording/reading map points). 
4. visual-functions (partially visible). 
All toggles are on (green). The red boxes guide the user to: open the Skills tab, find Workspace Skills, enable the skill toggle (e.g., arm-pick-and-place), and click Save to apply the change.
