## Description
Screenshot of a plugin tool list titled "robot-control" with badge "PLUGIN:ROBOT-CONTROL". Tools are shown as cards in a 5-column grid, each with a name, description, a green toggle (all enabled) and a "PLUGIN:ROBOT-CONTROL" tag.

Row 1:
- AdjustCameraView: Adjust the camera perspective by pitch and yaw angles. Use this to adjust the robot's view to better observe the environment. Return the image after adjusting the camera perspective.
- AdjustChassisFitArmRange: Quickly adjust the mobile chassis so that the target point is within the working range of the robotic arm.
- ControlSingleArmJoint: Set a single joint of robot arm to a specified angle. Joint 6 is the gripper (0=closed, 180=open).
- ControlSixArmJoint: Simultaneously control 6 joints of the robotic arm. The 6th joint controls the gripper angle (0=closed, 180=open).
- GetBbox: Detect and return the bounding box coordinates of a target object based on its description. Use this for visual localization of objects.

Row 2:
- GetCurrentArmJointAngles: Get the current joint angles of the robotic arm.
- GetEndEffectorPose: Acquire the pose of the end effector (consisting of grippers and a camera).
- GetMapMapping: Get the mapping relationship between all place names and their corresponding symbols.
- GetPlacePoint: Find placement point coordinates and check if it's within the robotic arm's reachable workspace.
- GetWasteRecognitionResults: Get the waste recognition results from the YOLO model. Returns detected waste objects with bounding boxes.

Row 3:
- GraspWaste: Grasp the specified waste object identified from waste recognition results.
- InitArmPose: Restore the robotic arm to the preset initial posture.
- Move: Control the robot's chassis to move a specified distance in a given direction.
- MoveWithSpeed: Control the robot's omnidirectional chassis movement using velocity commands. Provides sophisticated and flexible control.
- Navigation: Navigate to the target location via the target point symbol.

Row 4:
- Pick: Pick up an object using the bounding box coordinates (x1, y1, x2, y2) obtained from GetBbox.
- Place: Place the object at the specified 3D coordinates (in meters). IMPORTANT: Must provide placeX, placeY, and placeZ all together.
- PlaceWaste: Place the currently held waste object into the appropriate bin.
- RecordMapLocation: Save the current location to the map mapping file with a name and symbol.
- SeeWhat: Capture a frame of image from the robot's camera (the robot's eyes).

Row 5:
- TargetTrack: Visual tracking of target objects. Provide bounding box coordinates (x1, y1, x2, y2) to start tracking, or pass 'cancel' to stop current tracking.
