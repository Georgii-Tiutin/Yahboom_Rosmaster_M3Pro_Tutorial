## Description
Screenshot of the OpenClaw web interface (breadcrumb "OpenClaw › Chat"). Top bar has a Search box (⌘K) and theme icons. Session selectors read "main · openclaw-tui" and "qwen3.6-plus · bailian". The user message (right, 8:33 PM) reads: "What tools do you currently use for robot control?" The assistant replies: "I have a suite of robot control tools available across several categories:"

**Robotic Arm Control**
- ControlSingleArmJoint — Set a single joint (1-6) to a specific angle (Joint 6 = gripper: 0=closed, 180=open)
- ControlSixArmJoint — Simultaneously control all 6 joints at once
- GetCurrentArmJointAngles — Read current joint positions
- GetEndEffectorPose — Get the gripper/camera pose
- InitArmPose — Return arm to preset home posture

**Pick & Place**
- Pick — Pick up an object using bounding box coordinates
- Place — Place an object at 3D coordinates (x, y, z)
- GetBbox — Detect and locate objects visually
- GetPlacePoint — Find valid placement points within arm reach
- AdjustChassisFitArmRange — Reposition the chassis so the target is reachable

**Mobility & Navigation**
- Move — Move the chassis a set distance in a direction (forward/backward/left/right)
- MoveWithSpeed — Velocity-based omnidirectional movement (linear X/Y, angular Z)
- Rotate — Rotate in place by a specified angle
- Navigation — Navigate to a saved map location by symbol
- FollowLine — Follow colored lines on the ground (red/green/blue/yellow)
- RecordMapLocation — Save current position to the map

At the bottom is the input box "Message Assistant (Enter to send)" with attach, mic, and a red send button. The list is cut off at the bottom of the visible area. It demonstrates the robot control plugin tools exposed to the OpenClaw agent.
