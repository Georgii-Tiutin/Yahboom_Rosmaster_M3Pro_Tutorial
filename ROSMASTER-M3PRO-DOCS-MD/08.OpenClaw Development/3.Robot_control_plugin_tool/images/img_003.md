## Description
Screenshot of the OpenClaw Control dashboard (version v2026.3.13). The left sidebar has sections: CHAT (Chat), CONTROL (Overview, Channels, Instances, Sessions, Usage, Cron Jobs), AGENT (Agents, Skills, Nodes), SETTINGS (Config, Communications, Appearance, Automation), plus Docs and a VERSION v2026.3.13 indicator. The "Agents" sidebar entry is highlighted with a red box, and the "Tools" tab is also highlighted with a red box in the tab row (Overview, Files, Tools, Skills, Channels, Cron Jobs). Breadcrumb: OpenClaw > Agents. Page title "Agents – Workspaces, tools, identities." Agent selector shows "main (default)" with "..." and "Refresh" buttons. The Tool Access panel says "Profile + per-tool overrides for this agent. 46/87 enabled." Profile: coding; Source: global default. Quick Presets buttons: Minimal, Coding (selected, red outline), Messaging, Full, Inherit. Tool groups: Files – read (Read file contents, enabled, CORE), write (Create or overwrite files, enabled, CORE), edit (Make precise edits, CORE); Runtime – exec (Run shell commands, enabled, CORE), process (Manage background processes, CORE); Web – web_search (Search the web, enabled, CORE), web_fetch (Fetch web content, CORE).
