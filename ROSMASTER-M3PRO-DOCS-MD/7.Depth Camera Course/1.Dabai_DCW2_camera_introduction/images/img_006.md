## Caption
RViz2 interface showing the 'Add Display' dialog for adding a PointCloud2 visualization topic alongside existing LiDAR scan displays.

## Description
The image shows the RViz2 visualization tool interface with a prominent 'Create visualization' dialog box open in the center. The dialog is set to the 'By topic' tab and displays a tree of available ROS2 topics. A red arrow/circle highlights the '/camera/depth/points' PointCloud2 topic being selected. The left panel shows the existing display configuration including Global Options (Fixed Frame set to 'map'), Global Status showing an error on the fixed frame, a RobotModel, TF, Map, and two LaserScan displays (one configured with Flat color in yellow/green, the other partially visible). The bottom status bar shows ROS Time. This screenshot demonstrates how to add a depth camera point cloud display in RViz2 as part of the Dabai DCW2 depth camera tutorial, teaching users to visualize the camera's 3D point cloud data alongside existing LiDAR scan data.
