## Caption
RViz MoveIt2 motion planning interface with the robotic arm model loaded and planning parameters configured for the arm_group.

## Description
The image shows a split-screen view on an Ubuntu desktop. On the left is a terminal window displaying MoveIt2 initialization logs, including loading of MoveGroup capabilities, planning plugin (ompl_interface/OMPL), and various move group services (ClearOctomapService, ExecuteTrajectoryAction, MoveGroupPlanService, etc.), concluding with 'You can start planning now!' and readiness for planning group arm_group. Below the terminal is the RViz MotionPlanning panel with settings: Planning Group set to 'arm_group', Planning Time 5.0s, Planning Attempts 10, Velocity Scaling 0.10, Accel. Scaling 0.10, Start State and Goal State both set to '<current>', and checkboxes for Use Cartesian Path, Collision-aware IK, Approx IK Solutions, External Comm., and Replanning. On the right is the RViz 3D viewport showing a rendered model of the Yahboom ROSMASTER M3 Pro robotic arm on its chassis, displayed in a dark 3D environment. This screenshot is from the collision detection tutorial demonstrating how to set up MoveIt2 motion planning with collision awareness.
