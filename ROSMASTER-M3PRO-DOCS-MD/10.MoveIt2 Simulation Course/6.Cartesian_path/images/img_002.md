## Caption
RViz2 interface showing the 'Create visualization' dialog for adding a MarkerArray display topic in MoveIt2 motion planning.

## Description
The image shows the RViz2 visualization tool with a MoveIt2 MotionPlanning plugin loaded. The main 3D viewport on the right displays a robotic arm model rendered in a dark environment. On the left side is the Displays panel showing the MotionPlanning display tree with properties like Move Group Namespace, Robot Description, Planning Scene Topic, Scene Geometry, Scene Robot, and Planning Request. A 'Create visualization' dialog box is open in the center, set to 'By topic' tab, with the topic '/display_contacts' of type MarkerArray highlighted. Red arrows in the image point from the dialog to the relevant UI elements, guiding the user through the process of adding this visualization. The dialog shows other available topics including Camera, DepthCloud, /filtered_label, and Image. The bottom of the dialog has Cancel and OK buttons, with OK highlighted. Red boxes also highlight the 'Add' button at the bottom-left of the Displays panel, indicating this is the starting point for the action. This screenshot is part of the Cartesian path planning tutorial, demonstrating how to configure RViz2 to visualize contact markers during MoveIt2 path planning.
