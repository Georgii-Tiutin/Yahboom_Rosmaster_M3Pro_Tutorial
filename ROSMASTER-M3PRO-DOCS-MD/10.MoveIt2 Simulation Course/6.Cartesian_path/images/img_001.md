## Description
The image shows a split-screen view of a ROS2 MoveIt2 setup for the Yahboom ROSMASTER M3 Pro robotic arm. On the left side, a terminal window displays log output from the move_group node, including StateValidationService initialization, OMPL planner plugin loading, and various MoveIt2 capability services being loaded (OccupancyMapMonitor, ClearOctomapService, CartesianPathService, ExecuteTrajectoryAction, KinematicsService, MoveGroupMoveAction, MoveGroupPlanService, ApplyPlanningSceneService, QueryPlannerService, StateValidationService). The terminal confirms 'You can start planning now!' and indicates readiness for planning group arm_group. Below the terminal is the MoveIt2 Motion Planning panel in RViz showing controls for Planning Group (arm_group), Start State, Goal State, Plan and Execute buttons, and planning parameters (Planning Time: 5.0s, Planning Attempts: 10, Velocity Scaling: 0.10, Accel. Scaling: 0.10). Checkboxes for 'Use Cartesian Path', 'Collision-aware IK', 'Approx IK Solutions', 'External Comm.', and 'Replanning' are visible. On the right side, the RViz 3D viewport displays a rendered model of the robotic arm mounted on the ROSMASTER M3 Pro chassis. This screenshot is from the Cartesian path planning tutorial, demonstrating the MoveIt2 environment setup for executing Cartesian path motions with the 6-DOF arm.
