## Caption
RViz MoveIt2 interface showing the 'Create visualization' dialog for adding a new display type to visualize the robot arm's trajectory planning.

## Description
The screenshot shows the RViz visualization tool with MoveIt2 configuration loaded. On the left side is the Displays panel listing various display properties including Global Options, Grid, MotionPlanning with sub-items like Move Group Namespace, Robot Description, Planning Scene Topic, Scene Geometry, Scene Robot, Planning Request (with Planning Group, Show Workspace, Query Start State, Query Goal State, Interactive Marker Size), Start State Color, Goal State Color, and Planning Metrics. In the center, a 'Create visualization' dialog box is open, showing display type options such as Axes, Camera, DepthCloud, Effort, FluidPressure, Grid, and others, with a filter field at the top and a description area below. On the right side, a 3D viewport shows a robotic arm model (the ROSMASTER M3 Pro's 6-DOF arm) mounted on the mobile chassis in its default pose. The bottom status bar shows 'Displays information about a planning scene and can animate solution paths within that planning scene.' This is from a MoveIt2 trajectory planning tutorial demonstrating how to set up the RViz environment for motion planning visualization.
