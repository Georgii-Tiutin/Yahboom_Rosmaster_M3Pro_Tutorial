MoveIt Setup Assistant screen for configuring MoveIt controllers, showing arm and gripper controller groups with their associated joints.

## Description
The image shows the MoveIt Setup Assistant GUI window, specifically the 'Setup MoveIt Controllers' page. The left sidebar displays navigation options including Start Screen, Self-Collisions, Virtual Joints, Planning Groups, Robot Poses, End Effectors, Passive Joints, ROS2_control URDF, MoveIt Controllers (currently selected/highlighted), Perception, Launch Files, and Author Information. The main panel is titled 'Setup MoveIt Controllers' with a description about configuring controllers for executing trajectories with MoveIt (hardware or simulation). At the top is an 'Auto Add FollowJointsTrajectory' button and a 'Controllers For Each Planning Group' section. Two controller groups are defined: 1) 'arm_group_controller' of type FollowJointTrajectory, containing joints: arm1_joint, arm4_joint, and arm5_joint; 2) 'grip_group_controller' of type GripperCommand, containing joint: slink1_joint. Each group is expandable with a tree view showing its joints. On the right side, a 3D visualization panel shows the robot model with the robotic arm. Buttons at the bottom include 'Expand All', 'Collapse All', and 'Add Controller', with visual and collision toggle options for the 3D view.
