## Description
The image is a screenshot of the RViz2 interface with the MoveIt2 MotionPlanning plugin active. On the left side, the Displays panel shows Global Options (status Ok), a Grid, and the MotionPlanning display with Robot Description set to 'robot_description' and Planning Scene Topic set to 'monitored_planning_scene'. Below that is the MotionPlanning configuration panel with multiple tabs (Context, Planning, Joints, Scene Objects, Stored Scenes, Stored States, Status). The Planning tab is selected, showing: Planning Group set to 'arm_group', Start State set to '<current>', Planning Time of 5.0 seconds, Planning Attempts of 10, Velocity Scaling of 0.10, and Acceleration Scaling options. Buttons for 'Plan', 'Plan & Execute' are visible and highlighted with a red rectangle annotation. On the right side, a 3D viewport displays the ROSMASTER M3 Pro robot model with its Mecanum wheel chassis and a multi-joint robotic arm shown with colorful interactive markers (orange, green, blue) for motion planning. This page demonstrates how to configure and use the MoveIt2 motion planning interface in RViz2 for controlling the robot's arm group.
