## Description
The screenshot shows the RViz2 visualization tool running on Ubuntu with a MoveIt2 configuration workspace (moveit2_ws). The MotionPlanning panel below has multiple tabs (Context, Planning, Joints, Scene Objects, Stored Scenes, Stored States, Status). The Planning tab is active, showing the Planning Group dropdown set to 'arm_gro' (arm_group), with parameters like Planning Time (5.0s), Velocity Scaling, and Acceleration Scaling.
