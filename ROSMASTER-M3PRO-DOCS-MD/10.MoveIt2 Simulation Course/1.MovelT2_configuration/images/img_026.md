## Caption
MoveIt Setup Assistant screen for configuring ROS 2 controllers, showing the arm_group_controller with JointTrajectoryController assigned to the robot arm's joints.

## Description
The image shows the MoveIt Setup Assistant GUI window with the 'Setup ROS 2 Controllers' panel active. The left sidebar lists configuration steps including Start Screen, Self-Collisions, Virtual Joints, Planning Groups, Robot Poses, End Effectors, Passive Joints, ros2_control URDF Modifications, ROS 2 Controllers (currently selected, highlighted in blue), MoveIt Controllers, Perception, Launch Files, and Author Information. The main panel instructs users to configure ros2_controllers, noting that ros2_control fake_components are used by default to create a simple simulation. Two buttons at the top offer 'Auto Add JointTrajectoryController' and 'Controllers For Each Planning Group'. Below, an expanded tree shows 'arm_group_controller' of type 'joint_trajectory_controller/JointTrajectoryController' with its associated joints listed: arm1_joint through arm5_joint. At the bottom are 'Expand All / Collapse All' and 'Add Controller' buttons. On the right side, a 3D visualization shows the red robotic arm model in its default pose.
