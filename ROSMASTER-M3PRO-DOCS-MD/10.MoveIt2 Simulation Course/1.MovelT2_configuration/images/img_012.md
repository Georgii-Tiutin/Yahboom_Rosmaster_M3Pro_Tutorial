## Description
This screenshot shows the MoveIt2 Setup Assistant GUI application. The left sidebar displays a navigation menu with configuration steps: Start Screen, Self-Collisions, Virtual Joints, Planning Groups, Robot Poses (currently selected and highlighted), End Effectors, Passive Joints, ros2_control URDF Modification, ROS 2 Controllers, MoveIt Controllers, Perception, Launch Files, and Author Information. The main panel is titled 'Define Robot Poses' with instructions explaining that poses are defined as sets of joint values for particular planning groups, useful for positions like home position, and that the first listed pose will be the robot's initial pose in simulation. A table with columns 'Pose Name' and 'Group Name' is shown empty. Below the table are buttons: 'Show Default Pose', 'MoveIt', 'Delete Selected', and 'Add Pose'. On the right side, a 3D visualization panel shows a dark preview of the robot model with 'Visual' and 'Collision' toggle options at the top right.
