## Caption
MoveIt2 RViz interface showing the MotionPlanning plugin with planned path visualization and planning configuration parameters for a robotic arm grip group.

## Description
The image shows a screenshot of the RViz visualization tool with the MoveIt2 MotionPlanning plugin active. On the left side, there are two panel sections:

1. **Displays panel (top-left)**: Shows the 'Planned Path' display settings including Trajectory Topic set to 'display_planned_path', options for Show Robot Visual and Show Robot Collision (both checked), Robot Alpha set to 0.5, State Display Time at 0.05s, and toggles for Use Sim Time and Loop Animation.

2. **MotionPlanning panel (bottom-left)**: Contains multiple tabs (Context, Planning, Joints, Scene Objects, Stored Scenes, Stored States, Status). The Planning tab is active, showing:
   - Commands section with Plan, Plan & Execute, and Execute buttons
   - Query Options section with Planning Group set to 'grip_group', Start State set to '<current>', Planning Time(s) at 5.0, Planning Attempts at 10, Velocity Scaling at 0.10, and additional options for Collision-aware IK, Approx IK Solutions, and External Comm.

On the right side, the 3D viewport displays a robotic arm model (appears to be a gripper/manipulator) rendered in RViz with both the robot visual model and a semi-transparent planned path pose shown. A red bounding box highlights the gripper end-effector area.

This screenshot is from a MoveIt2 configuration tutorial demonstrating how to set up and use the MotionPlanning plugin in RViz to plan motions for the grip_group planning group of the Yahboom ROSMASTER M3 Pro's robotic arm.
