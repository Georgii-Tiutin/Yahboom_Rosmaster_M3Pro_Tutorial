## Caption
MoveIt2 Setup Assistant interface for defining robot arm poses by setting joint values for the arm planning group.

## Description
The image shows the MoveIt2 Setup Assistant (step 5) with the 'Define Robot Poses' panel active. On the left side is a navigation sidebar with options including Self-Collisions, Virtual Joints, Planning Groups, Robot Poses, End Effectors, Passive Joints, Controllers, Simulation, Perception, Launch Files, and Author Information. The main panel contains a form for creating a named robot pose called 'arm_ground' for the 'arm_group' planning group. Several joint sliders are displayed (arm1_Joint, arm2_Joint, arm3_Joint, arm5_Joint) with their corresponding numerical values set to specific positions (mostly near 0.0000 with arm5_Joint at 1.7540). On the right side is a 3D visualization preview showing the robot model in the defined pose. At the bottom are Save and Cancel buttons, along with checkboxes for 'visual' and 'collision' display options. This page is part of a tutorial on configuring MoveIt2 for the ROSMASTER M3 Pro robotic arm, demonstrating how to define preset joint configurations such as a ground/home position.
