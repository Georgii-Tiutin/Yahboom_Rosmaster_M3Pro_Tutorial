MoveIt2 Setup Assistant showing the Self-Collision checking optimization screen with a collision matrix table.

## Description
The image shows the MoveIt2 Setup Assistant GUI application. On the left side is a navigation panel with menu items: Start Screen, Self-Collisions (currently selected, highlighted), Virtual Joints, Planning Groups, Passive Joints, Perception, Launch Files, and Author Information. The main content area displays the 'Optimize Self-Collision Checking' configuration page. At the top is an explanatory text describing how this feature searches for pairs of robot links that can safely be disabled from collision checking to decrease motion planning time. Below that are controls for 'Sampling Density' with a slider (set to high/10000) and 'Min. collisions for "always" colliding pairs' (set to 95%). A 'Generate Collision Matrix' button is visible. The lower portion contains a collision matrix table showing pairs of robot links (Link A and Link B columns) with their disabled reasons and checkboxes. Visible link pairs include entries like 'arm_link0' paired with various other links (Camera, base_footprint, etc.) with reasons such as 'Never', 'Adjacent', and 'Default'. The table has columns for Link A, Link B, Disabled, and reason to Disable. At the bottom are options to 'show enabled pairs' and toggle between 'linear view', 'matrix view', and 'branch' views, plus visual/collision display toggles.
