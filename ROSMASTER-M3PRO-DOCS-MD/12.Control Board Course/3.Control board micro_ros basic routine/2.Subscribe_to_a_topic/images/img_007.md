## Description
The image shows the Eclipse IDE project properties window for a C/C++ project. On the left panel, a tree navigation shows Resource, Builders, C/C++ Build (with sub-items Build Variables, Environment, Logging, Settings), and C/C++ General (with sub-items Code Analysis, Documentation, File Types, Formatter, Indexer, Language Mappings, Paths and Symbols, Preprocessor Include, and CMSIS-SVD Settings). The 'Paths and Symbols' item is highlighted/selected. On the right panel, the Configuration is set to 'Debug [Active]' with a 'Manage Configurations...' button. Below are tabs: Includes, Symbols, Libraries, Library Paths, Source Location (currently selected, highlighted with a red/orange box), and References. The Source Location tab displays 'Source folders on build path:' with a tree showing /Publisher/APP, /Publisher/Core, /Publisher/Moorsee (highlighted with a red/orange box), and /Publisher/Middlewares. Action buttons 'Add Folder...' and 'Edit Filter...' appear on the right side. This screenshot is from a tutorial on subscribing to a topic in a micro-ROS or STM32 ROS2 context, showing how to configure source folder paths in the Eclipse-based IDE for building the Publisher project.
