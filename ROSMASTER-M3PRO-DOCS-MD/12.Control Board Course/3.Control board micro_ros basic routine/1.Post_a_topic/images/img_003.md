## Caption
STM32CubeMX SYS peripheral configuration showing the Timebase Source set to TIM7 under System Core categories.

## Description
The image shows the STM32CubeMX IDE configuration interface for the SYS (System) peripheral on an STM32H7 microcontroller. On the left side is a navigation panel under 'System Core' category listing peripherals: BDMA, CORTEX_M7, DMA, GPIO, IWDG1, MDMA, NVIC, RAMECC, RCC, SYS (currently selected and highlighted in blue with a green checkmark), and WWDG1. RCC has a yellow warning triangle. On the right side, the Mode section shows 'Timebase Source' set to 'TIM7'. Below that, the Configuration section displays a warning message: 'This peripheral has no parameters to be configured.' This is a typical step in STM32 project setup where the SYS timebase source is changed from SysTick to TIM7, which is required when using FreeRTOS or micro-ROS to avoid conflicts with the RTOS tick timer.
