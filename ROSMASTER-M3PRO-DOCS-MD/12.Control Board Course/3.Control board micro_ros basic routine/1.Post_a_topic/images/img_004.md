## Caption
STM32CubeMX USART1 configuration interface showing asynchronous mode settings with 2000000 baud rate and DMA stream assignments.

## Description
The image shows the STM32CubeMX IDE configuration screen for the USART1 peripheral. On the left is a peripheral navigation tree listing categories such as System Core, Analog, Timers, Connectivity (expanded to show ETH, FDCAN1, FDCAN2, FMC, I2C1-I2C3, LPUART1, MDIOS, QUADSPI, SDMMC1, SDMMC2, SPI1-SPI6, UART4-UART8, USART1-USART6). USART1 is selected. The top section shows Mode set to 'Asynchronous' with Hardware Flow Control (RS232) and (RS485) both disabled. The Configuration area has tabs: Parameter Settings, User Constants, NVIC Settings, DMA Settings, and GPIO Settings. Under Parameter Settings, Basic Parameters show: Baud Rate = 2000000 Bits/s, Word Length = 8 Bits (including Parity), Parity = None, Stop Bits = 1. Advanced Parameters show: Data Direction = Receive and Transmit, Over Sampling = 16 Samples, Single Sample = Disable, and additional FIFO-related settings. At the bottom, the DMA Settings tab is also visible showing two DMA requests: USART1_RX on DMA1 Stream 0 (Peripheral To Memory, Low priority) and USART1_TX on DMA1 Stream 1 (Memory To Peripheral, Low priority). This configuration is part of setting up serial communication between the STM32 control board and other components of the ROSMASTER M3 Pro robot platform.
