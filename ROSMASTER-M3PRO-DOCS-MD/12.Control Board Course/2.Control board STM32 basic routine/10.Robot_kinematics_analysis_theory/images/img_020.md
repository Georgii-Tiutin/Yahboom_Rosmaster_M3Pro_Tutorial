The diagonal pairing pattern of A and B wheels is clearly shown, which is essential for understanding how Mecanum wheels generate omnidirectional movement.

In the context of the robot kinematics tutorial (page 11), these diagrams explain the physical wheel configuration that forms the basis for kinematic analysis of omnidirectional motion using Mecanum wheels.
