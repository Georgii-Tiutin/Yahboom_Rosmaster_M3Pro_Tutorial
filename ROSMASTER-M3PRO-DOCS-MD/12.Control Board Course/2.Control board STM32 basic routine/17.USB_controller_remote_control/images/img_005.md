## Caption
Serial monitor (Uart Assistant) displaying USB controller joystick data received over COM4 at 115200 baud.

## Description
The image shows a Windows 'Uart Assistant' serial terminal application connected to COM4 at 115200 baud rate (8 data bits, 1 stop bit, no parity, no flow control). The Data Log panel on the right displays timestamped lines of incoming ASCII data in the format 'Joy:128 128 128 128 0F X X X X X X X X X X X X', representing joystick axis values and button states from a USB controller. All four joystick axes read 128 (centered/neutral position), and button states are shown as 'X' (unpressed). The entries are logged at approximately 200ms intervals (e.g., 12:19:37.196 to 12:19:38.599). The left panel shows COM configuration settings and receive/send options with ASCII mode selected, log display mode and auto linefeed enabled. This demonstrates verifying the USB controller's serial data output in the robot's remote control tutorial.
