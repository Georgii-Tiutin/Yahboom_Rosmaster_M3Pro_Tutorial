## Caption
STM32CubeMX NVIC configuration panel showing the SPI2 global interrupt enabled for IMU data communication.

## Description
The image shows the NVIC (Nested Vectored Interrupt Controller) Settings tab within the STM32CubeMX configuration tool. At the top is a 'Reset Configuration' button, followed by a row of configuration tabs: NVIC Settings (currently selected, highlighted in blue), DMA Settings, GPIO Settings, Parameter Settings, and User Constants. Below the tabs is the NVIC Interrupt Table with columns for Enabled, Preemption Priority, and Sub Priority. A single entry is shown: 'SPI2 global interrupt' with a checked enabled checkbox, Preemption Priority set to 0, and Sub Priority set to 0. This configuration step enables the SPI2 interrupt, which is necessary for reading IMU (Inertial Measurement Unit) sensor data via the SPI2 peripheral on the STM32 microcontroller.
