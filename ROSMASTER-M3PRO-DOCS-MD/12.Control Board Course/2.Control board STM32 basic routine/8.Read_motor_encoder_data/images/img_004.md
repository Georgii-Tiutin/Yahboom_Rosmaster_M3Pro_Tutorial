## Caption
STM32CubeMX TIM3 timer configuration set to Encoder Mode for reading motor encoder data.

## Description
This screenshot shows the STM32CubeMX IDE configuration interface for Timer 3 (TIM3). On the left side, the Categories panel lists peripherals under System Core, Analog, and Timers sections, with TIM3 highlighted/expanded under Timers. The main configuration area shows TIM3's mode settings: Channels 1-4 are set to Disable, while Combined Channels is set to 'Encoder Mode'. Below, the Parameter Settings tab is selected (alongside NVIC, DMA, and GPIO Settings tabs). The Counter Settings section shows: Prescaler (PSC) set to 0, Counter Mode set to Up, Counter Period (AutoReload) set to 65535, Internal Clock Division to No Division, and auto-reload preload as Disable. Additional settings include Trigger Output (TRQG) Parameters and Master/Slave Mode. The Encoder Mode is configured to use TI1 and TI2. This configuration enables TIM3 to read quadrature encoder signals from a motor, which is essential for measuring motor speed and position on the STM32 control board of the ROSMASTER M3 Pro robot.
