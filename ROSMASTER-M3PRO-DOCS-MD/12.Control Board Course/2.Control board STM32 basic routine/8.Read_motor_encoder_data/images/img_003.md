## Caption
STM32CubeMX TIM2 timer configuration set to Encoder Mode for reading motor encoder data.

## Description
This screenshot shows the STM32CubeMX IDE configuration interface for the TIM2 timer peripheral. On the left panel, the Categories tree lists peripheral groups (System Core, Analog, Timers, Connectivity, Multimedia) with the Timers section expanded showing all available timers (HRTIM, LPTIM1-5, RTC, TIM1-TIM17). TIM2 is selected and highlighted with a green checkmark, along with TIM3, TIM4, and TIM5. On the right panel, the TIM2 Mode and Configuration is displayed. In the Mode section, Combined Channels is set to 'Encoder Mode' while individual channels and other mode options are disabled. The Configuration section below shows Parameter Settings with Counter Settings (Prescaler: 0, Counter Mode: Up, Counter Period/AutoReload: 65535, Internal Clock Division: No Division, auto-reload preload: Disable), Trigger Output (TRGO) Parameters, and Encoder settings configured to 'Encoder Mode TI1 and TI2'. This configuration is part of a tutorial on reading motor encoder data from the STM32 control board, enabling quadrature encoder input on TIM2.
