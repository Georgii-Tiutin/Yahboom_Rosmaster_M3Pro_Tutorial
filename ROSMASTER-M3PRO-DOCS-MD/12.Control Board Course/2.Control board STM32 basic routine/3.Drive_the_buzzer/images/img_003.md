## Caption
STM32CubeMX pin configuration for the buzzer (BEEP) GPIO output on pin PE5.

## Description
The image shows the STM32CubeMX IDE interface used to configure GPIO pins on an STM32H7 microcontroller. On the left side is the System Core category tree listing peripherals (BDMA, CORTEX_M7, DMA, IWDG1, MDMA, NVIC, RAMECC, RCC, SYS, WWDG1) along with collapsible sections for Analog, Timers, Connectivity, Multimedia, Security, Computing, Middleware, and Trace and Debug. The center-right area displays a pin configuration table filtered to show only modified pins, with columns for Signal, Pin Config, GPIO, and pin settings. Four pins are listed: PC13 (LED output, low, no pull), PC14 (LED_ output, low, no pull), PC15 (KEY1 input, pull-up), and PE5 (BEEP output, low, no pull). The bottom-right panel shows the detailed PE5 Configuration with GPIO output level set to Low, GPIO mode set to Output Push Pull, no pull-up/pull-down, maximum output speed Low, and User Label set to BEEP. This configuration step is part of the STM32 buzzer driver tutorial, setting up the PE5 pin as a push-pull GPIO output to control the buzzer.
