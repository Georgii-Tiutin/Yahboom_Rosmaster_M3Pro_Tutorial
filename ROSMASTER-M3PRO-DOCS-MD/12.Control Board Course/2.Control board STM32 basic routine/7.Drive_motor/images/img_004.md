## Caption
STM32CubeMX TIM1 timer configuration showing PWM Generation on channels 1–4 for driving motors.

## Description
The image shows the STM32CubeMX IDE timer configuration interface for TIM1. On the left panel, the Categories tree lists peripherals including System Core, Analog, Timers (expanded to show HRTIM, LPTIM1-5, RTC, TIM1 through TIM17), Connectivity, and Multimedia. TIM1 is selected (green checkmark). The right panel displays the Mode section with Channels 1–4 set to 'PWM Generation CH1' through 'PWM Generation CH4', while Channels 5–6 and Combined Channels are disabled. Slave Mode, Trigger Source, and Clock Source are all set to Disable. Below, the Configuration section shows Parameter Settings with Counter Settings: Prescaler (PSC - 16 bits) = 4, Counter Mode = Up, Counter Period (AutoReload) = 1999, Internal Clock Division = No Division, Repetition Counter (RCR) = 0, auto-reload preload = Enable. Trigger Output (TRGO) parameters are also visible. At the bottom, the function signature 'void MX_TIM1_Init(void)' is shown. This configuration sets up four PWM channels on TIM1 to control the drive motors of the robot.
