## Caption
STM32CubeMX DMA configuration showing UART4_RX mapped to DMA1 Stream 2 for receiving LiDAR data.

## Description
This screenshot shows the DMA Settings tab in STM32CubeMX IDE configuration interface. The top navigation bar displays tabs: NVIC Settings, DMA Settings (currently selected, highlighted), GPIO Settings, Parameter Settings, and User Constants. Below is a table with columns: DMA Request, Stream, Direction, and Priority. A single DMA entry is configured: UART4_RX using DMA1 Stream 2, with direction set to 'Peripheral To Memory' and priority set to 'Low'. This configuration enables Direct Memory Access for UART4 receive operations, which is used to efficiently read incoming LiDAR serial data on the STM32 control board without CPU intervention.
