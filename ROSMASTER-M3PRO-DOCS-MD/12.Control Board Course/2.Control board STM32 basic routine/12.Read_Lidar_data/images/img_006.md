## Caption
STM32CubeMX UART4 configuration showing asynchronous mode with 230400 baud rate for LiDAR serial communication.

## Description
This screenshot shows the STM32CubeMX IDE peripheral configuration interface for UART4. The left panel displays a categorized list of peripherals (Categories/A-Z tabs) including NVIC, RAMECC, RCC, SYS, WWDG1, plus expandable sections for Analog, Timers, and Connectivity. Under Connectivity, UART4 is selected (highlighted with a green checkmark). The right panel shows 'UART4 Mode and Configuration' with Mode set to 'Asynchronous' and Hardware Flow Control (RS232) disabled. Below, the Configuration section has tabs for NVIC Settings, DMA Settings, GPIO Settings, Parameter Settings, and User Constants. The Parameter Settings tab is active, showing: Basic Parameters (Baud Rate: 230400 Bits/s, Word Length: 8 Bits including Parity, Parity: None, Stop Bits: 1), Advanced Parameters (Data Direction: Receive and Transmit, Over Sampling: 16 Samples, Single Sample: Disable, ClockPrescaler: 1, Fifo Mode: FIFO mode disable, Txfifo/Rxfifo Threshold: 1 eighth full configuration), and Advanced Features (Auto Baudrate: Disable, TX/RX Pin Active Level Inversion: Disable). This configures the STM32 microcontroller's UART4 peripheral for serial communication with the LiDAR sensor at 230400 baud.
