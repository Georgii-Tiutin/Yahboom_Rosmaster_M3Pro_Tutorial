STM32CubeMX NVIC Settings panel showing enabled DMA1 and UART4 global interrupts for LiDAR data communication.

## Description
The image shows the NVIC (Nested Vectored Interrupt Controller) Settings tab within the STM32CubeMX configuration tool. The interface displays a tabbed navigation bar with five tabs: NVIC Settings (currently selected, highlighted in blue), DMA Settings, GPIO Settings, Parameter Settings, and User Constants.

Below the tabs is an NVIC Interrupt Table with four columns: interrupt name, Enabled (checkbox), Preemption Priority, and Sub Priority. Two interrupts are listed and both are enabled (checked):
1. DMA1 stream2 global interrupt — Preemption Priority: 0, Sub Priority: 0
2. UART4 global interrupt — Preemption Priority: 0, Sub Priority: 0

In the context of the LiDAR data reading tutorial, this configuration enables the STM32 microcontroller to receive LiDAR serial data via UART4 with DMA (Direct Memory Access) transfer, allowing efficient non-blocking data reception from the LiDAR sensor.
