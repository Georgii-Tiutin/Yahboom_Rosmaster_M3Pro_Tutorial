## Caption
STM32CubeMX TIM12 timer configuration for PWM servo control, showing prescaler, counter period, and dual PWM channel settings.

## Description
This screenshot shows the STM32CubeMX IDE's timer configuration interface for TIM12. On the left is a navigation tree listing peripheral categories (System Core, Analog, Timers, Connectivity) with TIM12 selected (highlighted in blue with a green checkmark). The right panel displays TIM12's Mode and Configuration. In the Mode section, Slave Mode and Trigger Source are disabled, Internal Clock is unchecked, Channel1 and Channel2 are both set to 'PWM Generation CH1/CH2', Combined Channels is Disable, and One Pulse Mode is unchecked. The Configuration section has tabs for NVIC Settings, GPIO Settings, Parameter Settings (currently selected, highlighted in orange), and User Constants. Under Counter Settings, the Prescaler is set to 239, Counter Mode is Up, Counter Period (AutoReload) is 19999, Internal Clock Division is No Division, and auto-reload preload is Disable. Below that, PWM Generation Channel 1 and Channel 2 settings are shown with PWM mode 1, Pulse value 0, Output compare preload Enable, Fast Mode Disable, and CH Polarity High. These settings configure a 50Hz PWM signal (typical for servo motors) using a standard STM32 timer prescaler/period combination.
