## Description
The image is a diagram illustrating the relationship between PWM (Pulse Width Modulation) signal duty cycles and corresponding servo motor positions. It shows five rows, each containing a PWM waveform on the left, its pulse width label in the center, and a servo position indicator with angle on the right.

- 0.5ms pulse width → 0° (servo at minimum position)
- 1ms pulse width → 45° (servo rotated slightly)
- 1.5ms pulse width → 90° (servo at center/neutral position)
- 2ms pulse width → 135° (servo rotated further)
- 2.5ms pulse width → 180° (servo at maximum position)

Each PWM waveform shows a rectangular pulse with increasing width from top to bottom, demonstrating how longer high-signal durations command greater servo rotation angles. The servo position icons on the right visually depict the dial/indicator rotating clockwise as the pulse width increases. This is a standard reference diagram used in robotics tutorials to explain how PWM signals control servo motor positioning.
