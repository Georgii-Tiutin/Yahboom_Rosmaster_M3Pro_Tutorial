## Caption
STM32CubeMX GPIO pin configuration for a button input (KEY1) on PC15-OSC32_OUT, set as input mode with pull-up.

## Description
The image shows the STM32CubeMX IDE pin configuration interface. On the left side is the 'System Core' peripheral tree listing items such as DMA, BDMA, GPIO, MDMA, NVIC, RAMECC, RCC, SYS, and WWDG1. The top area has tabs for GPIO, DEBUG, and RCC, along with a 'Search Signals' bar and a 'Show only Modified Pins' checkbox. A table in the middle lists configured GPIO pins (PC13, PC14-OSC_IN, PC14-OS...) with columns for Pin, GPIO output level, mode, pull-up/pull-down, and user label (showing labels like LED and KEY). Below the table, the detailed configuration panel for pin PC15-OSC32_OUT (OSC32_OUT) is displayed, with GPIO mode set to 'Input mode', GPIO Pull-up/Pull-down set to 'Pull-up', and User Label set to 'KEY1'. At the bottom, a #define line maps LED to a specific MCU pin (GPIO PIN 12). This configuration is part of the STM32 button functions tutorial, showing how to set up a physical button as a GPIO input with an internal pull-up resistor in the CubeMX graphical configuration tool.
