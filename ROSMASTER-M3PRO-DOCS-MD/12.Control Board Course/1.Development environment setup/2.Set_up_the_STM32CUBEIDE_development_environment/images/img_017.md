## Description
The image shows the STM32CubeIDE integrated development environment with the Pinout & Configuration tab active. On the left side, a navigation tree lists peripheral categories including System Core (BDMA, CORTEX_M7, DMA, GPIO), Analog, Timers, Connectivity, Multimedia, Security, Computing, Middleware and Software Packs, and Power and Thermal. The center panel displays the GPIO Mode and Configuration section with a table showing pin settings grouped by peripherals, including columns for Pin Name, Signal, GPIO Mode, GPIO Pull-up/Pull-down, Maximum Output Speed, and User Label. A few pins are configured, with entries visible such as LED_Mcu with Low output and no pull-up settings. On the right side, an interactive MCU pinout view displays the chip package with color-coded pins indicating their assigned functions (green for configured GPIO, yellow for other peripherals). The top menu bar shows tabs for Pinout & Configuration, Clock Configuration, and Project Manager. This screenshot is from a tutorial on setting up the STM32CubeIDE development environment for the robot's STM32 control board.
