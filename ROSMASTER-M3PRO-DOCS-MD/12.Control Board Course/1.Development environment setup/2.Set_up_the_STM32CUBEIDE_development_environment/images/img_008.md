## Description
The image shows a screenshot of the ST Microelectronics (st.com) website product page for the STM32H743VGT6 microcontroller. The page displays the MCU/MPU product finder interface with navigation tabs including Features, Block Diagram, Docs & Resources, CAD Resources, and eDesignSuite. The main content area shows the STM32H7 series listing with the STM32H743VGT6 part number highlighted. Key specifications are shown: high-performance Arm Cortex-M7 MCU with DP-FPU and DSP, 1MB Flash memory, 1MB RAM, 480 MHz CPU, L1 cache, external memory interface, JPEG codec, and a large set of peripherals. Additional details include the unit price ($7.5266 for 10KU), LQFP 100 package (14x14x1.4 mm), and production status (in mass production). A product description paragraph at the bottom provides further technical details about the STM32H742/H743 device family. This screenshot is used in the STM32CubeIDE development environment setup tutorial to help users identify and select the correct target MCU for their Yahboom ROSMASTER M3 Pro robot's STM32 control board.
