## Description
Screenshot of the STM32CubeIDE (or Eclipse-based IDE) project properties dialog. The left panel shows a navigation tree with sections including Resource, C/C++ Build (with sub-items Build Variables, Environment, Logging, Settings), C/C++ General (expanded, showing Code Analysis, Documentation, File Types, Formatter, Indexer, Language Mappings, Paths and Symbols, Preprocessor Include, CMSIS-SVD Settings). The right panel displays the 'Source Location' tab (also highlighted with a red box), showing source folders on the build path: /Publisher/APP, /Publisher/Core, /Publisher/Drivers, and /Publisher/Middlewares. Buttons for 'Add Folder...', 'Link Folder...', and 'Delete' are available on the right side. The configuration is set to 'Debug [Active]'. This step is part of configuring the micro-ROS driver library compilation by verifying that the correct source folders are included in the project build path.
