## Caption
Diagram illustrating the ROS2 service communication model between a Service Client node and a Service Server node via request-response messaging.

## Description
The diagram shows two circular nodes representing ROS2 nodes. The larger node on the left contains a green 'Service Client' element, while the smaller node on the right contains an orange 'Service Server' element. Between them is a central box labeled 'Service' containing two purple sub-boxes: 'Request' and 'Response'. Curved arrows connect the Service Client to the Request box and the Service Server to the Request box (indicating the client sends a request to the server), and similarly connect the Response box back from the server to the client (indicating the server sends a response back). This illustrates the synchronous request-response pattern of ROS2 service communication, where a client node sends a request through a service interface and receives a response from the server node.
