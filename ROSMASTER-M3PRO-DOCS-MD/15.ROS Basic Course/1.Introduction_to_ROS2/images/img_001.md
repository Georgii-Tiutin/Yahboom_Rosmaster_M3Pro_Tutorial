## Caption
Comparison of ROS1 and ROS2 software architecture layers, highlighting the shift from TCPROS/UDPROS middleware to an abstract DDS layer in ROS2.

## Description
The diagram presents a side-by-side architectural comparison of ROS1 (left) and ROS2 (right), organized into three horizontal layers:

1. **Application Layer** (top): ROS1 shows a centralized Master node with Application nodes connected to it. ROS2 shows multiple independent Application nodes without a central master, reflecting its decentralized discovery architecture.

2. **Middleware Layer** (middle): ROS1 uses a Client Library communicating over TCPROS/UDPROS protocols with a Nodelets mechanism. ROS2 replaces this with a Client Library sitting atop an Abstract DDS Layer, with DDS (Data Distribution Service) as the underlying middleware and an Intra-process API for efficient same-process communication.

3. **OS Layer** (bottom): ROS1 supports only Linux, while ROS2 supports Linux, Windows, Mac, and RTOS, showing its cross-platform capability.

The ROS1 section is outlined with a dark border while the ROS2 section is highlighted with an orange/yellow header, emphasizing ROS2 as the focus. This diagram serves as an introductory overview in the ROS2 tutorial to explain why and how ROS2 differs from its predecessor.
