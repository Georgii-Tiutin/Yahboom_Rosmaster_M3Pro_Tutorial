## Caption
Diagram illustrating the three key components of a URDF robot link: the visual geometry (rendered shape), collision geometry (simplified bounding shape), and the coordinate frame (origin/axes).

## Description
The image shows a 3D rendering of a simple quadruped robot-like figure (blue body with orange legs) used to explain URDF link properties in ROS2. Three components are labeled with arrows:

1. **frame** — indicated by black coordinate axes (arrows) at the front-left of the model, representing the link's local coordinate frame (origin and orientation).
2. **visual geometry** — the solid blue 3D shape of the robot body and legs, representing the rendered appearance of the link in visualization tools like RViz.
3. **collision geometry** — shown as a green dashed bounding box surrounding the visual geometry, representing the simplified shape used for physics collision detection.

This diagram is a foundational concept in URDF (Unified Robot Description Format) modeling, teaching that each link in a robot model has separate definitions for its appearance (visual), its collision boundary (collision), and its reference frame (origin). The visual makes the robot look realistic, while the collision geometry is typically a simpler shape (box, cylinder, sphere) used for efficient collision checking in simulation.
