## Caption
Two terminal windows demonstrating ROS2 distributed communication with a talker node publishing messages and a listener node receiving them on separate machines.

## Description
The image shows two side-by-side terminal windows illustrating ROS2 distributed pub/sub communication. The left terminal (titled 'r@rr-pc' with a dark background) runs 'ros2 run demo_nodes_py talker', which continuously publishes 'Hello World' messages with incrementing counters (e.g., 'Hello World: 0', 'Hello World: 1', etc.). The right terminal (titled 'root@ubuntu' with a dark background and red/pink right border) runs 'ros2 run demo_nodes_py listener', which receives and logs the same messages (e.g., 'I heard: [Hello World: 0]'). Each log line includes an INFO-level timestamp. This demonstrates ROS2's built-in DDS-based distributed communication, where a publisher on one machine (rr-pc) can seamlessly send topic messages to a subscriber on another machine (ubuntu) without additional configuration, a key feature of ROS2's decentralized architecture covered in the distributed communication tutorial.
