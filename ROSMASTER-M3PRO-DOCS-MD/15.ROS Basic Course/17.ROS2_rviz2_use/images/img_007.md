## Caption
RViz2 'Create visualization' dialog showing available display types that can be added to the 3D visualization window.

## Description
The image shows the RViz2 'Create visualization' dialog box with two tabs: 'By display type' and 'By topic'. The 'By display type' tab is currently selected, displaying a scrollable list of available visualization plugins including PointStamped, Polygon, Pose, PoseArray, PoseWithCovariance, Range, RelativeHumidity, RobotModel, TF, Temperature, TwistStamped, and Wrench. Each item has a colored icon. Below the list are a 'Description' field and a 'Display Name' field for configuring the selected display type before adding it. At the bottom are 'Cancel' and 'OK' buttons. This dialog is used in ROS2 RViz2 to add new visualization displays for viewing robot sensor data, transforms, and models.
