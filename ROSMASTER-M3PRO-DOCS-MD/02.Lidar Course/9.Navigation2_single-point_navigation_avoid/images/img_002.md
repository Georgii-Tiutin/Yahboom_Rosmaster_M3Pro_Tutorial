## Caption
Terminal output showing ROS2 navigation errors where AMCL cannot publish pose and TF transforms from base_link to map are failing.

## Description
A Linux terminal window on a Jetson/Yahboom system showing multiple ROS2 error and warning messages during a Nav2 navigation session. The errors include: AMCL warning that it cannot publish a pose or update the transform and needs an initial pose set; repeated INFO messages from global_costmap timing out waiting for transform from base_link to map with 'Invalid frame ID map'; ERROR messages from transformPoseInTargetFrame indicating the 'map' frame does not exist; ERROR from global_costmap stating it cannot clear the map because robot pose cannot be retrieved; and similar warnings from local_costmap. These errors indicate the navigation stack was launched without proper localization initialization (no initial pose set in AMCL), causing TF frame failures throughout the Nav2 stack. This is a common troubleshooting scenario in the single-point navigation tutorial.
