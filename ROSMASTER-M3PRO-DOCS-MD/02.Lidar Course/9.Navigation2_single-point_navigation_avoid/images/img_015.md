## Description
The diagram illustrates the ROS2 TF (transform) relationship between two coordinate frames used in robot navigation. On the left is a blue rectangle labeled '/odom_frame' (the odometry frame), and on the right is a blue rectangle labeled '/base_frame' (the robot's base frame). A bold black arrow points from /base_frame to /odom_frame, labeled 'Translation' and 'Orientation', indicating that the transform between these two frames provides the robot's position and heading. Above the arrow, the text 'Dead Reckoning' with a downward-pointing arrow indicates that this transform is computed via dead reckoning (integrating wheel encoder data over time). This is a fundamental concept in ROS2 navigation: the odometry frame serves as a local reference, and the base frame represents the robot's current pose estimated through dead reckoning, which accumulates drift over time.
