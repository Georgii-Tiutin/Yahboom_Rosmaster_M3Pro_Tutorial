## Caption
RViz2 interface showing a 2D occupancy grid map with the Navigation2 panel ready for single-point navigation and obstacle avoidance.

## Description
The image shows the RViz2 visualization tool used in ROS2. On the left side is the Displays panel listing various visualization plugins including Global Options, Grid, TF, LaserScan, BumperHit, Map, AMCL Particle Swarm, Global Planner, Controller, Realsense, and MarkerArray. The toolbar at the top includes buttons for 2D Pose Estimate, Publish Point, and Nav2 Goal. The main viewport displays a 2D occupancy grid map of an indoor environment rendered in white (free space), black (obstacles/walls), and gray (unknown areas), with the robot's surroundings clearly mapped. At the bottom left is the Navigation 2 panel showing status fields (Navigation, Localization, Feedback all showing 'unknown'), along with metrics for poses remaining, ETA, distance remaining, time taken, and recoveries — all at zero, indicating navigation has not yet been initiated. This screenshot demonstrates the initial RViz2 setup before sending a navigation goal for the single-point navigation with obstacle avoidance tutorial.
