## Caption
ROS2 Navigation2 costmap inflation layer diagram showing how cell costs decay with distance from obstacles, defining lethal, inscribed, circumscribed, and freespace cost zones.

## Description
The image is a technical diagram illustrating the costmap inflation cost function used in ROS2 Navigation2. It shows a stepped/decaying cost curve plotted against distance from an obstacle. The vertical axis represents cell cost (int) and the horizontal axis represents distance from the obstacle center.

Key zones are labeled from highest to lowest cost:
- 'Lethal' or 'W-space' obstacle (cost_lethal=254): The region definitely in collision with the obstacle.
- 'Inscribed' or 'C-space' obstacle (cost_inscribed=253): The region where the robot is possibly in collision.
- 'Circumscribed' obstacle (cost_possibly_circumscribed=128): The region where collision depends on robot orientation.
- A discretized cost decay function curve shows costs decreasing from the circumscribed boundary outward, representing the zone where the robot is definitely not in collision but where user cost preferences can be expressed.
- Freespace (cost=1): The lowest non-freespace cost at the bottom.

The diagram includes colored concentric regions around a central obstacle point, with red indicating lethal zones, blue for inscribed, and progressively lighter shading for the decay region. Annotations on the right side describe the meaning of each cost range. A buffer zone created by the inflation layer is shown, illustrating how Nav2 creates a safety margin around obstacles. The bottom includes a source URL reference. This diagram is fundamental to understanding how the Nav2 costmap inflation layer works for path planning and obstacle avoidance.
