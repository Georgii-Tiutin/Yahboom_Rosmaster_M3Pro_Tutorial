## Caption
RViz2 interface showing an in-progress SLAM Toolbox map being built with LiDAR scan data and robot model visualization.

## Description
The image shows the RViz2 visualization tool used in ROS2 for monitoring a SLAM (Simultaneous Localization and Mapping) session using slam_toolbox. The left panel displays the RViz display tree with several active plugins: Global Options, Grid, RobotModel, TF, LaserScan, Bumper Hit, Map, Amcl Particle Swarm, Global Planner, Controller, Realsense, and MarkerArray. Below is the Navigation 2 panel showing navigation status fields (all currently unknown/zero), along with buttons for 2D Pose Estimate, Publish Point, and Nav2 Goal. The main viewport shows a partially constructed occupancy grid map (white areas represent explored free space, dark areas represent obstacles/walls) overlaid on a gray background grid. Red dots represent the current LiDAR laser scan points scattered around the robot's position. The map appears to be in an early stage of construction with the robot exploring its environment. This screenshot demonstrates the SLAM Toolbox mapping process as part of the LiDAR SLAM tutorial for the Yahboom ROSMASTER M3 Pro robot.
