## Caption
ROS2 rqt_graph node/topic diagram for Cartographer SLAM mapping on the ROSMASTER M3 Pro, showing how keyboard teleop, the base driver, lidar scans, IMU, EKF, TF and Cartographer connect to produce /map.

## Description
An rqt_graph-style computation graph, left to right. Ellipses are nodes; rectangles are topics.

Left side: node /teleop_twist_keyboard -> topic /cmd_vel -> node /YB_Node.

/YB_Node publishes:
- /odom_raw -> /ekf_filter_node
- /imu/data_raw (inside the /imu group box with /imu/data) -> /imu_filter_madgwick_node -> /imu/data -> /ekf_filter_node
- /scan0 and /scan1 -> /laserscan_multi_merger

/ekf_filter_node -> /tf.
/imu_filter_madgwick_node -> /tf.

Lidar chain: /laserscan_multi_merger -> /scan_multi -> /laser_filter_node -> /scan -> /cartographer_node.

/cartographer_node -> /tf and -> /submap_list. /submap_list -> /cartographer_occupancy_grid_node -> /map.

Top right: /robot_state_publisher -> /tf. /robot_state_publisher -> /joint_states (via the arrow loop from /joint_states back to /robot_state_publisher). /joint_state_publisher -> /joint_states. /robot_state_publisher -> /robot_description -> /joint_state_publisher.

/tf feeds five listener nodes: /transform_listener_impl_5a9aab251880, /transform_listener_impl_aaab02cbc2e0, /transform_listener_impl_aaaae8faae00, /transform_listener_impl_aaaafc161e60, /transform_listener_impl_aaaadc1cc5b0.
