## Description
Screenshot of the RQt (Robot Qt) Topic Monitor tool running in a ROS2 environment during a Navigation2 multi-point navigation session. The window title shows 'Default - rqt' with a standard menu bar (File, Plugins, Running, Perspectives, Help). The Topic Monitor panel displays a tree-structured list of active ROS2 topics with their types, bandwidth, Hz, and value columns. Key topics visible include:
- /scan and /scan_multi (sensor_msgs/msg/LaserScan) — LiDAR scan data
- /set_pose (geometry_msgs/msg/PoseWithCovarianceStamped) — robot pose setting
- /tf (tf2_msgs/msg/TFMessage) — coordinate frame transforms
- /tf_static (tf2_msgs/msg/TFMessage) — static transforms
- /waypoints (visualization_msgs/msg/MarkerArray) — navigation waypoint markers, expanded to show a sequence of individual visualization_msgs/Marker entries

Most topics show 'not monitored' status in the Bandwidth/Hz/Value columns. The /waypoints topic is expanded to reveal its child markers, indicating the multi-point navigation waypoints being visualized. This screenshot demonstrates the ROS2 topic infrastructure used during Navigation2 multi-point navigation with obstacle avoidance.
