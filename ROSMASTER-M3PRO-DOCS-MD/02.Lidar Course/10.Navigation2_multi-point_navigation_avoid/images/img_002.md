RViz2 interface showing a Nav2 navigation setup with a 2D map, robot position, and a green navigation goal arrow for multi-point navigation.

## Description
The image shows the RViz2 visualization tool used with ROS2 Navigation2 (Nav2). On the left side, the Displays panel lists several visualization components: Global Options, Grid, RobotModel, TF, LaserScan, Bumper Hit, Map, AMCL Particle Swarm, Global Planner, Controller, Realsense, and MarkerArray. Below the displays panel is a Navigation 2 panel showing status fields (Navigation: unknown, Localization: unknown, Feedback: unknown, Poses remaining: 0, ETA: 0s, Distance remaining: 0.00 m, Time taken: 0s, Recoveries: 0) with a Reset button. The main viewport displays a 2D occupancy grid map of an indoor environment rendered in black (obstacles/walls) and white (free space), with gray representing unknown areas. A green arrow is visible on the map indicating a Nav2 Goal pose being set. The top toolbar shows buttons including 2D Pose Estimate, Publish Point, and Nav2 Goal. This screenshot demonstrates the initial RViz2 setup for configuring multi-point navigation with obstacle avoidance in the Nav2 framework.
