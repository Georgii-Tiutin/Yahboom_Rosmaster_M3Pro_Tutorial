## Description
Screenshot of RViz2 during SLAM Toolbox map loading/relocalization. The top toolbar shows: Interact, Move Camera, Select, Focus Camera, Measure, 2D Pose Estimate, 2D Goal Pose, Publish Point, plus/minus icons. The left Displays panel lists: Global Options, Global Status: Ok, Grid, LaserScan, Map, RobotModel, TF (partly hidden), and MarkerArray, all checked. The MarkerArray entry is outlined with a red rectangle to indicate it should be added/enabled. Buttons below: Add, Duplicate, Remove, Rename. The SlamToolboxPlugin panel contains: Create Map Tool; Interactive Mode (checked) and Accept New Scans (unchecked); buttons Clear Changes, Save Changes, Save Map, Serialize Map, Deserialize Map with a text field containing "/home/jetson/map/map"; radio buttons Start At Dock, Start At Pose Est. (selected), Start At Curr. Odom, Localize; fields X 2.05, Y -0.51, θ -0.02; Clear Measurement Queue; Merge Map Tool with Add Submap and Generate Map. The right 3D view shows a grey occupancy map with black obstacles, laser scan points, a small robot model near the center, and a graph of thick blue lines connecting many red spheres (SLAM pose graph nodes and constraints/loop closures).
