## Description
Screenshot of the OpenClaw Gateway Dashboard connection form, shown in the Webchat Interaction tutorial. It has the OpenClaw red mascot logo and the title "OpenClaw" with the subtitle "Gateway Dashboard". Fields from top to bottom: "WebSocket URL" = ws://192.168.10.138:18789; "Gateway Token" = yahboom, with an eye (show/hide) button. The Gateway Token field and its label are enclosed in a red rectangle to show where to enter the token. "Password (not stored)" has the placeholder "optional" and a hide-eye button. Below is a red "Connect" button. A pink error box reads: "unauthorized: gateway token missing (open the dashboard URL and paste the token in Control UI settings)". A "How to connect" section lists: 1. Start the gateway on your host machine: `openclaw gateway run`; 2. Get a tokenized dashboard URL: `openclaw dashboard --no-open`; 3. Paste the WebSocket URL and token above, or open the tokenized URL directly. A "Read the docs →" link is at the bottom. The tutorial uses it to show entering the token "yahboom" to authenticate the webchat connection to the gateway at the robot's IP.
