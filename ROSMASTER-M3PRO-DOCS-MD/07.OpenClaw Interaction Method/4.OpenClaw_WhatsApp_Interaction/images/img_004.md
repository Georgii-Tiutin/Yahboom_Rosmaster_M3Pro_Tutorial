## Description
Screenshot of the OpenClaw control dashboard (VERSION v2026.3.13) used in the WhatsApp interaction tutorial. The left sidebar lists sections: CHAT (Chat), CONTROL (Overview, Channels, Instances, Sessions, Usage, Cron Jobs), AGENT (Agents, Skills, Nodes), SETTINGS (Config, Communications, Appearance, Automation), plus Docs. The "Channels" menu item is highlighted with a red box. The breadcrumb reads "OpenClaw > Channels" and the page heading "Channels" (subtitle "Channels and settings.") is also boxed in red. The main panel is titled "WhatsApp – Link WhatsApp Web and monitor connection health." and shows status rows: Configured: Yes, Linked: Yes, Running: Yes, Connected: Yes, Last connect: 15m ago, Last message: n/a, Auth age: 4m. Buttons: Show QR (red, primary), Relink, Wait for scan, Logout, Refresh. Collapsible sections: Accounts, Ack Reaction, Actions. Below is an "Allow From" section with "1 item" badge and a "+ Add" button (red box). Item #1 has a trash icon and a text field containing "+85…" (a phone number with country code), also outlined in red. The image shows where to whitelist the WhatsApp phone number allowed to message the bot.
