Phone screenshot (status bar time 14:45) of a WhatsApp "Message yourself" chat, with the contact name blurred and marked "(You)". At the top, a partly visible earlier message contains a link ending in "www.baidu.com" and blurred text, timestamp 12:15. Below the "Today" divider are these messages:
1. User (14:44): "Open the Raspberry Pi website and go to Baidu."
