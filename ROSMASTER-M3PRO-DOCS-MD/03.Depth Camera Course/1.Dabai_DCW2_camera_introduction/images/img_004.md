## Caption
RViz2 interface showing how to add an Image display by selecting it from the 'Create visualization' dialog for the Dabai depth camera.

## Description
The screenshot shows the RViz2 visualization tool in ROS2 with a 'Create visualization' dialog box open in the center. The left panel displays the existing display tree including Global Options, Global Status (showing an Error for Fixed Frame), RobotModel, TF, Map, and two LaserScan displays. The dialog box is used to add a new display type, with 'By display type' tab selected. A red annotation arrow points to 'Camera' and 'Image' options in the display type list, with 'Image' highlighted. The Description section explains that 'The Image display creates a new rendering window with an image.' Fields for Display Name (set to 'Image') and Topic are visible. Red annotation boxes highlight the 'Image' selection and the display name field. The bottom status bar shows ROS Time. This screenshot guides users through adding an Image display in RViz2 to visualize the Dabai DCW2 depth camera feed.
