## Description
RViz2 window from the Visual Relocation Markers tutorial. Left column has three panels. Top "Image" panel: camera view showing orange and blue bins and a floor with an AprilTag (small black-and-white square marker) highlighted by a red rectangle. Middle "apriltag_recorder_panel": label "AprilTag ID:" with a text field with placeholder "Enter tag ID (e.g., 0, 1, 2...)", a "Save" button, and status text "Ready". Bottom "Displays" panel: Global Options with Fixed Frame = map, Background Color = 48; 48; 48, Frame Rate = 30; Global Status: Ok; items Grid (checked), RobotModel (checked), TF (checked), LaserScan (checked), Map (checked), MarkerArray (unchecked), Image (checked). Right: 3D view of an occupancy grid map (gray free space, black obstacles, dark gray unknown) with green laser scan points and the small robot model. A TF frame labeled "tag6" with colored axes appears beside the robot, highlighted by a red rectangle, showing the detected tag's pose on the map. Purpose: demonstrate that the tag was recognized and its frame appears, so its ID (e.g., 6) can be entered and saved as a relocation marker.
