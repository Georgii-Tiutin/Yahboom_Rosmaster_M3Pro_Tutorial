## Description
Screenshot of RViz2 during map building/editing for the sand table map. Top toolbar: Interact, Move Camera, Select, Focus Camera, Measure, 2D Pose Estimate, 2D Goal Pose, Publish Point. Left Displays panel lists: Global Options, Global Status: Ok, Grid, LaserScan, Map, RobotModel, TF (partly hidden), and MarkerArray. The MarkerArray row is checked and highlighted with a red rectangle. Buttons: Add, Duplicate, Remove, Rename. Below is the SlamToolboxPlugin panel: "Create Map Tool" with Interactive Mode (checked) and Accept New Scans (unchecked); buttons Clear Changes, Save Changes, Save Map, Serialize Map, Deserialize Map (text field containing /home/jetson/map/map). Radio options: Start At Dock, Start At Pose Est. (selected), Start At Curr. Odom, Localize. Pose fields: X 2.05, Y -0.51, θ -0.02. Button Clear Measurement Queue. "Merge Map Tool" section with Add Submap and Generate Map buttons. The 3D view on the right shows a grey occupancy grid map with black obstacle outlines, the robot model near the centre, laser scan points, and a SLAM pose graph drawn as red spheres (nodes) connected by thick blue lines (constraints). It illustrates enabling MarkerArray to visualize the pose graph and deserializing a saved map from /home/jetson/map/map.
