RQt Parameter Reconfigure window showing angular velocity calibration parameters for the robot's odometry.

## Description
Screenshot of the RQt dynamic reconfigure GUI (rqt_reconfigure__Param) used for angular velocity calibration of the ROSMASTER M3 Pro robot. The left panel shows a tree of available nodes including calibrate_angular, ekf_filter_node, imu_filter, and rqt_gui_py_node_95743, with calibrate_angular selected. The right panel displays the /calibrate_angular parameters: use_sim_time (unchecked), rate (20.0), test_angle (360.0 degrees), speed (2.0), tolerance (0.17), odom_angular_scale_correction (0.75), start_test (unchecked checkbox to trigger the test), direction (1.0), base_frame (base_footprint), and odom_frame (odom). These parameters allow the user to configure and run an angular velocity calibration test to correct odometry drift during rotation.
