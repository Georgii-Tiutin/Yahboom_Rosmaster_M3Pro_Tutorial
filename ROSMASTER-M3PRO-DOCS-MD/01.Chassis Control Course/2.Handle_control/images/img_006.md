Flowchart showing the decision logic for handle (gamepad) control of robotic arm joints, navigation cancellation, and RGB/buzzer control.

## Description
This is a continuation of a flowchart from a robotics tutorial on handle (gamepad) control. The flow proceeds through several decision diamonds and process blocks:

1. A decision diamond at the top (partially cut off) leads to a 'Yes' branch that calls the 'pub_armjoint' function (调用pub_armjoint函数) to publish arm joint commands.
2. This is followed by starting a thread to call the 'arm_ctrl' function (启动线程调用arm_ctrl函数).
3. The 'No' branch from the first decision bypasses these arm control steps.
4. Both paths converge at the next decision diamond: 'Need to cancel navigation?' (是否需要取消导航?).
5. If 'Yes', the flow calls the 'cancel_nav' function (调用cancel_nav函数) to cancel navigation.
6. If 'No', it bypasses cancellation.
7. Both paths then converge at a final decision diamond (partially cut off at bottom): 'Control RGB lights or buzzer?' (是否需要控制RGB灯或蜂鸣器?).

The flowchart uses purple/lavender diamond shapes for decisions and rounded rectangles for process steps, with bilingual labels in Chinese and English. It illustrates the sequential decision-making logic in the handle control callback for the ROSMASTER M3 Pro robot.
