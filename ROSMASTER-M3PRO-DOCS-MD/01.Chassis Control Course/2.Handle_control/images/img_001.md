## Description
A screenshot of a Linux terminal on a Jetson (yahboom) system. The user has executed 'ls /dev/input' to list available input devices. The output shows multiple event devices (event0 through event10), as well as 'by-id', 'by-path', and importantly 'js0' which is highlighted with a red rectangle. The 'js0' device represents a joystick/gamepad controller connected to the system. This step in the tutorial demonstrates how to verify that a handle (gamepad) controller is properly detected by the system before using it to control the robot.
