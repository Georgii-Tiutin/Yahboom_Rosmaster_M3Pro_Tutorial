## Description
This is a flowchart diagram illustrating the control logic for the robot's line patrol (automatic driving) mode. At the top is a diamond-shaped decision node labeled '跟踪状态? / Tracking Status?' which serves as the main conditional check. Two branches extend downward from this decision node: the left branch is labeled '线条跟踪 / Line Tracking' and leads to a rectangular process box '执行线条跟踪逻辑 / Execute Tracking Logic'; the right branch is labeled '避障 / Obstacle Avoidance' and leads to another rectangular process box '执行避障逻辑 / Execute Obstacle Avoidance'. Both branches converge at the bottom into a single rectangular process box labeled '发布速度指令 / Publish Velocity Command'. The flowchart uses bilingual labels (Chinese and English) throughout. This diagram explains how the robot's line-following system makes real-time decisions: if the tracking status indicates a clear line, it follows the line; if an obstacle is detected, it switches to obstacle avoidance logic. In either case, the result is a velocity command published to control the robot's movement.
