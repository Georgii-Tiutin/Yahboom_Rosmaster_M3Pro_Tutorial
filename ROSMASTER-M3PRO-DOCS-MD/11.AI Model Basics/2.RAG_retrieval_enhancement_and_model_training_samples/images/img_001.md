## Caption
Flow diagram of a RAG (retrieval-augmented generation) pipeline: user instructions retrieve vector fragments from a private knowledge base, which are spliced with a prompt and sent to an AI large model to produce answers.

## Description
Diagram explaining how RAG retrieval enhancement works. At top left, a user icon with a speech bubble "User instructions" is labeled "user". An arrow labeled "Retrieve related snippets" goes down from the user to a database cylinder labeled "Stored as a vector" and captioned "RAG Private Knowledge Base". From the database, an arrow runs right to a stacked set of cards labeled "Vector fragment". An arrow from these cards points up to a chevron sequence titled "Splicing text" (bold) with three chevrons: "prompt", "User instructions", "Vector fragment". The spliced text is passed by an arrow to an OpenAI-style logo labeled "AI Large Model", which then outputs via an arrow to a rectangle box "Answers based on the RAG knowledge base". The diagram shows that the user's query is used to fetch relevant vectorized snippets, which are concatenated with the prompt and user instructions before being fed to the large model.
