## Description
Diagram from the "Embodied intelligent robot system architecture" tutorial (page 3), with two horizontal flows, each: user -> Execution layer model -> robot.

Top row: An orange user icon has a speech bubble "User instructions". An arrow from the user to the black cube-shaped "Execution layer model" icon is labeled "User instructions are directly passed to the execution layer large model". A second arrow runs from the Execution layer model to a blue-and-white robot icon labeled "robot". Labels beneath the icons: "user", "Execution layer model", "robot".

Bottom row: The user icon has a speech bubble "End current task.......". An arrow goes from the user to the Execution layer model, then another arrow to the robot, labeled "Resets the conversation history and bot state and starts a new task cycle." Labels beneath: "user", "Execution layer model", "robot".

The diagram shows that in this architecture the execution layer model receives user instructions directly without an intermediate planning layer. An "end task" instruction clears the context and robot state to start a new task cycle.
