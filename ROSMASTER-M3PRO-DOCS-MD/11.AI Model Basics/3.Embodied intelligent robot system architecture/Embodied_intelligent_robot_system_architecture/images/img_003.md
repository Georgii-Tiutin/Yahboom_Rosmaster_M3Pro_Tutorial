## Caption
Flow diagram of the execution layer model sending an action list (get_current_pose) to the robot, with execution status and environment screen fed back to the model.

## Description
Diagram with three elements in a row. On the left is a black hexagonal cube logo labeled "Execution layer model". An arrow leads to the center rounded rectangle labeled "Action List", which contains the JSON text: {"action":["get_current_pose()"], "response":"I have memorized the current position"}. An arrow leads right to a blue cartoon robot icon labeled "robot". A feedback arrow runs from the robot up and back left to the execution layer model, labeled "Feedback action execution status and environment screen". It shows the closed loop of the execution layer in the embodied intelligent robot system architecture: the model outputs actions plus a response, the robot executes them, and status and camera/environment information returns to the model.
