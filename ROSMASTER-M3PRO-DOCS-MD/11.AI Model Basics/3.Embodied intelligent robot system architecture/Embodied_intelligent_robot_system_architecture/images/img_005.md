## Caption
Flow diagram showing how conversation history context is built up and passed between the user, decision-making layer model, execution layer model, and robot in the embodied intelligent robot architecture.

## Description
Diagram with four "Conversation history context" boxes connected by arrows, illustrating how the conversation history grows through the pipeline.

1. Top-left box: "Conversation history context" containing "Promot Tips" (sic), labeled "Initialization history". An arrow leads to the "user" icon (orange person outline) with a speech bubble "User instructions". The arrow continues to the "Decision-making layer model" (OpenAI-style logo).

2. Arrow labeled "Add user instructions and task steps to the conversation history" leads to the top-right box: "Conversation history context" with "Promot Tips", "User command: xxxxxxxxxx", "Disassembly quest steps 1. xxxxxxxxxxx 2. xxxxxxxxxxx". An arrow leads right to the "Execution layer model" (black cube logo).

3. From the Execution layer model, a downward arrow labeled "Add the content of the large model reply to the conversation history" leads to the bottom-left box: "Conversation history context" with "Promot Tips", "User command: xxxxxxxxxx", "Disassembly quest steps 1. xxxxxxxxxxx 2. xxxxxxxxxxx", and the JSON {"action":["get_current_pose()"], "response":"xxxxxxxxxx"}.

4. An arrow from that box leads to the "robot" icon, then an arrow labeled "Add bot feedback to conversation history" leads to the bottom-right box: "Conversation history context" with "Promot Tips", "User command: xxxxxxxxxx", "Disassembly quest steps 1. xxxxxxxxxxx 2. xxxxxxxxxxx", {"action":["get_current_pose()"], "response":"xxxxxxxxxx"}, "Robot feedback: Execution xxx completed", and a dotted line indicating continuation.

5. An arrow from the bottom-right box returns up to the Execution layer model, labeled "Each request to the execution layer large model sends the complete conversation history".

The diagram shows a loop where the complete accumulated history (prompt tips, user command, task steps, model actions/responses, robot feedback) is sent to the execution-layer LLM on every request.
