Left-to-right flow diagram. At the far left is an orange user icon labeled "user" with a speech bubble reading "Could you please get me a bottle of mineral water from the kitchen?". A final arrow leads to a rounded box labeled "Disassembly task steps". The box contains a numbered list: 1. Record your current location; 2. Navigate to the tea room; 3. Check the location of your bottle of mineral water; 4. Grab the bottle of mineral water; 5. Return to your starting location; 6. Place the bottle of mineral water. The diagram shows how the large model breaks a natural-language command into sub-tasks in the embodied intelligent robot system architecture.
