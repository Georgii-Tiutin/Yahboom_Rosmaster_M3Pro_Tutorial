## Caption
Flowchart of the embodied intelligent robot system's single task cycle, showing a decision-making level (large text generation model with RAG database) feeding an execution level (multimodal large model controlling the robot with feedback).

## Description
Block diagram enclosed in a thick dashed box labeled "Single task cycle". Left: "User instructions" box with an arrow into the "decision-making level" (dashed box). There, "Large text generation model" receives input from below from a "RAG Database" box containing "Robot motion function library" and "Training examples". The model outputs, labeled "Understanding instructions" and "Planning tasks", to stacked "Task steps (several subtasks)" boxes. An arrow leads from the task steps into the "Execution level" (dashed box) to the "Multimodal large model". This model receives input from below from a "prompt" box containing "Robot motion function library" and "Mapping". The Multimodal large model sends an arrow labeled "Generate action list and reply content" to the "robot" box. From the robot, a feedback arrow goes up and left to a box "Action execution status feedback, visual information feedback", which feeds back down into the Multimodal large model. Bottom caption in the execution level: "Dynamic feedback reasoning until the task steps are completed". The diagram shows an architecture where an LLM plans subtasks using RAG, and a multimodal model executes them with a closed feedback loop.
