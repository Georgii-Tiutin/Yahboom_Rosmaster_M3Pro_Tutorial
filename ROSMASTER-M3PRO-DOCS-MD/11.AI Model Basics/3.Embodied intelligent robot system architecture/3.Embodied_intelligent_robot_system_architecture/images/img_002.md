## Description
Left-to-right flow diagram from the embodied intelligent robot system architecture tutorial. At the far left, an orange user icon has a speech bubble reading "Could you please get me a bottle of mineral water from the kitchen?". The icon is labeled "user". An arrow leads to a blue robot icon labeled "robot". Another arrow leads to the OpenAI-style logo labeled "decision-making level Large Model". A final arrow leads to a rounded box labeled "Disassembly task steps". The box contains a numbered list: 1. Record your current location; 2. Navigate to the tea room; 3. Check the location of your bottle of mineral water; 4. Grab the bottle of mineral water; 5. Return to your starting location; 6. Place the bottle of mineral water. The diagram shows how the large model decomposes a natural-language instruction into sequential subtasks for the robot.
