## Caption
Flow diagram of a single task cycle in an embodied intelligent robot system, showing a decision-making level (large text generation model with RAG database) feeding an execution level (multimodal large model controlling the robot with feedback loop).

## Description
The diagram is enclosed in a thick dashed box labeled "Single task cycle". Inside are two thinner dashed boxes: "decision-making level" (left) and "Execution level" (right).

Left to right flow:
1. "User instructions" box (outside the dashed areas, on the left) -> arrow into "Large text generation model".
2. Decision-making level: "Large text generation model" receives input from below from a "RAG Database" box, which has three stacked rows: "RAG Database", "Robot motion function library", "Training examples". Between the model and the next box are the labels "Understanding instructions" and "Planning tasks". Output is "Task steps (several subtasks)" shown as a stack of cards.
3. Task steps -> arrow to "Multimodal large model" in the Execution level.
4. The Multimodal large model gets input from below from a "prompt" box with rows: "prompt", "Robot motion function library", "Mapping".
5. Multimodal large model -> arrow labeled "Generate action list and reply content" -> "robot" box on the right.
6. Feedback loop: from the robot, an arrow goes up and left to a box "Action execution status feedback, visual information feedback", then down into the Multimodal large model.
7. Bottom text in the Execution level: "Dynamic feedback reasoning until the task steps are completed".

The diagram illustrates the architecture where an LLM plans subtasks (with RAG) and a multimodal model executes them on the robot with closed-loop feedback.
