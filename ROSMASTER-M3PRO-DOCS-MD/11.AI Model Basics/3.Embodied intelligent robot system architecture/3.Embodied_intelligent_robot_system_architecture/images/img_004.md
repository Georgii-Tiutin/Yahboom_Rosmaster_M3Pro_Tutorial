## Caption
Two-panel diagram showing how user instructions flow directly to the execution layer model and robot, and how an "End current task" command resets the conversation and robot state.

## Description
Diagram with two horizontal flows, each with three nodes: user (orange person icon with speech bubble), Execution layer model (black cube logo), and robot (blue robot icon). Top flow: the user's speech bubble says "User instructions". An arrow from user to the execution layer model is labeled "User instructions are directly passed to the execution layer large model". A further arrow goes from the Execution layer model to the robot. Labels beneath: "user", "Execution layer model", "robot". Bottom flow: the user's speech bubble says "End current task.......". An arrow from user to Execution layer model, then an arrow from Execution layer model to robot labeled "Resets the conversation history and bot state and starts a new task cycle." Labels beneath: "user", "Execution layer model", "robot". The diagram, from the Embodied intelligent robot system architecture tutorial, illustrates the execution-layer-only mode: normal instructions pass straight through, and an end-task command resets the history and state to begin a new task cycle.
