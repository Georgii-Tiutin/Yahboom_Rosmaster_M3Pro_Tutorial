## Caption
Flow diagram showing how the conversation history context grows as the user, decision-making layer model, execution layer model, and robot exchange information in the embodied intelligent robot system.

## Description
Diagram of the conversation history context flow in the embodied intelligent robot architecture. Each "Conversation history context" box is a white rectangle, and the contents grow step by step.

1. Initialization history (top left box): "Conversation history context" with "Promot Tips" (spelled this way in the image). The label below it is "Initialization history".
2. An arrow leads to the "user" icon (orange outline person), with a speech bubble "User instructions".
3. An arrow leads from the user to the "Decision-making layer model" (OpenAI-style logo).
4. The arrow from the decision-making layer is labeled "Add user instructions and task steps to the conversation history". It leads to the second box (top right): "Conversation history context", "Promot Tips", "User command: xxxxxxxxxx", "Disassembly quest steps 1. xxxxxxxxxxx 2. xxxxxxxxxxx".
5. That box feeds the "Execution layer model" (black cube-like logo, top right).
6. An arrow from the execution layer model goes down and left. It is labeled "Add the content of the large model reply to the conversation history". It leads to the third box (bottom left): "Conversation history context", "Promot Tips", "User command: xxxxxxxxxx", "Disassembly quest steps 1. xxxxxxxxxxx 2. xxxxxxxxxxx", and the JSON {"action":["get_current_pose()"], "response":"xxxxxxxxxx"}.
7. An arrow leads to the "robot" icon (blue robot).
8. The arrow from the robot is labeled "Add bot feedback to conversation history". It leads to the fourth box (bottom middle): the same contents as the third box, plus "Robot feedback: Execution xxx completed" and a dotted line "-----------------------".
9. An arrow from the fourth box goes right, then up, and back into the Execution layer model. It is labeled "Each request to the execution layer large model sends the complete conversation history".

The diagram shows a loop: the execution layer model is called repeatedly. Each call sends the full accumulated history, which contains the prompt tips, user command, task steps, model action replies, and robot feedback.
