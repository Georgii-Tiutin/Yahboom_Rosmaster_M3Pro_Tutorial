Terminal session showing how to set and unlock the root user password on a Raspberry Pi, then switch to the root user with the su command.

## Description
The image shows a Raspberry Pi terminal window with a dark background and light text. The session demonstrates three sequential commands:
1. 'sudo passwd root' — prompts the user to enter and retype a new UNIX password for root, confirming 'password updated successfully'.
2. 'sudo passwd --unlock root' — unlocks the root account, displaying 'password expiry information changed'.
3. 'su' — switches to the root user after entering the password, changing the prompt from 'pi@raspberrypi:~' to 'root@raspberrypi:/home/pi#'.
The green cursor block is visible at the end of the root prompt, indicating the user is now logged in as root. This is part of a tutorial on setting the root user password on a Raspberry Pi running Linux.
