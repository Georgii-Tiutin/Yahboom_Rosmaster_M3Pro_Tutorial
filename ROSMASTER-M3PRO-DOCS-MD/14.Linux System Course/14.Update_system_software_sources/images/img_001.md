## Caption
Editing the APT sources list file in nano to replace default Raspberry Pi repositories with Aliyun mirror sources.

## Description
The image shows a terminal window with the GNU nano 3.2 text editor open, editing the file /etc/apt/sources.list (marked as Modified in the top bar). The file contains APT package repository configuration lines for a Raspberry Pi running Debian Buster. The original default Raspberry Pi repository lines (deb http://raspbian.raspberrypi.org/raspbian/ buster main contrib non-free rpi) are commented out with # symbols (shown in green/cyan highlighting). Below them, new active lines point to the Aliyun mirror (deb http://mirrors.aliyun.com/raspbian/raspbian/ buster main contrib non-free rpi) for both binary (deb) and source (deb-src) packages. This demonstrates the process of updating system software sources to use a faster Chinese mirror server, which is a common step for improving package download speeds in China.
