## Description
Screenshot of the Dify web UI in the "yahboom's Workspace" workspace. The top navigation bar has Explore, Studio, Knowledge and Tools. At the top right is a "Plugins" button, highlighted with a red box, next to the user avatar "Y". Below it, the Plugins page has two tabs: "Plugins" (count 2) and "Explore Marketplace", which is highlighted with a red box. The right side of the page has "Request a plugin", "Publish plugins" and "+ Install plugin" controls.

The marketplace banner reads "Empower your AI development" and "Discover Models, Tools, Data Sources, Triggers, Agent Strategies, Extensions and Bundles in Dify Marketplace". Below the banner are an "All Tags" dropdown and a "Search plugins" box. Under those is a category row: All, Models (highlighted with a red box), Tools, Data Sources, Triggers, Agent Strategies, Extensions and Bundles.

The page shows "104 results", sorted by "Most Popular". The model plugin cards, each labeled MODEL and published by langgenius unless noted, with install counts, are:
