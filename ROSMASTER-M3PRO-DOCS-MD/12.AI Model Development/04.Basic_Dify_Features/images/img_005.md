## Description
Screenshot of the Dify web UI Settings dialog, used to show how to add an API key for a model provider. The left sidebar is titled "Settings" and has a WORKSPACE section (Model Provider, Members, Data Source, API Extension) and a GENERAL section (Language). "Model Provider" is highlighted with a red box. The main panel is titled "Model Provider", with a Search box and a "System Model Settings" button at top right. Under "Models" is the TONGYI provider card with tags LLM, TEXT EMBEDDING, RERANK, SPEECH2TEXT, TTS, plus "Show Models >". It shows an "API KEY 1" badge with a green dot and a "Config" button, which is highlighted in red. A dropdown opened from Config lists "API Keys" with "✓ ● API KEY 1" and an "Add API Key" button, also highlighted in red. Below is a "To be configured" section with OpenRouter (tag LLM, "Setup" button, and the note "Set up api-key or add model to use" with "Add Model"). The "Install model providers" section follows, with a "Discover more in Dify Marketplace" link and provider cards: OpenAI (langgenius, 364,601), Anthropic (75,153), Amazon Bedrock (35,307), Azure OpenAI (68,686), Azure AI Studio (11,945), Cohere (17,260), Gemini (157,470) and Hugging Face Hub (29,280). The background on the left is blurred.
