## Description
Screenshot of the Dify web interface account settings page. The main area is titled "My Account" and shows a profile card with a blue circular avatar "Y", name "yahboom" and email "yahboom@163.com". Below are fields: "Name" with value "yahboom" and an "Edit" button; "Email" with value "yahboom@163.com" and a "Change" button; "Password" with the note "You can set a permanent password if you don't want to use temporary login codes" and a "Reset password" button; and "Account's data" ("The user data of your account.") with an expandable row "Show 3 apps". In the top right, the user avatar menu is expanded showing "yahboom" and "yahboom@163.com" plus a "Log out" item, which is outlined with a red rectangle to show where to click to log out of Dify (the tutorial step for logging out).
