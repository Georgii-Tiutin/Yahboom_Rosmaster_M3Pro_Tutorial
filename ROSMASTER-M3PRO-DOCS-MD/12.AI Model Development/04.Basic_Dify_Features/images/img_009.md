## Description
Screenshot of the Dify workflow editor with a model configuration popup open over the canvas. A "Preview" button appears at the top right, and partially visible node text ("structured_out...", "decision_OUT") is behind the popup.

MODEL section: dropdown showing "qwen-max" with a "CHAT" tag.

PARAMETERS section (each row has a toggle, a help icon, a slider and a value box):
- Temperature: toggle ON (blue), slider about 35%, value 0.7
- Max Tokens: toggle off, slider near max, value 8192
- Top P: toggle off, slider about 80%, value 0.8
- Top k: toggle off, slider at the left, value 0
- Random seed: toggle off, value 1234
- Repetition penalty: toggle off, value 1.1
- Web Search: toggle off, with True / False buttons, False selected

Only Temperature is enabled. The popup has a vertical scrollbar, so more parameters are below. The image shows how to choose the LLM model and tune its generation parameters in a Dify workflow node.
