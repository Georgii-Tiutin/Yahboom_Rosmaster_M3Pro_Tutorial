## Description
Screenshot of the Dify web UI (workspace "yahboom's Workspace"), Knowledge page, breadcrumb: 1 DATA SOURCE > STEP 2 DOCUMENT PROCESSING (active) > 3 EXECUTE & FINISH. Top nav: Explore, Studio, Knowledge (active), Tools, Plugins.

Left panel (settings):
- Delimiter: \n\n
- Maximum chunk length: 1024 characters
- Chunk overlap: 50 characters
- Text Pre-processing Rules: checked "Replace consecutive spaces, newlines and tabs"; unchecked "Delete all URLs and email addresses".
- Unchecked "Chunk using Q&A format in English".
- Buttons: "Preview Chunk" (highlighted with red box) and "Reset".
- Parent-child option: "When using the parent-child mode, the child-chunk is used for retrieval and the parent-chunk is used for recall as context."
- Index Method: "High Quality (RECOMMEND)" – calling the embedding model to process documents for more precise retrieval helps LLM generate high-quality answers; "Economical" (selected, highlighted with red box) – "Using 10 keywords per chunk for retrieval, no tokens are consumed at the expense of reduced retrieval accuracy."
- Retrieval Setting: "Inverted Index" – structure used for efficient retrieval, organized by terms, each term points to documents or web pages containing it. Top K = 3 (slider).

Right panel (highlighted with red box): PREVIEW of "Sample training for the de..." (Excel file icon), "16 ESTIMATED CHUNKS". Chunks in query/answer format:
- Chunk-1 (173 characters): query "Remove/take away the machine code with a height higher than x cm."; answer "1. Call the function to remove machine code of a specified height with the parameter x."
- Chunk-2 (190): query "Track object x."; answer "1. Observe the coordinates of object x in the current view. 2. Call the function to track the object with the parameter being the coordinates of object x."
- Chunk-3 (122): query "Sort/pick up/grasp machine code No. x."; answer "1. Call the function to sort machine code with the parameter x."
- Chunk-4 (185): query "Remove/take away n - colored squares with a height higher than x cm."; answer "1. Call the function to remove color blocks of a specified height with the parameters 'n' and x."
- Chunk-5 (115): query "Perform a dance and then tell a joke."; answer "1. Call the function for dance movements. 2. Tell a joke."
- Chunk-6 (293): query "Please go to Area A, Area D, and Area B in sequence and describe the scenes you see."; answer: navigate to Area A, observe and describe; Area D; Area B.
- Chunk-7 (599): query "Move n1 to Area A, and then move n2 from Area A back."; answer: record current position, call vision function to observe n1, pick up with robotic arm, navigate to Area A and put down, etc.
- Chunk-8 (537 characters) partially visible.

Purpose in tutorial: shows how to configure chunking and the Economical index method and preview the chunks when deploying a RAG knowledge base in Dify for the robot's LLM task-planning.
