## Description
Screenshot of the Dify web UI (Workspace "yahboom's Workspace", Knowledge tab active) on the "KNOWLEDGE" page, at STEP 2 DOCUMENT PROCESSING (steps: 1 DATA SOURCE, STEP 2 DOCUMENT PROCESSING, 3 EXECUTE & FINISH). Left panel, with red boxes highlighting key settings:
- Index Method: "High Quality" (RECOMMEND) selected – "Calling the embedding model to process documents for more precise retrieval helps LLM generate high-quality answers." Alternative: "Economical" – "Using 10 keywords per chunk for retrieval, no tokens are consumed at the expense of reduced retrieval accuracy." Warning: "Once finishing embedding in High Quality mode, reverting to Economical mode is not available."
- Embedding Model: "text-embedding-v1" (highlighted).
- Retrieval Setting: options Vector Search, Full-Text Search, and Hybrid Search (RECOMMEND), which is selected and highlighted. Under Hybrid Search there are two choices: "Weighted Score" and "Rerank Model" (selected). Rerank model dropdown: "gte-rerank". Top K = 3 (slider), Score Threshold toggle (off) = 0.5.
- Buttons at bottom: "← Previous step" and a highlighted blue "Save & Process".
Right panel: PREVIEW of "Sample training for the de..." with "16 ESTIMATED CHUNKS". Chunks (Chunk-1 to Chunk-9) contain query/answer pairs for robot function-calling, e.g. Chunk-1 (173 characters): query "Remove/take away the machine code with a height higher than x cm." answer "1. Call the function to remove machine code of a specified height with the parameter x."; Chunk-2: "Track object x."; Chunk-3: "Sort/pick up/grasp machine code No. x."; Chunk-4: remove n colored squares higher than x cm; Chunk-5: "Perform a dance and then tell a joke."; Chunk-6: go to Area A, Area D, Area B and describe scenes; Chunk-7: move n1 to Area A then n2 from Area A back; Chunk-8: move the x-colored square in front of you to Area A then return to the starting position. The image is used in the tutorial for deploying a RAG knowledge base: choose High Quality, text-embedding-v1, Hybrid Search with Rerank Model gte-rerank, Top K 3, then click Save & Process.
