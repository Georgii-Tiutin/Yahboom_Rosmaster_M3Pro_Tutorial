## Description
Screenshot of the Alibaba Cloud Model Studio website (International Edition), used in the "Register a model service account" tutorial. The top navigation bar shows the "Alibaba Cloud Model Studio" logo, with tabs "Dashboard", "Docs" (active) and "API References". At top right are "International Edition" and icons. The left sidebar lists: Get started, Product introduction, Make your first API call to Qwen, Models (selected), Model pricing, Rate limits, Text generation, Overview of text generation models, Multi-turn conversations, Streaming, Deep thinking, Structured output, Partial mode, Context cache, Tool calling, Specialized models, Multimodal models, Visual understanding, Visual reasoning, Text extraction. The main page is "Models" with a "Model Comparison" button at top right. Behind it, a greyed model list shows entries like Qwen-MT-Plus, Qwen-Plus-Latest, Qwen-Plus-Character-Japanese, Qwen3-Max-2025-09-23, Qwen3-Coder-Plus-2025-09-23, Qwen-Plus-2025-09-11.

A modal dialog titled "Terms of Service" is in the foreground. It contains a scrollable text box with the heading "Alibaba Cloud International Website Product Terms of Service", "Updated at: 2024-06-26 11:27", an introduction paragraph stating that these Product Terms describe the general and specific terms and conditions applicable to purchase and use of products and services offered through the website www.alibabacloud.com (the "Alibaba Cloud Platform"), and a section heading "1. Application and Acceptance of the Product Terms". At the bottom of the dialog are two buttons: a purple "Agree" button, highlighted with a red rectangle to show the user should click it, and a "Reject" button. The step shows accepting the terms of service when first activating the Model Studio service.
