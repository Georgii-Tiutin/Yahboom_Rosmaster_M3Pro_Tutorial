## Description
Two stacked screenshots from the Alibaba Cloud Model Studio (Qwen) console, used in the "Register a model service account" tutorial.

Top screenshot: the "Models" page. The left sidebar lists: Get started, Product introduction, Make your first API call to Qwen, Models (highlighted with a red box), Model pricing, Rate limits, Text generation, Overview of text generation models, Multi-turn conversations, Streaming, Deep thinking, Structured output, Partial mode, Context cache, Tool calling, Specialized models, Multimodal models, Visual understanding, Visual reasoning. The main area shows three banner cards at the top ("Most powerful general-purpose LLM", "Latest-generation text-to-video model", "Latest-generation e2e speech recogniti..."). Under the heading "Flagship – Versatile, high-intelligence flagship models with advanced multilingual capabilities" is a two-column list of models: Qwen3-Max, Qwen3-Max-Preview, Qwen3-Coder-Plus, Qwen-Plus (highlighted with a red box; "Qwen-Plus is an enhanced version of the Qwen ultra-large language model t..."), Qwen-MT-Plus, Qwen-Plus-Latest, Qwen-Plus-Character-Japanese, Qwen3-Max-2025-09-23, Qwen3-Coder-Plus-2025-09-23, Qwen-Plus-2025-09-11, Qwen-Plus-2025-07-28, Qwen3-Coder-Plus-2025-07-22, Qwen-Plus-2025-07-14, Qwen-Plus-2025-04-28, Qwen3-Next-80B-A3B-Instruct, Qwen3-Next-80B-A3B-Thinking.

Bottom screenshot: the Qwen-Plus model detail page (breadcrumb "Models / Qwen-Plus", with a "View API Reference" button). A summary card shows Price "$0.4 · $1.2" (Input · Output), Input: Text, Output: Text. "Model Information": Qwen-Plus, Provider: Alibaba Cloud. Overview: Qwen-Plus is an enhanced version of the Qwen ultra-large language model that supports multiple input languages such as Chinese and English, with improvements in code generation, logical reasoning, multilingual abilities, human-preference alignment, creative writing, JSON formatting adherence and role-playing. Price per 1M tokens: Input $0.4, Output $1.2. "Free quota" bar shows "2% Remaining" with the value "24,098 / 1,000,000" highlighted in an orange box.

Purpose: shows how to navigate to Models, select Qwen-Plus, and check its pricing and remaining free token quota (24,098 of 1,000,000 tokens).
