## Description
Screenshot of a modal popup from an OpenRouter-style API key creation page, used in the "Register a model service account" tutorial (page 8). Title text: "Your new key:". Below is a grey text field containing the key beginning "sk-or-v1-" followed by pixelated/blurred characters to hide the secret. A horizontal scrollbar sits under the field. To the right of the field is a clipboard "copy" icon, highlighted with a red rectangle and a red arrow pointing at it from the lower right, indicating the user should click it to copy the key. Below the field: "Please copy it now and write it down somewhere safe. **You will not be able to see it again.**" (bold second sentence). Then: "You can use it with OpenAI-compatible apps, or your own code" where "your own code" is a blue/purple link. A close (X) icon is in the top-right corner of the dialog. The purpose is to instruct users to copy and save the API key immediately since it is shown only once.
