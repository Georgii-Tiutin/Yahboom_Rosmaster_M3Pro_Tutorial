## Description
Screenshot of the Alibaba Cloud Model Studio console (International Edition), Key Management page, from the tutorial "Register a model service account" (page 4). Top navigation: Dashboard, Docs, API References; at the top right: International Edition, icons, and a user avatar. The left sidebar lists Permissions and Key Management (selected), with Default Workspace at the bottom. The main panel is titled "Key Management" with an "API-Key" tab. The center shows an empty-state icon with the text "No API Key" and "To call models or applications, create an API key". A purple "Create API Key" button is highlighted with a red rectangle and a red arrow pointing to it. This is the button the user must click to create a key. Below is a gray three-step panel: "1 Create API Key" (Click Create API Key to create one and copy it; keep the key secured), "2 Documentation" (At the top of the page, click API References to view detailed API documentation), "3 Get Started" (Use the API key you just created to access models or applications from Model Studio based on the documentation).
