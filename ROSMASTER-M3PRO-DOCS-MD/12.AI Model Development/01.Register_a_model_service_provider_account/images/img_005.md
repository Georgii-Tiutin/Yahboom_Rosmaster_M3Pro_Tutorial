Alibaba Cloud Model Studio "Create an API key" documentation page, with annotations showing where to open the Key Management page (Singapore link) and where to create and copy an API key.

## Description
Screenshot of the Alibaba Cloud Model Studio docs. The top nav has tabs "Dashboard", "Docs" and "API References"; "API References" is boxed in red. The left sidebar lists: Preparations, Create an API key (highlighted), Export API key as an environment variable, Install the SDK, Chat, Qwen, Image generation, Qwen - text-to-image, Qwen - image editing, Wan - text-to-image V2, Wan - general image editing 2.5, FAQ, Video generation, Wan - image-to-video - first frame, Wan - image-to-video - first and last frames, Wan - text-to-video.

Main content, titled "Create an API key": "Before you use the models or applications in Alibaba Cloud Model Studio, first activate the service and create an API key for authentication."
Section "1. Activate the Model Studio service": use your Alibaba Cloud account to access Model Studio (Singapore or Beijing). If an activation prompt appears at the top of the page, activate the service. You are only charged for model calls that exceed your free quota. If no prompt appears, the service is already activated.
Section "2. Create an API key": an "Important" note says the operation requires an Alibaba Cloud account or a RAM user with `administrator` or `API-Key` page permissions. After activating Model Studio, you must manually create an API key, because the system does not generate one automatically.
Step 1: "Go to the Key Management (Singapore or Beijing) page. On the API-Key tab (① in the following figure), click Create API Key (② in the following figure)." A red box and red arrow highlight the "Singapore" link.
Embedded figure of the Key Management page: the "API-Key" tab is boxed in orange and marked 1, next to a "KMS Management" tab. A purple "+ Create API Key (6/20)" button is marked 2. The table columns are ID, API Key, Owner Account, Creation Time, Description, Actions. One row shows ID 1, API key "sk-e****2245" with a copy icon boxed and marked 3, creation time 2025-06-03 16:02:10, and Edit and Delete actions.
Step 2: "In the Create API Key dialog box, select an Owner Account and Workspace, enter a Description, and then click OK." The sub-bullet "Owner Account" says to select an Alibaba Cloud account or a RAM user, and that if an employee leaves or changes roles, you must remove their RAM user from the workspace.
In the tutorial, this page shows how to register a model service account and obtain an API key.
