## Description
Screenshot of the Dify "Create from Blank" dialog used to create a chatbot app. Left panel: heading "Create from Blank", then "Choose an App Type" with cards: Workflow ("Agentic flow for intelligent automations"), Chatflow ("Workflow enhanced for multi-turn chats"). Under "MORE BASIC APP TYPES" are three cards: Chatbot ("LLM-based chatbot with simple setup", selected and highlighted with a red box), Agent ("Intelligent agent with reasoning and autonomous tool use"), and Text Generator ("AI assistant for text generation tasks"). Below is "App Name & Icon" with the text field containing "chatbot" (red box) and a robot emoji icon at right. Then an optional "Description (Optional)" text area with placeholder "Enter the description of the app". At the bottom: "No ideas? Check out our templates →", a "Cancel" button, and a blue "Create" button with a keyboard shortcut hint (red box). Right panel: preview titled "CHATBOT – Quickly build an LLM-based chatbot with simple configuration. You can switch to Chatflow later. Learn more", showing a thumbnail of the Orchestrate screen with Instructions, Variables, Knowledge, Debug & Preview, and a Features panel (Conversation Opener, Speech to Text, File Upload, Content Moderation, Follow-up, Text to Speech, Citations and Attributions, Annotation Reply). The steps shown: select Chatbot, name the app "chatbot", click Create.
