## Description
Screenshot of the Dify web UI, in the "yahboom's Workspace" workspace. The top bar shows Explore, Studio, TEST_API, Knowledge and Tools, plus Plugins and a user avatar. The left sidebar is for app TEST_API (CHATBOT) and has Orchestrate (selected), API Access, Logs & Annotations and Monitoring. The main Orchestrate area has an INSTRUCTIONS box containing "You are a chat assistant" (character count 24) and a "Generate" button. Below it are Variables (+ Add), Knowledge (Retrieval Setting, + Add, "You can import Knowledge as context"), METADATA FILTERING (Disabled), and Vision (Settings toggle). The right side is the Debug & Preview panel with a "Talk to Bot" input and "Features Enabled / Manage". At top right the model selector shows "qwen-vl-max CHAT" and a Publish button. A red rectangle highlights the open model settings popup. It lists MODEL: qwen-vl-max, and PARAMETERS, each with a toggle: Temperature 0.3, Top P 0.8, Top k 0, Max Tokens 2000, Random seed 1234, Response Format (Please select), Repetition penalty 1.1. At the bottom is a "Debug as Multiple Models" link. In the tutorial (Configuring API-KEY), this step shows how to choose the model (qwen-vl-max) and set its parameters in Dify.
