## Description
Screenshot of the Dify web UI "Settings" dialog, used in the "Configuring API-KEY" tutorial. The left sidebar lists WORKSPACE: Model Provider (highlighted with a red box, currently selected), Members, Data Source, API Extension; and GENERAL: Language. The right panel is titled "Model Provider" with a Search box at top and a "System Model Settings" button. Under "Models" a notice reads "Model provider not set up. Please install a model provider first." Under "To be configured" two providers are listed: TONGYI (tags: LLM, TEXT EMBEDDING, RERANK, SPEECH2TEXT, TTS) with status "Unauthorized" (red dot) and a "Setup" button highlighted with a red box, and OpenRouter (tag: LLM) also "Unauthorized" with a "Setup" button. Each provider card has the hint "Set up api-key or add model to use" and an "Add Model" button. Below is an "Install model providers" section with "Discover more in Dify Marketplace". An ESC close button is at the top right. The red boxes indicate the steps: open Model Provider, then click Setup on TONGYI to enter the API key.
