## Description
Screenshot of the Dify "Create from Blank" dialog, from the tutorial "RAG knowledge base + chatbot" (page 2). Under "Choose an App Type" the top row has Workflow ("Agentic flow for intelligent automations") and Chatflow ("Workflow enhanced for multi-turn chats"). Under "MORE BASIC APP TYPES" are three cards: Chatbot ("LLM-based chatbot with simple setup"), Agent ("Intelligent agent with reasoning and autonomous tool use") and Text Generator ("AI assistant for text generation tasks"). The Chatbot card is selected and has a red box around it. Below that, the "App Name & Icon" field contains "RAG knowledge base + chatbot", with a robot icon to its right. This field is also boxed in red. The "Description (Optional)" text area shows the placeholder "Enter the description of the app". At the bottom are "No ideas? Check out our templates →", a "Cancel" button, and a blue "Create" button with a keyboard shortcut hint. The Create button has a red box around it. On the right, a preview panel is headed "CHATBOT" and reads "Quickly build an LLM-based chatbot with... You can switch to Chatflow later." It shows an Orchestrate mock-up with Instructions, Variables (expert_name, unrelated_topic), Knowledge (Marketing Basics, Brand Strategy, Market Research Guide) and Vision. The steps are to select Chatbot, enter the app name "RAG knowledge base + chatbot", and click Create.
