## Caption
Workflow diagram of an AI agent that uses a Question Classifier to route user questions to different LLM nodes or a fixed direct reply.

## Description
Node-based workflow canvas (Dify-style) flowing left to right. START node connects to a QUESTION CLASSIFIER node that uses model "qwen3-4b" (CHAT). Its description text reads "对问题进行分类" (classify the question). The classifier has three outputs: CLASS 1 "Mathematical problems", CLASS 2 "Physics problems", CLASS 3 "Other questions".

Routing:
- CLASS 1 -> LLM-1 (model qwen3-8b, CHAT) -> REPLY DIRECTLY node with ANSWER set to variable "LLM-1 {x} text".
- CLASS 2 -> LLM -2 (model qwen3-1.7b, CHAT) -> REPLY DIRECTLY node with ANSWER set to variable "LLM -2 {x} text".
- CLASS 3 -> REPLY DIRECTLY node with ANSWER fixed text "Sorry, I can't answer these questions."

The diagram shows how to build a multi-branch agent workflow where different-sized Qwen3 models handle math and physics questions, and other questions get a canned refusal.
