## Description
Screenshot of a visual workflow editor (Dify-style) on a dotted canvas. Left to right: a START node (green check) connects to a QUESTION CLASSIFIER node using model qwen3-8b (CHAT). The classifier lists three classes: CLASS 1 "Mathematical problems", CLASS 2 "Physics problems", CLASS 3 "Other questions", and a Chinese instruction text "对问题进行分类" (classify the question). Three outputs branch from the classifier: Class 1 goes to LLM-1 (qwen3-8b, CHAT) which connects to a REPLY DIRECTLY node with ANSWER "LLM-1 {x} text"; Class 2 (highlighted green active path) goes to LLM -2 (qwen3-1.7b, CHAT) which connects to a REPLY DIRECTLY node with ANSWER "LLM -2 {x} text"; Class 3 goes to a REPLY DIRECTLY node with ANSWER "Sorry, I can't answer these questions." Red rectangles highlight the START node, QUESTION CLASSIFIER node, LLM -2 node and its REPLY DIRECTLY node, showing the executed path for a physics question. Inactive nodes (LLM-1, its reply, the Class 3 reply) are greyed out.
