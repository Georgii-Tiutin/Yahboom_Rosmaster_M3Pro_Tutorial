## Description
Screenshot of the Yahboom 'RosRobot' mobile application used for controlling the ROSMASTER robot. The interface has several key sections:

- Left sidebar (blue background with Yahboom logo): Shows a WebSocket connection field with the address 'ws://192.168.2.5x' and a green 'Connected' status indicator. Below are two menu items: 'Mapping' and 'Navigation', each with home icons.

- Center 'Operate' panel: Displays a 2D occupancy grid map generated by SLAM (Simultaneous Localization and Mapping). The map shows walls and obstacles as black lines, unknown areas in white, and red/colored points indicating LiDAR scan data or navigation waypoints. Two action buttons are visible at the top: 'init point' (green) for setting the robot's initial pose and 'nav points' (orange/red) for setting navigation goal points.

- Right sidebar: Contains a 'Video' section showing a live camera feed thumbnail from the robot's onboard camera, and a 'Robot Control' section below it for manual movement commands.

This screenshot demonstrates the app-based mapping and navigation workflow, where users connect to the robot via WebSocket, visualize the SLAM map in real time, and set navigation goals through the mobile interface.
