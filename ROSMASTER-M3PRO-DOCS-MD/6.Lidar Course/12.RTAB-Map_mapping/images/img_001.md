## Caption
RViz displaying a 3D RTAB-Map point cloud map generated from an RGBD camera on the ROSMASTER M3 Pro robot.

## Description
The screenshot shows the RViz visualization tool running the RTAB-Map RGBD configuration (/opt/ros/humble/share/rtabmap_launch/launch/config/rgbd.rviz). The left panel displays the Displays sidebar with Global Options (Fixed Frame set to 'map', Frame Rate 30), and enabled display plugins including Grid, Info, and MapCloud. The MapCloud plugin is configured with Topic '/rtabmap/mapData', Style 'Points', Size 3 pixels, Alpha 1, Position Transform XYZ, and Color Transformer RGB8. The main 3D viewport on the right shows a colorful RGB point cloud of an indoor environment being reconstructed in real-time by RTAB-Map, with the robot's coordinate frame axes (red/green/blue) visible at the origin. The point cloud shows walls, furniture, and structural features captured by the depth camera. The toolbar at the top includes standard RViz interaction tools such as Move Camera, Select, Focus Camera, Measure, 2D Pose Estimate, 2D Goal Pose, and Publish Point. This demonstrates the RTAB-Map SLAM mapping process covered in the tutorial.
