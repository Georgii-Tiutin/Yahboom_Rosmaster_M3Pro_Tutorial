## Caption
RViz visualization of an RTAB-Map RGBD 3D point cloud map being built in real-time using a depth camera on the ROSMASTER M3 Pro robot.

## Description
The image shows the RViz (Robot Visualization) tool running with the RTAB-Map RGBD launch configuration (/opt/ros/humble/share/rtabmap_launch/launch/config/rgbd.rviz). On the left side is the Displays panel showing configuration options: Fixed Frame set to 'map', Background Color as dark gray (48,48,48), Frame Rate at 30fps, and a MapCloud display with topic /rtabmap/mapData. The point cloud settings show Style as Squares, Size 0.05, Position Transformer XYZ, Color Transformer RGB8, Cloud from scan, Cloud decimation 4, Cloud max depth 4, Cloud min depth 0, and Cloud voxel size 0.01. The main 3D viewport on the right displays a partially built 3D point cloud map showing what appears to be an indoor environment with a wall or large surface rendered as a colored point cloud. The robot's coordinate frame axes (red/green/blue for X/Y/Z) are visible in the scene, along with a grid floor. This demonstrates the RTAB-Map SLAM process creating a 3D reconstruction from the robot's depth camera data.
