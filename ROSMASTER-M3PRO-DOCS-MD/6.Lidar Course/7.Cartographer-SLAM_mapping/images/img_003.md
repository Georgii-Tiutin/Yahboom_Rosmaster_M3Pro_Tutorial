## Description
The image shows the RViz2 visualization tool interface during a Cartographer SLAM mapping session. The main viewport displays a 2D occupancy grid map being built in real-time, with white areas representing free/explored space, gray areas representing unknown space, and dark edges indicating detected walls and obstacles. Red dots from the LaserScan topic are visible, showing the current LiDAR scan data overlaid on the map.

On the left side panel, the Displays tree is visible with the following items configured:
- Global Options (Fixed Frame set to 'map', Background Color set to dark gray 48;48;48, Frame Rate 30)
- Global Status showing 'Ok'
- Grid display
- Map display (showing the occupancy grid)
- LaserScan display (showing real-time LiDAR points)

The top toolbar shows standard RViz2 controls including Interact, Move Camera, Select, Focus Camera, Measure, 2D Goal Pose, and Publish Point buttons. This screenshot demonstrates the result of running Cartographer SLAM on the ROSMASTER M3 Pro robot, where the robot has explored and mapped an indoor environment showing rooms, corridors, and wall structures.
