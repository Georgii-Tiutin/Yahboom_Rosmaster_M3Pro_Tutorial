## Description
This is a software architecture diagram titled 'cartographer整体代码框架图' (Cartographer Overall Code Framework Diagram). It illustrates the internal structure and data flow of Google's Cartographer SLAM library as used with ROS. The diagram is divided into two main sections:

1. **cartographer_ros** (left side): Shows ROS-specific nodes and components including sensor_bridge, map_builder_bridge, node (main entry point), and occupancy_grid_node. These handle ROS message conversion, sensor data bridging, and occupancy grid map publishing.

2. **cartographer** (right side): Shows the core SLAM library components including:
   - PoseExtrapolator (pose prediction/extrapolation)
   - Collator (sensor data collation and synchronization)
   - LocalTrajectoryBuilder3D/2D (local trajectory building with scan matching)
   - PoseGraph3D/2D (global pose graph optimization and loop closure)
   - CollatedTrajectoryBuilder and GlobalTrajectoryBuilder (trajectory management)
   - MapBuilder类 (MapBuilder class, the main entry point for the cartographer library)

Arrows indicate data flow between components, showing how sensor data flows from ROS through the bridge into the core SLAM pipeline, through local and global optimization stages. The diagram uses blue boxes and connecting lines on a white background, with Chinese annotations explaining the role of each component. This provides readers with a high-level understanding of Cartographer's software architecture before diving into SLAM mapping configuration.
