## Description
The image shows the RViz2 visualization tool during a ROS2 Navigation2 (Nav2) session. The main viewport displays a 2D occupancy grid map with colorful costmap overlays: the global costmap and local costmap are both visible, showing obstacle inflation zones in cyan, magenta, and pink gradients around detected walls and obstacles. The left panel shows the Displays tree with various visualization layers enabled, including Global Options, Grid, RobotModel, TF, LaserScan, Bumper Hit, Map, Amcl Particle Swarm, Global Planner (with Global Costmap, Downsampled Costmap, Path, VoxelGrid, Polygon), and Local Planner (with Local Costmap highlighted in a red box, Local Plan, Trajectories, Polygon, VoxelGrid, Realsense, MarkerArray). The bottom-left Navigation 2 panel shows the navigation status: Navigation is 'active', Localization is 'active', and Feedback shows 'reached', indicating the robot successfully arrived at its goal. ETA is 0s, Distance remaining is 0.0m, Time taken is 0s, and Recoveries is 0. The red box highlighting the Local Costmap section suggests this is being used to teach the reader about costmap visualization in the context of obstacle avoidance during navigation.
