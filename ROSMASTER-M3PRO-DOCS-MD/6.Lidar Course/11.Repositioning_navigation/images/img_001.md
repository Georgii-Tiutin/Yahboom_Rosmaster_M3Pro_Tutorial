## Caption
RViz2 navigation interface showing a robot's map with navigation waypoints set for repositioning navigation.

## Description
The screenshot shows the RViz2 visualization tool running on a Jetson system with the M3Pro navigation package. The main viewport displays a 2D occupancy grid map (grayscale) generated by SLAM, with the robot's position visible along with multiple navigation goal poses indicated by colored arrows/markers scattered across the map. The left panel shows the display tree including Global Options, Grid, RobotModel, TF, LaserScan, Bumper Hit, Map, AMCL Particle Swarm, Global Planner, Controller, and Realsense plugins. The top toolbar includes standard RViz tools: Move Camera, Select, Focus Camera, Measure, 2D Pose Estimate, Publish Point, and Nav2 Goal. The bottom-left panel shows the Nav2 navigation status with 'Navigation: active', 'Localization: inactive', 'Poses remaining: 0', 'ETA: 0s', 'Distance remaining: 0.00m', and 'Time taken: 0s'. This demonstrates the repositioning (multi-point) navigation feature where multiple waypoints are placed on the map for the robot to follow sequentially.
