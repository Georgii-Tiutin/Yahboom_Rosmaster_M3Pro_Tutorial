## Caption
RViz2 interface showing LiDAR LaserScan visualization setup with the 'Create visualization' dialog open for adding a LaserScan display.

## Description
The image shows the RViz2 (ROS2 visualization tool) interface during LiDAR setup. On the left side is the Displays panel with Global Options (Fixed Frame set to base_link, background color settings, frame rate), a Global Status showing an error about the fixed frame, and existing display entries including RobotModel, TF (with Show Names, Show Axes, Show Arrows options), and a LaserScan display configured on the /scan topic. In the center-right area, a 'Create visualization' dialog box is open, showing display types available to add, with 'LaserScan' highlighted/selected. The dialog includes a description stating that LaserScan displays data from a sensor_msgs/LaserScan message as points in the 3D world. The bottom of the dialog has a 'Display Name' field and OK/Cancel buttons. A red rectangle annotation highlights the LaserScan selection in the dialog. This screenshot demonstrates the process of adding a LiDAR scan visualization in RViz2 as part of the LiDAR introduction tutorial.
