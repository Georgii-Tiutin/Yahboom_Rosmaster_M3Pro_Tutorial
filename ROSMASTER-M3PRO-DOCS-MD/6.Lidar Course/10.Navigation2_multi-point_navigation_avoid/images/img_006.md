## Description
The image shows the RViz2 visualization tool used with ROS2 Navigation2 stack. On the left side is the Displays panel listing various visualization plugins: Global Options, Global Status (Ok), Grid, RobotModel, TF, LaserScan, Bumper Hit, Map, AMCL Particle Swarm, Global Planner, Controller, Realsense, and MarkerArray. The main viewport displays a 2D occupancy grid map (gray open space with black walls/obstacles) with red LiDAR scan points, white AMCL particle cloud for localization, and the robot's position. The toolbar at the top includes buttons for 2D Pose Estimate, Publish Point, and Nav2 Goal. At the bottom-left is the Navigation2 panel showing status information: Navigation active, Localization active, Feedback unknown, Poses remaining 0, ETA 0s, Distance remaining 0.00m, Time taken 0s, Recoveries 0. Below the status are three buttons: 'Start Nav Through Poses', 'Cancel Accumulation', and 'Start Waypoint Following' (highlighted with a red rectangle to draw attention as the key action for multi-point navigation). This screenshot demonstrates the setup for initiating waypoint-based multi-point navigation with obstacle avoidance in the Navigation2 framework.
