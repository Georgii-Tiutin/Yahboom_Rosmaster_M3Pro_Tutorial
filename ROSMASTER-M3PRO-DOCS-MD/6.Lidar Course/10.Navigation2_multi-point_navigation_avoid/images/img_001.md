RViz2 interface showing a 2D occupancy grid map with the Navigation2 panel for multi-point navigation and obstacle avoidance.

## Description
The image shows the RViz2 visualization tool used in ROS2. The main viewport displays a 2D occupancy grid map generated by SLAM, with white areas representing free space, black areas representing obstacles/walls, and gray areas representing unknown space. A diagonal dark gray region in the lower-left suggests an unexplored or out-of-bounds area.

On the left side is the RViz2 Displays panel listing several visualization layers: Global Options, Grid, TF, LaserScan, Bumper Hit, Map, Amcl Particle Swarm, Global Planner, Controller, Realsense, and MarkerArray. Below the displays panel is the Navigation2 plugin panel showing navigation status fields: Navigation (unknown), Localization (unknown), Feedback (unknown), Poses remaining (0), ETA (0s), Distance remaining (0.00 m), Time taken (0s), and Recoveries (0), with a Reset button at the bottom.

The top toolbar includes buttons for camera movement, selection, focus, measurement, 2D Pose Estimate, Publish Point, and Nav2 Goal. This screenshot demonstrates the initial state of the Nav2 multi-point navigation interface before any goals have been set, as part of a tutorial on Navigation2 multi-point navigation with obstacle avoidance.
