## Description
The image shows the QTopic Monitor plugin within a ROS2 GUI tool (likely rqt). On the left side, there is a list of active ROS2 topics including /scan, /scan_multi, /set_pose, /tf, /tf_static, and /waypoints. The /waypoints topic is expanded to show a visualization_msgs/msg/Marker message structure with fields such as header, ns, points, colors, texture_resource, texture, uv_coordinates, text, mesh_resource, mesh_file, mesh_use_embedded_materials, id, type, action, pose (with position x/y/z and orientation x/y/z/w), scale, color, lifetime, and frame_locked. On the right side, the topic list shows message types and bandwidth/frequency columns, displaying sensor_msgs/msg/LaserScan for the scan topics and geometry_msgs/msg/PoseWithCovarianceStamped for /set_pose. This screenshot is used in the Navigation2 multi-point navigation tutorial to illustrate monitoring waypoint markers and navigation-related topics during a multi-point navigation session.
