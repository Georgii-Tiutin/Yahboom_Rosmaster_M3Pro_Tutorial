## Caption
RViz2 interface showing Navigation2 multi-point navigation with an occupancy grid map and the Nav2 control panel in an active navigation session.

## Description
The image shows the RViz2 visualization tool used with ROS2 Navigation2 (Nav2). The left side contains the Displays panel listing various visualization layers including Global Options, Grid, RobotModel, TF, LaserScan, Bumper Hit, Map, Amcl Particle Swarm, Global Planner, Controller, Realense, and MarkerArray. Below it is the Navigation 2 control panel showing Navigation: active, Localization: active, Feedback: unknown, with Poses remaining: 0, ETA: 0s, Distance remaining: 0.00 m, Time taken: 0s, and Recoveries: 0, along with Pause, Reset buttons and a Waypoint/Nav Through Poses Mode toggle. The main viewport displays an occupancy grid map with black cell boundaries representing walls and obstacles, gray areas for free space, and white areas for unknown regions. Red scattered points indicate LiDAR scan data, and the robot's position is visible in the center of the map. The top toolbar includes Move Camera, Select, Focus Camera, Measure, 2D Pose Estimate, Publish Point, and Nav2 Goal tools. This screenshot demonstrates the Nav2 multi-point navigation interface in an idle/completed state as part of the ROSMASTER M3 Pro navigation tutorial.
