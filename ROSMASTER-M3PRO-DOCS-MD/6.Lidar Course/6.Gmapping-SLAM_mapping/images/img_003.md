## Caption
RViz visualization showing a Gmapping SLAM-generated occupancy grid map with laser scan data and robot model overlay.

## Description
The image shows the RViz (ROS Visualization) application window during a Gmapping SLAM mapping session. The main viewport displays a 2D occupancy grid map being built in real-time, with black lines representing walls and obstacles detected by the LiDAR sensor, white areas representing free/explored space, and gray areas representing unknown/unexplored regions. Red dots visible on the map represent the current laser scan data points from the LiDAR. The left panel shows the Displays sidebar with several visualization layers enabled: Global Options (fixed frame set to 'map'), Grid, Map, LaserScan, RobotModel, and TF. The toolbar at the top includes standard RViz interaction tools such as 2D Pose Estimate and 2D Goal Pose buttons. The status bar at the bottom shows ROS Time and Wall Time information. This screenshot demonstrates the expected result when running Gmapping SLAM mapping on the Yahboom ROSMASTER M3 Pro robot, as part of the LiDAR SLAM mapping tutorial.
