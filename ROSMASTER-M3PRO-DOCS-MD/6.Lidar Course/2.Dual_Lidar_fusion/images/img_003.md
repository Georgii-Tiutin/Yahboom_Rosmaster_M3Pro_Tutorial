## Caption
RViz2 interface showing the 'Create visualization' dialog for adding a LaserScan display topic during dual LiDAR fusion setup.

## Description
The image shows the RViz2 visualization tool with its left-side Displays panel listing several display types including Global Options, RobotModel, TF, map, and multiple LaserScan entries (for /scan, /scan1, /scan_multi, /waypoints topics). A 'Create visualization' dialog box is open in the center, with 'By topic' tab selected, showing available LaserScan topics that can be added. Red annotation arrows point from the dialog to the corresponding LaserScan entries in the Displays panel, illustrating how to add LiDAR scan visualizations. The right side of the RViz viewport shows a partial dark visualization with LiDAR scan data rendered in red/colored points. The bottom status bar shows ROS time and wall elapsed time information.
