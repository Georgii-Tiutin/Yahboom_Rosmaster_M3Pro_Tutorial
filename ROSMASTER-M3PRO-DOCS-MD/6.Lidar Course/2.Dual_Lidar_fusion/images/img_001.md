## Caption
RViz2 interface showing the process of adding a LaserScan display topic for dual LiDAR fusion, with the 'Create visualization' dialog selecting the /scan_multi topic.

## Description
The image is a screenshot of the RViz2 visualization tool in ROS2, showing the configuration for dual LiDAR fusion. On the left side, the Displays panel shows the current visualization setup including Global Status (OK), PoseWithCovariance, RobotModel, and two existing LaserScan displays. A LaserScan display is selected showing its properties: Topic set to /scan_multi, Style set to Flat Squares, Size 0.01m, Alpha 1, and Decay Time 0. On the right side, a 'Create visualization' dialog box is open, showing available display types including MarkerArray and LaserScan. The dialog includes a topic dropdown and description area explaining that LaserScan displays sensor data as points in the world. Red rectangular annotations highlight key areas: the 'By topic' tab at the top of the dialog, the /scan_multi topic in the left panel properties, and the OK/Cancel buttons at the bottom. This demonstrates how to add and configure the fused multi-LiDAR scan topic in RViz2 for visualizing combined data from dual LiDAR sensors.
