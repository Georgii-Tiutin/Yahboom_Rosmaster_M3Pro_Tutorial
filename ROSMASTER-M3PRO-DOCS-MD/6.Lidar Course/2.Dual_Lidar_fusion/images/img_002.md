## Caption
RViz2 displaying fused dual LiDAR point cloud data with the robot model visible in the 3D viewport.

## Description
The image shows the RViz2 visualization tool with a dual LiDAR fusion setup. On the left side is the Displays panel containing: Global Options with Fixed Frame set to 'base_link', Background Color set to dark gray (48;48;48), and Frame Rate at 30. Below that are entries for RobotModel, TF, and a LaserScan display. The LaserScan display is configured with Topic '/scan_multi' (the fused multi-LiDAR topic), Style set to 'Flat Squares', Size 0.01m, Alpha 1, and Color Transformer set to 'Intensity'. On the right side is the 3D viewport showing scattered LiDAR point cloud data rendered as colored dots against a dark background, with the robot model (showing colored axis markers in red, green, and blue for X, Y, Z) visible at the center. The point cloud represents the merged output from two LiDAR sensors, demonstrating the dual LiDAR fusion result. The toolbar at the top shows standard RViz2 controls including Interact, Move Camera, Focus Camera, and Measure tools.
