Geometric diagram illustrating 2D image rotation by showing how a point (x, y) maps to a new position (x', y') through angular rotation θ around the origin.

## Description
The diagram shows a 2D coordinate system with X and Y axes (in blue) and a rotated coordinate system X' and Y' (in red). A point is shown at position (x, y) in the original coordinate system, which maps to (x', y') after rotation by angle θ. The diagram includes geometric construction lines showing the trigonometric relationships involved in the rotation: components labeled as x·cosθ, x·sinθ, y·cosθ, and y·sinθ are marked along the axes and projected lines. Dashed lines (in brown/orange) show the perpendicular projections used to derive the rotation matrix formulas. The origin O is at the bottom-left corner, and the overall layout demonstrates how the standard 2D rotation transformation matrix is derived from these trigonometric components.
