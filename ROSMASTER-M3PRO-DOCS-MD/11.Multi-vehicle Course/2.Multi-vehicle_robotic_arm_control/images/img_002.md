The image is a screenshot of the ROS2 rqt_graph tool displaying the active node and topic relationships for a multi-vehicle robotic arm control setup. On the left side, three nodes are visible: /joy_node, /joy, and /joy_ctrl, which represent the joystick input pipeline. The /joy_ctrl node publishes to two topics: /cmd_vel (for chassis velocity commands) and /arm_joint (for robotic arm joint commands). Both robot nodes subscribe to the /cmd_vel and /arm_joint topics, indicating that a single joystick controller can simultaneously command both robots' chassis movement and arm positions. The graph uses the standard rqt_graph visualization with oval shapes for nodes and rectangular shapes for topics, with directional arrows showing the publisher-subscriber relationships. Filter options for namespaces, actions, tf, images, and other categories are visible in the toolbar.
