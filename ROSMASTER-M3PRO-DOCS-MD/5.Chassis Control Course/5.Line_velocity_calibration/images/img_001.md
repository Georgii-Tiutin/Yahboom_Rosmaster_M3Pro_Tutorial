## Caption
RQt dynamic reconfigure window showing the calibrate_linear node parameters for linear velocity calibration of the robot.

## Description
The image shows the RQt Parameter Reconfigure GUI (rqt_reconfigure) with the /calibrate_linear node selected in the left panel. The left panel lists available ROS2 nodes including calibrate_linear, ekf_filter_node, imu_filter, and rqt_gui_py nodes. The right panel displays the configurable parameters for the calibrate_linear node:
- use_sim_time: unchecked (real hardware mode)
- rate: 20.0 (update rate in Hz)
- test_distance: 1.0 (target distance in meters for the calibration test)
- speed: 0.5 (linear speed in m/s for the test)
- tolerance: 0.03 (acceptable error tolerance in meters)
- odom_linear_scale_correction: 1.0 (the correction factor to be calibrated)
- start_test: unchecked (checkbox to initiate the calibration test)
- direction: checked (forward direction)
- base_frame: base_footprint (robot base TF frame)
- odom_frame: odom (odometry TF frame)

This is used in the linear velocity calibration tutorial where users adjust the odom_linear_scale_correction parameter by comparing the robot's reported odometry distance against a physically measured distance, iterating until the robot accurately travels the specified test_distance.
