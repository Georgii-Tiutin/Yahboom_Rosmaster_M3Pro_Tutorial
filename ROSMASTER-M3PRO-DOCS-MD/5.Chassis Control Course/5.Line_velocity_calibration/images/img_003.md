## Caption
ROS2 node graph showing the interconnections between IMU, calibration, and robot base nodes used during linear velocity calibration.

## Description
The image displays a ROS2 computation graph (rqt_graph style) illustrating the node and topic relationships for linear velocity calibration. On the left side, the /imu_filter node publishes to /imu/data and /imu/data_raw topics, and connects to the /tf topic. In the center, the /calibrate_linear node subscribes to /tf and publishes /cmd_vel. On the right side, the /YB_Node (Yahboom base node) receives /cmd_vel commands and publishes /odom_raw, which feeds into the /ekf_filter_node. The /transform_listener_impl node (with a hash suffix) also connects between /tf and the calibration node. Arrows indicate data flow directions between rectangular topic boxes and elliptical node shapes, forming the complete ROS2 pipeline for performing linear velocity calibration on the ROSMASTER M3 Pro robot.
