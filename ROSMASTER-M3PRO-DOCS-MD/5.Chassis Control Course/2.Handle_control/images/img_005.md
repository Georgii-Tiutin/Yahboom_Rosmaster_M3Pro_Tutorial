## Caption
Flowchart showing the decision logic for processing joystick (Joy) messages to control the robot, branching based on username and robot arm control needs.

## Description
A vertical flowchart depicting the program logic for handle/joystick control of the ROSMASTER M3 Pro robot. The flow begins with a diamond decision node asking 'Joy message received?' (接收到Joy消息?). If Yes, it proceeds to call the buttonCallback function (调用buttonCallback函数). Next, another diamond decision checks 'Is username yahboom?' (用户名是yahboom?). If Yes, it calls user_jetson function (调用user_jetson函数); if No, it calls user_pc function (调用user_pc函数). Both paths then converge to a final diamond decision asking 'Need to control robot arm?' (是否需要控制机械臂?). The flowchart uses standard shapes: diamonds for decisions and rounded rectangles for process steps, with bilingual labels in Chinese and English throughout.
