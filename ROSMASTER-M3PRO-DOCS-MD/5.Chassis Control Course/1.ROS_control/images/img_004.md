## Description
The image shows a terminal screenshot on a Raspberry Pi (root@raspberrypi) displaying the output of the command 'ros2 node info /YB_Node'. The YB_Node is the primary ROS2 node for the Yahboom ROSMASTER robot's STM32 control board interface. The node subscribes to five topics: /arm6_joints (arm_msgs/msg/ArmJoints) for 6-DOF arm control, /arm_joint (arm_msgs/msg/ArmJoint) for individual joint control, /beep (std_msgs/msg/UInt16) for buzzer control, /cmd_vel (geometry_msgs/msg/Twist) for chassis velocity commands, and /rgb (std_msgs/msg/ColorRGBA) for LED color control. It publishes five topics: /battery (std_msgs/msg/Float32) for battery voltage, /imu/data_raw (sensor_msgs/msg/Imu) for IMU sensor data, /odom_raw (nav_msgs/msg/Odometry) for raw odometry, and /scan0 and /scan1 (sensor_msgs/msg/LaserScan) for dual LiDAR scan data. The Service Servers, Service Clients, Action Servers, and Action Clients sections are all empty. This screenshot serves as a reference in the ROS control tutorial to help users understand the communication interface of the robot's main hardware node.
