## Caption
Flowchart illustrating the program logic for keyboard-based teleoperation control of the ROSMASTER M3 Pro robot.

## Description
This is a detailed flowchart showing the complete program flow for keyboard control of the robot. It begins with a 'Start' node, followed by initializing the ROS node and parameters, setting initial parameters, and printing control instructions. The main loop gets keyboard input, which branches into multiple actions based on the key pressed: setting movement direction (forward, backward, left, right, rotate, etc.), increasing a speed counter, or detecting Ctrl+C to exit. Within the loop, a decision diamond checks if the counter exceeds 4, triggering a smooth stop if true. Another decision checks if the speed exceeds the limit, capping it if necessary. The current speed is then published. On exit (Ctrl+C), the program publishes a stop message, restores terminal settings, destroys the ROS node, shuts down ROS, and ends. The flowchart uses standard symbols: rounded rectangles for start/end, rectangles for processes, diamonds for decisions, with directional arrows showing program flow. Chinese text labels are used throughout with some English annotations in the OCR.
