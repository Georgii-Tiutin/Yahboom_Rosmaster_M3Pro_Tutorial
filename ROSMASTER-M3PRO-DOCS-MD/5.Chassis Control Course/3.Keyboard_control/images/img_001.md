ROS2 node graph showing the keyboard control node publishing velocity commands to the robot node.

## Description
The image is a ROS2 computation graph (rqt_graph style) depicting the communication flow for keyboard-based robot control. On the left, an ellipse represents the /yahboom_keyboard_ctrl node, which publishes to the /cmd_vel topic (shown as a rectangle in the center). An arrow connects the publisher node to the topic. On the right, another ellipse represents the /YB_Node subscriber, which receives the velocity commands from /cmd_vel via a second arrow. This diagram illustrates how keyboard inputs are translated into Twist messages on the /cmd_vel topic and consumed by the robot's main control node to drive the chassis.
