## Description
This is a flowchart depicting the program logic of the line patrol (line tracking) automatic driving ROS node. The flow begins with a loop that checks 'Message Received?' (接收到消息?). If yes, it proceeds to 'Process Message' (处理消息), then checks 'Is Image Message?' (是否为图像消息?). If it is an image message, the flow continues to 'Image Processing' (图像处理), then 'Detect AprilTag' (检测AprilTag), and finally 'Line Tracking Processing' (线条跟踪处理). The loop cycles back to check for the next message. A parallel branch on the right side checks 'Exit?' (是否退出?). If yes, it proceeds to 'Stop Publishing Velocity' (停止发布速度指令), 'Destroy Node' (销毁节点), 'Shutdown ROS' (关闭ROS), and 'End' (结束). All labels are bilingual in Chinese and English. The flowchart uses standard shapes: rounded rectangles for processes, diamonds for decisions, and directional arrows for flow.
