## Caption
ROS2 node graph showing the data flow between camera, line-following, and robot control nodes for line patrol automatic driving.

## Description
This is a ROS2 computation graph (rqt_graph style) depicting the node and topic relationships for the line patrol automatic driving system. On the left, the /camera node publishes color and depth image topics (/camera/color/image_raw, /camera/depth/image_raw) within the /camera namespace, with sub-nodes /camera/camera and /camera/camera_container. Two standalone nodes /tin_ik_fk and /launch_ros_29256 appear at the top. The /follow_line node in the center subscribes to the camera image topics and publishes control outputs to /arm6_joints, /cmd_vel, and /beep topics. These are consumed by the /YB_Node on the right, which also publishes /scan1 (LiDAR scan data). The graph illustrates how visual input from the depth camera is processed by the line-following algorithm to generate chassis velocity commands, robotic arm joint commands, and buzzer signals for the autonomous line patrol behavior.
