## Description
Screenshot of a matplotlib-style window titled "frame" with a toolbar (back, forward, up, down, home, zoom, save icons, etc.). The window is split into two panels. Left panel: the camera image of a gray tiled floor with a red/brown tape strip running roughly vertically from the bottom toward the center-left. A small blue rotated square (diamond) with a magenta center dot marks the detected line position/target point on the tape near the lower left. Right panel: a black binary mask image where only the red tape region appears as scattered white pixels near the bottom, at roughly the same position as the tape in the left image. This illustrates the color line patrol (line following) color recognition result from the OpenClaw Color Line Patrol tutorial.
