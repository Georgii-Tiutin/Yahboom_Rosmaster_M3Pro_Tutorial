## Description
Line drawing of a right hand forming the right-hand coordinate frame. Three arrows radiate from the hand's palm area: a vertical arrow labeled "ẑ" (z-hat) pointing up, aligned with the thumb; an arrow labeled "x̂" (x-hat) pointing up-left, aligned with the index finger; and an arrow labeled "ŷ" (y-hat) pointing down-left, aligned with the middle finger. The remaining fingers are curled. It illustrates the right-handed Cartesian coordinate system convention (x, y, z) used for the robotic arm's coordinate frames in the tutorial.
