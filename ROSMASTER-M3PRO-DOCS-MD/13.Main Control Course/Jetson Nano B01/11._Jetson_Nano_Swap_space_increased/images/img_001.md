## Caption
Terminal session showing the step-by-step process of creating and enabling a 3GB swap file on a Jetson Nano running Ubuntu.

## Description
The image shows a Linux terminal window with a dark background displaying a sequence of commands executed by the 'jetson' user on a 'jetson-desktop' host. The commands demonstrate how to increase swap space on a Jetson Nano:

1. `sudo fallocate -l 3G /var/swapfile` — allocates a 3GB file for swap
2. `ls /var/swapfile -lh` — verifies the file was created (shows 3.0G, owned by root)
3. `sudo chmod 600 /var/swapfile` — sets restrictive permissions on the swap file
4. `sudo mkswap /var/swapfile` — formats the file as swap space (output shows version 1, size 3 GiB with a UUID)
5. `sudo swapon /var/swapfile` — activates the swap file

This is a standard procedure for increasing virtual memory on resource-constrained embedded platforms like the Jetson Nano, which is important for running memory-intensive ROS2 and AI workloads.
