## Description
Screenshot of the jtop (Jetson Stats) terminal-based monitoring tool version 4.2.0, showing the 7INFO tab. The left side lists Platform information (aarch64 machine, Linux system, Ubuntu 18.04 Bionic Beaver, kernel 4.9.253-tegra, Python 3.6.9) and installed Libraries (CUDA 10.2.300, cuDNN 8.2.1.32 highlighted in yellow, TensorRT 8.2.1.8, VPI 1.2.3, Vulkan 1.2.70, OpenCV 4.1.1 with CUDA marked as NO in red). The right side shows Hardware details (NVIDIA Jetson Nano Developer Kit model, part numbers, BoardIDs p3448, Module: Jetson Nano 4 GB ram, SoC tegra210, CUDA Arch BIN 5.3, Jetpack 4.6.1) and network Interfaces (Hostname: yahboom, wlan0: 192.168.2.68, docker0: 172.17.0.1). The bottom navigation bar shows tabs 1ALL through 7INFO (highlighted) and Quit. Two items are highlighted with yellow boxes: the cuDNN version and the 7INFO tab selector.
