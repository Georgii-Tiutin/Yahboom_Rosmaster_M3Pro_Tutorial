## Description
The image shows the Windows Computer Management application with the Disk Management utility selected in the left navigation pane. The top section displays a list of volumes with columns for Volume, Layout, Type, File System, Status, Capacity, and Free Space. Several partitions are visible including system partitions (FAT32, NTFS) and data volumes labeled with drive letters (C:, D:, E:). The bottom section shows a graphical representation of multiple physical disks (Disk 0, Disk 1, Disk 2, Disk 3) with color-coded partition blocks indicating primary partitions, logical drives, and free space. This screenshot is used in the tutorial context to guide users on how to locate and re-read a memory card or USB drive that has been flashed/burned with a robot system image, by identifying the correct disk in Windows Disk Management.
