## Caption

## Description
Screenshot of the jtop (jetson_stats) terminal utility version 4.2.0 running on a Jetson Nano Developer board. The interface shows the 7INFO tab with two main sections: Platform information on the left (Machine: aarch64, System: Linux, Distribution: Ubuntu 18.04 Bionic Beaver, Release: 4.9.253-tegra, Python: 3.6.9) and Hardware details on the right (Model: NVIDIA Jetson Nano Developer, 699-level Part Number: 699-13448-000, P-Number: p3448-0000, Module: NVIDIA Jetson Nano 4 GB ram, SoC: tegra210). A Libraries section lists installed software versions including CUDA 10.2.300, cuDNN 8.2.1.32, TensorRT 8.2.1.8, VPI 1.2.3, Vulkan 1.2.70, and OpenCV 4.1.1 (marked red as NOT compiled with CUDA). The right side also shows CUDA Arch BIN: 5.3, Codename: Porg, L4T: 32.7.1, Jetpack: 4.6.1, Hostname: yahboom, and network interfaces (wlan0: 192.168.2.68, docker0: 172.17.0.1). The top bar shows MAXN power mode with CPU at 30.9% and GPU at 0.0%. Navigation tabs at the bottom include 1ALL, 2GPU, 3CPU, 4MEM, 5ENG, 6CTRL, 7INFO, and Quit. This screenshot is used in the tutorial to introduce the Jetson Nano system information and demonstrate how to check hardware/software configuration using jtop.
