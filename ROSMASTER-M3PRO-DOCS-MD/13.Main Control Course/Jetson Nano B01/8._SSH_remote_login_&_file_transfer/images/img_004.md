## Description
The image shows the WinSCP application interface used for SSH-based file transfer between a local Windows computer and a remote Linux system (likely the robot's onboard computer). The window has a dual-pane layout: the left pane displays the local Windows file system with folders like Documents, and the right pane shows the remote Linux file system with typical Linux directories (such as Desktop, Documents, Downloads, etc.). The top toolbar includes connection settings, transfer options, and navigation controls. The status bar at the bottom shows connection information. This screenshot demonstrates how to use WinSCP to remotely browse and transfer files to/from the robot's Linux-based controller via SSH, which is a key step in the tutorial for setting up remote file management with the ROSMASTER M3 Pro robot.
