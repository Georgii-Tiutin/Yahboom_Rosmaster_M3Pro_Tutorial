## Caption
WinSCP file transfer interface showing local and remote file system panels for SSH-based file management with a robot platform.

## Description
The image shows the WinSCP application window, a popular Windows SSH/SFTP file transfer client. The interface is split into two panes: the left pane displays the local file system with folders and files on the Windows computer, and the right pane shows the remote file system on the robot's Linux system connected via SSH. The toolbar at the top contains standard file operation buttons (Upload, Download, Edit, Delete, Properties, New, etc.) along with session management options. Both panes display file/folder listings with columns for Name, Size, Type, Changed date, and Rights/permissions. A right-click context menu is visible on the remote side showing file operation options. This screenshot demonstrates how to use WinSCP for transferring files between a local Windows PC and the robot's onboard computer (such as Jetson Nano or Raspberry Pi) via SSH, which is a key step in the SSH remote login and file transfer tutorial.
