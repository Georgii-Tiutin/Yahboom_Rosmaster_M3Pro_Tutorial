## Description
The image contains two stacked screenshots of the Raspberry Pi Software Configuration Tool (raspi-config) running in a terminal. The top screenshot shows the main menu with numbered options: 1 System Options, 2 Display Options, 4 Performance Options, 5 Localisation Options, 6 Advanced Options, 8 Update, and 9 About raspi-config. The 'Interface Options' entry appears highlighted (selected) in the list. The bottom screenshot shows the Interface Options submenu, which lists toggles for various interfaces and remote access services including SSH, VNC, SPI, I2C, Serial Port, 1-Wire, and Remote GPIO. This two-panel layout demonstrates the navigation path a user follows to enable remote access (SSH/VNC) on the Raspberry Pi 5 as part of the robot's remote connectivity setup.
