## Caption
WinSCP interface showing drag-and-drop file transfer from local Windows PC to remote Raspberry Pi.

## Description
The image shows a WinSCP session connected to a Raspberry Pi at IP address 192.168.2.93. The interface is split into two panes: the left pane displays the local Windows file system with a file selected, and the right pane shows the remote Raspberry Pi's home directory (/home/pi) with typical Linux directories like Desktop, Documents, Downloads, Music, Pictures, etc. A large arrow annotation in the center indicates dragging the file from the local side (left) to the remote side (right), with Chinese text '将文件拖拽到对方区域' meaning 'Drag the file to the other side's area.' This demonstrates how to use WinSCP's drag-and-drop feature to remotely transfer files to the robot's Raspberry Pi controller.
