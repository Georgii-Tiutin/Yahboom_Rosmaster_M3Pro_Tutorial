## Caption
WinSCP file transfer interface showing a dual-pane view with local Windows files on the left and remote Raspberry Pi files on the right, connected via SSH to 192.168.2.93.

## Description
The image shows the WinSCP application window connected to a Raspberry Pi at IP address 192.168.2.93 (user: pi). The interface displays a dual-pane file manager layout:

- Left pane: Local Windows computer file system, showing folders such as Arduino, PictoBlox, MakeCode, Notepad++, Raspberry Computing, Scratch Files, and WPS Office, with their modification dates from late 2023.
- Right pane: Remote Raspberry Pi file system (home directory of user 'pi'), showing standard Linux home directories including Bookshelf, Desktop, Documents, Downloads, Music, Pictures, Public, Templates, and Videos, with file permissions (rwxr-xr-x) and ownership (pi/root) visible.

The top toolbar contains standard WinSCP navigation and file operation buttons. The title bar confirms the SSH connection to pi@192.168.2.93. This screenshot demonstrates how to use WinSCP for remote file transfer between a Windows PC and a Raspberry Pi, which is essential for transferring robot configuration files, code, and resources to the robot's onboard computer.
