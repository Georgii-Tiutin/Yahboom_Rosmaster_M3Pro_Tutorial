## Caption
GParted partition editor on a Jetson device showing the completion of pending partition operations on an NVMe SSD, followed by the resulting partition layout.

## Description
The image contains two stacked screenshots from an Ubuntu desktop on a Jetson (NVIDIA) device. The top screenshot shows the GParted 1.3.1 partition editor with a dialog box titled 'Applying pending operations' displaying 'Completed Operations' with a full green progress bar, indicating the partition resize/modification operation on /dev/nvme0n1 (238.47 GiB) has finished successfully. A 'Close' button (highlighted with a red rectangle) is visible. The bottom screenshot shows the GParted main window after the operation is complete, displaying the full partition table of /dev/nvme0n1p1 (237.02 GiB) with multiple partitions listed including kernel, kernel-dtb, reserved_on_user, recovery, esp, and APP partitions. The APP partition (ext4) is the largest at 237.02 GiB, showing 12.00 GiB used and 224.52 GiB available. The terminal in the background shows the gparted launch command with libparted-dmraid and online-resize options enabled. This demonstrates the SSD expansion process where the NVMe drive partitions have been successfully resized on the Jetson platform.
