## Caption
GParted partition editor showing the partition layout of an NVMe SSD (/dev/nvme0n1) on a Jetson system with a large unallocated space of 218.53 GiB.

## Description
The screenshot shows the GParted 1.3.1 partition management tool running on an Ubuntu-based Jetson system (jetson@yahboom). The terminal in the background displays the GParted launch command and version info. The main GParted window shows the partition table for /dev/nvme0n1 (238.47 GiB total). A graphical bar at the top visualizes the disk layout, with a large green/hatched unallocated region dominating the right side. The partition list below shows multiple small Jetson-specific partitions (A_kernel, A_kernel-dtb, A_reserved_on_user, etc.) with various filesystem types (msftdata, ext4, unknown), most only a few MiB in size. A large 218.53 GiB unallocated space is visible, which is the target area for SSD expansion as described in the tutorial. The NVIDIA Jetson Support Forums page is partially visible in the background. This image demonstrates the initial state of the SSD before expanding or creating new partitions to utilize the unallocated space.
