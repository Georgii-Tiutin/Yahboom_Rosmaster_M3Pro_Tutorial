## Caption
GParted partition editor showing the NVMe drive partition layout on a Jetson system for SSD expansion.

## Description
Screenshot of the GParted 1.3.1 application running on an Ubuntu desktop (Jetson/Yahboom system). The terminal in the background shows the gparted launch command. The GParted window displays the partition table for an NVMe drive (/dev/nvme0n1) with approximately 15 partitions (p1 through p15) listed in a table showing partition name, file system type, mount point, size, used space, unused space, and flags. The partitions include system partitions labeled A_kernel, A_kernel-dtb, A_reserved, B_kernel, and others typical of a Jetson NVIDIA Linux (L4T) flash layout. A large unallocated space (approximately 216 GB) is visible at the end of the drive, highlighted in the visual partition bar at the top. This screenshot is from a tutorial on expanding SSD storage, showing the initial partition state before resizing or creating new partitions in the unallocated space.
