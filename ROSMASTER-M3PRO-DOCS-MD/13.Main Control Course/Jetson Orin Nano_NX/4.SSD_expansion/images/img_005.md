## Caption
GParted partition editor on a Jetson device showing a confirmation dialog to apply pending partition operations on an NVMe SSD.

## Description
The screenshot shows a Jetson (Ubuntu/Linux) desktop with the GParted 1.3.1 partition editor open, operating on /dev/nvme0n1 (238.47 GiB NVMe SSD). The main window displays the partition layout with multiple partitions listed (including /dev/nvme0n1p1 at 237.02 GiB and several smaller system partitions). A confirmation dialog box titled 'Apply operations to device' is displayed in the foreground, warning the user with a caution icon that 'Editing partitions has the potential to cause LOSS of DATA' and asking 'Are you sure you want to apply the pending operations?' with Cancel and Apply buttons. The terminal in the background shows the gparted command being launched. The NVIDIA Jetson Support webpage is also visible in a browser tab. This is part of the SSD expansion tutorial, demonstrating the step where the user applies partition changes to expand or configure the NVMe SSD storage on the Jetson board.
