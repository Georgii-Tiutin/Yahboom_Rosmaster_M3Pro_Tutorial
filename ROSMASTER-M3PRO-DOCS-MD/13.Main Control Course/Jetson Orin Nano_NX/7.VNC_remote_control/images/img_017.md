## Caption
Terminal commands on a Jetson board installing and enabling the GNOME extension to allow locked remote desktop access for VNC.

## Description
The image shows an Ubuntu desktop environment on an NVIDIA Jetson board with a terminal window open in the foreground. The file manager is visible in the background showing the Downloads folder containing a GNOME shell extension zip file. In the terminal, two commands are executed:
1. 'gnome-extensions install allowlockedremotedesktop@kamens.us.v9.shell-extension.zip' to install the extension
2. 'sudo gnome-extensions enable allowlockedremotedesktop@kamens.us' to enable it (with a password prompt for the jetson user)
The NVIDIA Jetson desktop shows the taskbar on the left with standard Ubuntu application icons, and the top-right corner displays the NVIDIA logo and Jetson Support/Forums shortcuts. This step is part of the VNC remote control setup tutorial, configuring the system to allow remote desktop connections even when the screen is locked.
