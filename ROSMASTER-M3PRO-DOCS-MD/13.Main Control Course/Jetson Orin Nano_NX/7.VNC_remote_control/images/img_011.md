## Caption
The Passwords and Keys application on the Jetson showing stored credentials including GNOME Remote Desktop RDP and VNC passwords in the Default keyring.

## Description
Screenshot of the GNOME 'Passwords and Keys' (Seahorse) application running on an NVIDIA Jetson desktop. The left sidebar shows categories: Passwords > Login, Keys > GnuPG keys and OpenSSH keys, and Certificates > System Trust. The main panel displays the 'Default keyring' contents with two entries: 'GNOME Remote Desktop RDP credentials' and 'Remote Desktop VNC password', both listed as 'Password or Secret' type. A right-click context menu is visible on the VNC password entry showing options: Change Password, Lock, Delete, and Properties. The Jetson desktop taskbar is visible at the bottom with shortcuts to Terminal, NVIDIA Jetson Developer Zone, Jetson Support Forums, L4T-README, NVIDIA Jetson Community, and Jetson Zoo. This screenshot demonstrates how to manage or change VNC remote desktop passwords through the system keyring manager as part of the VNC remote control tutorial.
