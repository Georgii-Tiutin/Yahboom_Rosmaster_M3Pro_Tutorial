## Caption
Ubuntu Settings panel showing the Sharing section with Remote Desktop, Media Sharing, and Remote Login options enabled on the Yahboom robot.

## Description
Screenshot of the Ubuntu GNOME Settings application open to the Sharing page. The left sidebar lists system settings categories (Network, Bluetooth, Background, Appearance, Notifications, Search, Multitasking, Applications, Privacy, Online Accounts, Sharing, Sound, Power, Displays, Mouse & Touchpad, Keyboard). The 'Sharing' option is highlighted with an orange box labeled '2'. At the top-left, the Settings gear icon is also highlighted with an orange circle labeled '1'. The main content area shows the Computer Name set to 'yahboom' and three sharing services: Remote Desktop (On), Media Sharing (Active), and Remote Login (On). In the top-right header bar, a toggle switch is highlighted with an orange box labeled '3', indicating the master sharing toggle is enabled. The numbered annotations (1, 2, 3) guide users through the steps: open Settings, select Sharing, and enable the sharing toggle. This is part of a VNC remote control tutorial for configuring remote desktop access on the Yahboom ROSMASTER robot's Jetson board.
