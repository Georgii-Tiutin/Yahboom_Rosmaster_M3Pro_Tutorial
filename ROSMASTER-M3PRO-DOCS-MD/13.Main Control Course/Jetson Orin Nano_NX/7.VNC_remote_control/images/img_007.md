## Caption
Ubuntu Settings panel showing Remote Desktop configuration with VNC protocol enabled and authentication credentials set.

## Description
The image shows the Ubuntu GNOME Settings application open to the 'Remote Desktop' section on a Jetson device. The left sidebar displays various settings categories (Network, Bluetooth, Background, Appearance, Notifications, Multitasking, Applications, Privacy, Online Accounts, Displays, Mouse & Touchpad, Keyboard) with 'Remote Desktop' highlighted. The main panel on the right shows:

1. A 'Remote Desktop' toggle switched ON at the top, with a description about desktop sharing.
2. 'Enable Legacy VNC Protocol' toggle switched ON.
3. 'Remote Control' section with 'New connections must ask for access' unchecked and 'Require a password' selected (highlighted in orange).
4. 'How to Connect' section displaying the Device Name, Remote Desktop Address, and VNC Address fields.
5. 'Authentication' section with User Name set to 'jetson' and Password set to 'yahboom'.

This screenshot demonstrates the step-by-step configuration of VNC remote desktop access on the robot's Jetson controller, enabling users to remotely control the robot's desktop environment.
