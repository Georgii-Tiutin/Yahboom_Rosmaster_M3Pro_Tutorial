## Description
The image is a screenshot of the Ubuntu GNOME Settings application, open to the 'Sharing > Remote Desktop' section. The left sidebar shows various settings categories (Wi-Fi, Bluetooth, Background, Appearance, Notifications, Search, Multitasking, Applications, Privacy, Online Accounts, Sharing, Sound, Power, Displays, Mouse & Touchpad, Keyboard, Remote Desktop). The main panel on the right displays the Remote Desktop configuration with several key settings highlighted in red boxes:

1. 'Enable Legacy VNC Protocol' toggle - switched ON
2. 'Remote Control' toggle - switched ON
3. Under 'How to Connect': Device Name is 'yahboom', Remote Desktop Address is 'ms-rd://yahboom-2.local', VNC Address is 'vnc://yahboom-2.local'
4. Under 'Authentication': User Name is 'jetson' and Password is 'yahboom', both highlighted in red boxes
5. 'Verify Encryption' option is also visible

This screenshot serves as a step-by-step guide in the VNC remote control tutorial, showing users exactly which settings to enable and what credentials to configure on the Yahboom robot's Jetson board to allow remote VNC desktop access.
