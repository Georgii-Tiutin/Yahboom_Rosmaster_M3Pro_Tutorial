## Description
The image contains two stacked screenshots from the RealVNC Viewer application on Windows. The top screenshot shows the 'Get started with RealVNC Viewer' setup wizard with two feature panels: 'Cloud connectivity' (for discovering cloud-joined computers) and 'Backup and sync' (for syncing address books across devices), along with a blue 'Sign in to get started' button, a Privacy Policy link, and a checkbox for sending anonymous usage data. The 'Finish' button is highlighted with a red rectangle in the wizard's top navigation bar. The bottom screenshot shows the main RealVNC Viewer window after setup, with a menu bar (File, View, Help), a VNC Connect search bar for entering a VNC Server address, an 'Address book' panel on the left, and a central area stating 'There are no computers in your address book at present' with instructions to sign in or enter a VNC Server IP address or hostname directly. This demonstrates the steps to complete VNC Viewer installation and access the main interface for remote desktop connections to the robot.
