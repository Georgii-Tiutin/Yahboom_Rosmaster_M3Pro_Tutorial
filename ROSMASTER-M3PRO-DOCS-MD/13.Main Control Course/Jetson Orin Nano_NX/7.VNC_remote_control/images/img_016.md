## Description
The screenshot shows the Chromium web browser open to the GNOME Shell Extensions website (extensions.gnome.org) displaying the 'Allow Locked Remote Desktop' extension page (extension #4338). At the top is a blue notification banner indicating that GNOME Shell integration browser extension and native host connector need to be installed to control extensions from this site. The extension page shows the title 'Allow Locked Remote Desktop' with its description about allowing remote desktop connections when the screen is locked. Below are sections for 'User Reviews' and 'Your opinion' on the right side. The browser tab and URL bar are visible at the top. This page is part of the VNC remote control tutorial, guiding users to install this GNOME extension to enable remote desktop access even when the Linux desktop is locked.
