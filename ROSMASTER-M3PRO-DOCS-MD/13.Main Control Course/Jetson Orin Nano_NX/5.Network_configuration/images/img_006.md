## Description
The image shows two overlapping Ubuntu terminal windows on a Jetson@yahboom desktop. The left terminal displays the output of the `ifconfig` command, listing multiple network interfaces: docker0 (172.17.0.1), enP8p1s0 (highlighted with a red box, showing IP 192.168.2.114 — the wired Ethernet interface), lo (loopback 127.0.0.1), and partial usb entries. The right terminal window shows additional interfaces: usb0, usb1, and wlP1p1s0 (highlighted with a red box, showing IP 192.168.2.110 — the wireless Wi-Fi interface). The red boxes call attention to the two key network interfaces (Ethernet and Wi-Fi) that are relevant for network configuration. The NVIDIA Jetson Support Forums page is partially visible in the background. This screenshot is from a network configuration tutorial demonstrating how to identify the robot's IP addresses on the Jetson board.
