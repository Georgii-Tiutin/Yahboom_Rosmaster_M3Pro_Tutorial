GParted partition editor showing the SSD partition layout on an Ubuntu Linux system used for the robot's backup process.

## Description
The image shows an Ubuntu desktop with the GParted (GNOME Partition Editor) application open. The terminal in the background shows the command used to install GParted. The GParted window displays the partition table for an SSD device (/dev/sdb), showing multiple partitions including system partitions (ext4, vfat types) such as kernel, recovery, APP, and ESP partitions. A horizontal bar at the top visualizes the disk layout with color-coded partition segments. The partition list shows details including partition name, file system type, mount point, size, and used/unused space. This screenshot is from page 3 of the 'Backup SSD system' tutorial, demonstrating how to view and manage the SSD partition structure before creating a system backup on the Jetson-based robot controller.
