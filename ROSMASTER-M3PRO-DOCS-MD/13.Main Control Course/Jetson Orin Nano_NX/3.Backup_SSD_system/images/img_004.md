## Caption
GParted partition editor showing the partition layout of an SSD (/dev/sdb) on an Ubuntu system used for backing up the Jetson board's SSD system.

## Description
The image shows an Ubuntu desktop with the GParted partition editor application open. The GParted window displays the partition table of /dev/sdb (an SSD drive) with numerous partitions listed in a table format. Each partition entry shows the device path (e.g., /dev/sdb1 through /dev/sdb15+), along with columns for partition type, filesystem, size, and flags. The partitions include various system partitions typical of an NVIDIA Jetson board: kernel, boot, recovery, recovery_alt, esp, esp_alt, UDA, reserved, and APP partitions. A colored bar at the top of the partition list provides a visual representation of the disk layout. The 'Create Partition' or similar button appears highlighted in yellow/orange in the upper right area of the GParted window. The Ubuntu taskbar is visible at the bottom of the screen. This screenshot demonstrates how to view and manage the SSD partition structure as part of the system backup procedure described in the tutorial.
