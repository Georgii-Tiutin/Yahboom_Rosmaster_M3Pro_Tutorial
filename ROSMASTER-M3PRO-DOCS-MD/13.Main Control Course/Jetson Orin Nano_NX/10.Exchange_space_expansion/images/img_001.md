## Caption
Terminal session on a Jetson board showing commands to disable zram and create an 8GB swap file for expanding virtual memory.

## Description
The image shows a full desktop screenshot of an NVIDIA Jetson (Yahboom configuration) running Ubuntu Linux. A terminal window is open displaying a sequence of commands executed as the 'jetson' user:

1. `sudo systemctl disable nvzramconfig` — disables the default zram swap configuration
2. `sudo fallocate -l 8G /var/8GB.swap` — allocates an 8GB swap file
3. `sudo mkswap /var/8GB.swap` — formats the file as swap space (with a warning about insecure permissions)
4. `sudo swapon /var/8GB.swap` — activates the swap file
5. `echo "/var/8GB.swap none swap sw 0 0" | sudo tee -a /etc/fstab` — adds the swap file entry to /etc/fstab for persistence across reboots
6. `cat /etc/fstab` — displays the fstab contents to verify the entry was added correctly

The fstab output shows the root filesystem and the newly added swap entry. The desktop has NVIDIA Jetson-related shortcuts on the right side (Jetson Support Forums, L4T-README, Terminal, Jetson Zoo, Jetson Developer Zone, NVIDIA Jetson Community). This is part of a tutorial on expanding exchange (swap) space on the Jetson platform to support memory-intensive tasks like MoveIt2 or AI workloads.
