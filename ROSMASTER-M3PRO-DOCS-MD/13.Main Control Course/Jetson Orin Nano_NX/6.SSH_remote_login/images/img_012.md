## Description
The image shows the MobaXterm terminal application on Windows after successfully establishing an SSH connection to a Jetson device at IP address 192.168.2.199. The main terminal area displays the remote file system directory listing (showing folders like .cache, .config, .dotnet, fontconfig, .gnupg, .python, .jupyter, .keras, .local, .nv, Downloads, Desktop, jetcam, jetson-gpio, etc.). A modal dialog box is displayed in the center asking 'Do you want to save password for jetson@192.168.2.199?' with Yes/No buttons, and a note that MobaXterm will use a Master Password to encrypt stored passwords. The left sidebar shows the remote file browser with the folder tree. At the bottom, there is a notice about the unregistered version of MobaXterm. This screenshot demonstrates the final step of SSH login where the user is prompted to save credentials for future connections.
