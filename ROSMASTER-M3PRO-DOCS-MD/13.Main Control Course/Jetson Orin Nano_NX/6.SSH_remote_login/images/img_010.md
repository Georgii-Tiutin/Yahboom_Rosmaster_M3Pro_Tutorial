MobaXterm SSH session configuration dialog and initial connection prompt for remote login to a robot's system.

## Description
The image shows two stacked screenshots of the MobaXterm application on Windows. The top screenshot displays the 'Session settings' dialog box with the SSH tab selected. Key fields visible include 'Remote host' (with an IP address entered), 'Specify username' checkbox (checked with a username filled in), and sections for 'Basic SSH settings', 'Advanced SSH settings', 'Terminal settings', 'Network settings', and 'Bookmark settings'. The bottom screenshot shows MobaXterm after initiating the SSH connection, displaying a security prompt dialog asking the user to confirm the connection to the remote host for the first time, with options to accept or reject the host key. This is part of a tutorial demonstrating how to set up an SSH remote login session to the robot's onboard computer using MobaXterm as the SSH client.
