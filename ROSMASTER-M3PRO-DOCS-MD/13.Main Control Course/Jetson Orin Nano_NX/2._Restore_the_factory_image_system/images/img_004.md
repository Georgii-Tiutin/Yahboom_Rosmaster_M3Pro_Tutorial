## Caption
DiskGenius software showing how to delete all partitions on a USB disk to prepare for factory image restoration.

## Description
The image contains two stacked screenshots of the DiskGenius V5.6.1.1580 x64 partition management tool on Windows. The top screenshot shows the right-click context menu on a USB disk (Disk 3, ~119.2GB capacity, USB adapter with JMS583 controller) with options including 'Delete All Partitions' highlighted. The disk's partition table is visible showing multiple partitions. The bottom screenshot shows the confirmation dialog box asking 'Are you sure you want to delete all the partitions on a certain disk? All files on it will lose. Select Yes to delete.' with 'Yes' and 'No' buttons, where the user is expected to click 'Yes'. This is part of a tutorial for restoring the factory image system on the robot's storage device, demonstrating the disk preparation step of clearing all existing partitions before writing a new system image.
