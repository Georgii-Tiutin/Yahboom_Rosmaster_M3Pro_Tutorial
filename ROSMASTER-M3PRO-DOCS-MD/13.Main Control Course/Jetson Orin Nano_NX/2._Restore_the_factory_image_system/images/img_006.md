## Description
The image contains two stacked screenshots of DiskGenius V5.6.1.1580 (x64), a Windows partition management and data recovery tool. The top screenshot shows the main interface with the disk tree on the left listing multiple hard drives (including an HD0 system drive at ~932GB, an HD1 WDC drive at ~932GB, and a USB-connected disk via JMS583 adapter at ~119.2GB capacity). The USB disk (Disk 3) is selected, and its properties are displayed on the right side showing adapter type (USB), disk GUID, partition table style (GPT), total sectors, sector size (512 bytes), and other details. The bottom screenshot shows the same interface with a dialog box open titled 'Create ESP and MSR partition'. This dialog asks whether ESP and/or MSR partitions should be created before creating a new partition, with checkboxes for 'Create ESP partition' (with size set to 100 MB) and 'Create MSR partition', along with explanatory text about what these partitions are used for. This is part of a tutorial showing how to prepare a USB drive or storage device for restoring a factory image system on the robot's controller board.
