## Caption
DiskGenius software showing the process of creating a new partition on a USB disk for restoring the robot's factory image system.

## Description
The image contains two stacked screenshots of the DiskGenius partition management and data recovery software. The top screenshot shows the 'Create New Partition' dialog box open, where the user is configuring a new partition on a USB disk (Disk 3, ~119.2GB capacity, USB adapter model jms583). The dialog shows options for partition type (Primary Partition selected), file system type (NTFS), partition size, and other settings, with OK and Cancel buttons highlighted. The left panel displays a disk tree listing multiple hard drives. The bottom screenshot shows the result after the partition has been created, with the new NTFS partition visible in the partition list showing its size, file system, start/end cylinder, head, sector details, and capacity (~119.2GB). The disk details panel at the bottom shows partition table type (MBR/MSDOS), total sectors, and physical sector size information. This is part of a tutorial guiding users through restoring the factory image system on the Yahboom ROSMASTER robot's storage device.
