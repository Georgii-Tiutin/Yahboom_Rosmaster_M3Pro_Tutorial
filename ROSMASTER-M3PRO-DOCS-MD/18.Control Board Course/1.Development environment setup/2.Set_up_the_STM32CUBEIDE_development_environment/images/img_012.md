## Caption
STM32CubeIDE pinout configuration screen showing the Debug mode set to Serial Wire with JTMS-SWDIO pin assignments.

## Description
The image shows the STM32CubeIDE Pinout & Configuration tab within the device configuration tool. On the left side, a hierarchical category tree lists System Core, Analog, Timers, Connectivity, Computing, Middleware, and Trace and Debug sections. The Debug category is selected and expanded, showing the Mode set to 'Serial Wire' with an 'External Trigger Bi-directional' checkbox option. On the right side, a microcontroller pinout visualization displays the chip package with colored pins. Below the categories, a 'Search Signals' table shows the debug pin assignments: PA13 mapped to DEBUG_JTMS-SWDIO and PA14 mapped to another DEBUG signal. The top navigation tabs show Pinout & Configuration (active), Clock Configuration, Project Manager, and Software Packs. This screenshot demonstrates how to configure the SWD (Serial Wire Debug) interface in STM32CubeIDE as part of setting up the development environment for the STM32 control board used in the ROSMASTER M3 Pro robot.
