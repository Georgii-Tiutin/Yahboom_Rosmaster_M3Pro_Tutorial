## Caption
STM32CubeIDE RCC Mode and Configuration panel showing HSE set to Crystal/Ceramic Resonator for the high-speed clock source.

## Description
This screenshot shows the STM32CubeIDE microcontroller configuration tool (STM32CubeMX integrated view). The left sidebar displays the system peripherals tree including System Core, RCC, CORTEX_M7, GPIO, BDMA, DMA, MDMA, NVIC, and WWDG1. The RCC (Reset and Clock Control) peripheral is selected. In the central configuration panel, under 'RCC Mode and Configuration', the High Speed Clock (HSE) is set to 'Crystal/Ceramic Resonator' via a dropdown, while the Low Speed Clock (LSE) is set to 'Disable'. Additional options for Master Clock Output 1, Master Clock Output 2, and Audio Clock Input (I2S_CKIN) are visible. The right side shows the MCU pinout with RCC_OSC_IN and RCC_OSC_OUT pins highlighted. Tabs at the bottom show 'NVIC Settings', 'GPIO Settings', and 'Power Parameters'. The top navigation bar includes tabs for 'Pinout & Configuration', 'Clock Configuration', 'Software Packs', 'Project Manager', and 'Pinout'. This step is part of configuring the STM32 development environment for the Yahboom ROSMASTER M3 Pro robot's control board.
