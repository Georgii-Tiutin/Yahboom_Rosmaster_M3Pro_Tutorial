## Caption
STM32CubeIDE debug configuration dialog showing GDB Hardware Debugging settings for an ST-LINK SWD connection.

## Description
The image shows the STM32CubeIDE (or Eclipse-based IDE) Debug Configurations dialog window. On the left panel, a tree list displays various debug configuration types including C/C++ Application, C/C++ Attach to Application, C/C++ Postmortem Debugger, C/C++ Remote Application, GDB Hardware Debugging, Launch Group, and STM32 C/C++ Application, with 'Led Debug' selected under GDB Hardware Debugging. The right panel shows the 'Debugger' tab selected, containing GDB Connection Settings with options for connecting to a remote GDB server or autostarting a local GDB server (set to localhost, port 61234). Below that is the Debug probe section set to 'ST-LINK (ST-LINK GDB server)' with SWD interface selected and additional options for frequency and reset behavior. This configuration is part of the tutorial for burning STM32 firmware using SWD (Serial Wire Debug), showing users how to set up the debug connection parameters.
