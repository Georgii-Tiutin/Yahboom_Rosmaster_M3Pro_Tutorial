## Description
A top-down rendered photograph/diagram of the Yahboom YB-ERF02-V1.0 STM32 control board used in the ROSMASTER M3 Pro robot. The board features numerous labeled connectors and components including: SWD header pins (SWDIO, GND, SWCLK, 3U3) highlighted in the center-upper area for firmware burning, CAN bus connector, IMU chip, RGB LED header, SBUS input, voltage choose jumper, motor connectors along the bottom, 5VOUT1 and 5VOUT2 power output ports on the left, an I2C header (SCL, SDA), S1/S2 buttons, and various other peripheral connectors. The board name 'YAHBOOM YB-ERF02-V1.0' is printed in the center. This image serves as a reference for locating the SWD programming pins needed to flash STM32 firmware via an SWD debugger.
