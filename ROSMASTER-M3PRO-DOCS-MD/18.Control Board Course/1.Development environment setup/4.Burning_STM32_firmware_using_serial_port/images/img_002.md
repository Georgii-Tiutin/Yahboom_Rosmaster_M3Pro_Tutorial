## Caption
Yahboom YB-ERF02-V1.0 STM32 control board with labeled connectors and interfaces used in the ROSMASTER robot platform.

## Description
A top-down 3D render of the Yahboom YB-ERF02-V1.0 STM32 control board PCB. The black circuit board features numerous labeled connectors and components:

- Top edge: Ethernet/RJ45 port, SWD debug header (SWDIO, GND, SWCLK, 3V3), CAN bus connector, I2C pins (SDA, SCL), RGB header, SBUS connector, and S1/S2 signal pins
- Left side: LED indicators, a buzzer (Beep), IO connector, power barrel jack, and two 5V output connectors (5VOUT1, 5VOUT2) with red JST and barrel connectors
- Center: IMU chip, the board name silkscreen reading 'YAHBOOM YB-ERF02-V1.0'
- Bottom edge: Motor connectors (white multi-pin headers) for driving the Mecanum wheel motors
- Right side: Voltage selector switch (6V8/5V), ND6US3 connectors (yellow), USB HOST port
- Various capacitors, voltage regulators, and SMD components are visible across the board

This image serves as a reference photo for identifying the STM32 control board and its port layout before performing firmware burning via serial port.
