## Caption
Pin configuration diagram of the STM32H743VGTx microcontroller in LQFP100 package, showing all pin assignments used on the ROSMASTER M3 Pro control board.

## Description
This image shows a top-down pinout diagram of the STM32H743VGTx microcontroller in an LQFP100 (100-pin Low-Profile Quad Flat Package). The chip is rendered as a large gray square with the ST Microelectronics logo and part number in the center. Pins are arranged along all four sides, each labeled with its assigned function from the STM32CubeMX or similar configuration tool.

Key pin assignments visible include:
- Multiple UART/USART interfaces (USART1-5, UART4, UART7) for serial communication with peripherals such as ROS nodes and sensors
- SPI buses (SPI2, SPI4) for high-speed peripheral communication
- Timer channels (TIM1, TIM3, TIM5, TIM8) used for PWM motor control and encoder inputs for the Mecanum wheel chassis
- FDCAN interface (FDCAN1_TX, FDCAN1_RX) for CAN bus communication
- USB OTG FS (Full Speed) data lines (DP/DM) and VBUS
- OLED display interface pins (OLED_SDA, OLED_SCL)
- GPIO pins for LEDs (LED_MCU, LED_ROS, LED_SW), a buzzer (BEEP), RGB output, a button (KEY1), and battery monitoring (BAT)
- Debug interface (DEBUG_JTMS-SWDIO, DEBUG_JTC)
- IMU interrupt pin (IMU_INT)
- Crystal oscillator pins (RCC_OSC_IN, RCC_OSC_OUT)

Pins are color-coded: green for configured/active pins and yellow/white for power and special-function pins (VDD, VSS, VDDA, VCAP, etc.). This diagram serves as a reference for understanding how the STM32H743 MCU on the ROSMASTER M3 Pro control board connects to motors, sensors, communication buses, and user interface elements.
