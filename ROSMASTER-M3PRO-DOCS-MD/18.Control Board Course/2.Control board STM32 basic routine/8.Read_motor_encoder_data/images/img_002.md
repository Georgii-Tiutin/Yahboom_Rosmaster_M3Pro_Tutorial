## Caption
Schematic diagram of the STM32 motor driver circuit showing four motor connectors (M1–M4) with encoder interfaces and motor driver chips.

## Description
This image shows a hardware schematic from the STM32 control board section of the ROSMASTER M3 Pro tutorial. The top portion displays four 6-pin PH-6P connectors (J8, J9, J4, J6) for motors M1 through M4, each providing M+, M-, GND, VCC, and two encoder signal lines (A/B) with pull-up resistors. The middle section shows the motor driver chip circuitry (labeled 'Motor driver chip' in red text), featuring AM2857 driver ICs with associated capacitors and filtering components for each motor channel. The bottom-left portion shows the STM32 microcontroller pin assignments, mapping GPIO pins (PB5, PB4, PB3, PD7, PD6, PD5, PD4, PD3, PD2, PD1, PD0, PC12, PC11, PC10, PA15, PD13, PD12) to the encoder input signals (H1A, H1B, H2A, H2B, H3A, H3B, H4A, H4B) and other peripherals. This diagram is essential for understanding how encoder data from the four Mecanum wheel motors is read by the STM32 control board.
