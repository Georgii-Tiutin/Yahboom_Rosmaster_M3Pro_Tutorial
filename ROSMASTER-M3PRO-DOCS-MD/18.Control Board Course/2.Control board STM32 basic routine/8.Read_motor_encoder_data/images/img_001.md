## Description
A top-down photograph of the Yahboom ROSMASTER M3 Pro robot with its cover removed, exposing the internal electronics. The robot has four Mecanum wheels at each corner. Red text labels and arrows annotate the four motor connector positions: M1 (front-left), M2 (rear-left), M3 (rear-right), and M4 (front-right). A USB-TypeC port on the STM32 control board is also labeled. The main controller board (Jetson module with a cooling fan) is visible in the center, along with various wiring and connectors. This image serves as a hardware reference for identifying motor encoder connections in the tutorial on reading motor encoder data.
