## Caption
STM32CubeMX GPIO configuration for I2C pins (PB10/SCL, PB11/SDA) used to drive an OLED display.

## Description
The image shows the STM32CubeMX IDE's GPIO Mode and Configuration panel. On the left side, the System Core category tree is expanded showing peripherals like BDMA, CORTEX_M7, DMA, GPIO, IWDG1, MDMA, NVIC, RAMECC, RCC, SYS, and WWDG1, with GPIO selected. The main area displays a pin configuration table listing three modified pins: PB10 configured as High Output with Pull-up (labeled SCL), PB11 configured as High Output with Pull-up (labeled SDA), and PC13 configured as Low Output with No pull (labeled LED). At the top right, a small chip pin diagram shows the VCAP, PB11/SDA, PB10, and SCL pin assignments. The bottom section shows the detailed PB11 Configuration with GPIO output level set to High, GPIO mode set to Output Push-Pull, Pull-up/Pull-down set to Pull-up, Maximum output speed set to High, and User Label set to SDA. This configuration sets up the I2C communication pins for connecting an OLED display to the STM32 microcontroller.
