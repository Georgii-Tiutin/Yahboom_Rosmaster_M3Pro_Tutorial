## Description
A close-up photograph of a small OLED display module mounted on the STM32 control board of the ROSMASTER M3 Pro robot. The OLED screen has a dark background with white text displaying two lines: "Hello Yahboom" on the first line and "count:97" on the second line, indicating a running counter program. The display is connected via I2C pins (SDA, SCL, VCC, GND) visible on the blue terminal block to the left. Surrounding the OLED module are various board components including capacitors, connectors (SBUS, S1, S2), a voltage selector, and yellow XT connectors. A red arrow annotation points to the voltage chooser area on the board. This image demonstrates the successful output of the OLED display driving tutorial on the STM32 expansion board.
