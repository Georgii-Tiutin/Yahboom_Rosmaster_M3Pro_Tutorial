## Caption
STM32CubeMX USART1 serial port configuration showing pin assignments, NVIC interrupt settings, and communication parameters.

## Description
The image shows the STM32CubeMX IDE configuration interface for setting up the USART1 serial port on an STM32 microcontroller. At the top, pin assignments are displayed: PA10 mapped to USART1_RX and PA9 mapped to USART1_TX (highlighted in green). Below that, the NVIC Settings tab shows the USART1 global interrupt enabled with preemption and sub priority both set to 0. The right side displays the Mode panel with Asynchronous mode selected, Hardware Flow Control (RS232) disabled, and Slave Select (NSS) Management disabled. The left sidebar shows the Connectivity category expanded, listing available peripherals (ETH, FDCAN1, FDCAN2, FMC, I2C1-I2C4, LPUART1, MDIOS, QUADSPI, SDMMC1, etc.). The Configuration section at the bottom shows Parameter Settings with Basic Parameters: Baud Rate 115200 Bits/s, Word Length 8 Bits (including Parity), Parity None, Stop Bits 1; and Advanced Parameters: Data Direction Receive and Transmit, Over Sampling 16 Samples, Single Sample Disable, ClockPrescaler 1. This is part of the STM32 control board serial communication tutorial for the ROSMASTER M3 Pro robot platform.
