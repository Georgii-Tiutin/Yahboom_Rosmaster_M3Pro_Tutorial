## Description
A top-down photograph of the Yahboom ROSMASTER M3 Pro robot platform with its cover removed, exposing the internal electronics including the STM32 control board, Jetson compute module with cooling fan, and wiring. Four Mecanum wheels are visible at the corners of the chassis. Red annotation lines and labels identify the four drive motors: M1 (front-left), M2 (rear-left), M3 (rear-right), and M4 (front-right). This image introduces the motor numbering convention used in the robot kinematics analysis tutorial, establishing which motor corresponds to which wheel position for subsequent kinematic equations.
