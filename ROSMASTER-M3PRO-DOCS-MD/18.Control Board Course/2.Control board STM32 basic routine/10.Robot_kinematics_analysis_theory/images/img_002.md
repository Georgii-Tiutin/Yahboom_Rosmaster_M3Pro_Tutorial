## Caption
Wiring schematic showing PH-6P connector pinouts for four motor channels with encoder feedback connections.

## Description
The image displays four identical wiring diagrams arranged in a 2x2 grid, each representing a motor connection through PH-6P connectors (J8, J9, J4, J6). Each diagram shows a 6-pin connector with the following signals: M+ (motor positive), M- (motor negative), GND (ground), +3.3V (logic power), H2A and H2B (quadrature encoder channels A and B). The encoder lines pass through pull-up resistors (R44/R40, R51/R53, R35/R37, R41/R42) connected to VCC. The four connectors correspond to the four Mecanum wheel motors (M1+/M1-, M2+/M2-, M3+/M3-, M4+/M4-), providing both power drive and encoder feedback for closed-loop speed control on the STM32 control board.
