STM32CubeMX pin configuration for PC13 as GPIO output to control an onboard LED labeled LED_MCU.

## Description
The image shows the STM32CubeMX IDE interface for configuring the PC13 pin on an STM32 microcontroller. On the left sidebar, the System Core peripherals tree is visible with GPIO selected. The main panel displays a pin table showing PC13 configured as a GPIO Output with Low initial level, Output Push Pull mode, no pull-up/pull-down, and Low maximum output speed, with the user label set to LED_MCU. Below the configuration panel, auto-generated C code defines are shown: #define LED_MCU_Pin GPIO_PIN_13 and #define LED_MCU_GPIO_Port GPIOC, along with the beginning of a void MX_GPIO_Init(void) function. This is from a tutorial on turning on an LED using the STM32 control board on the Yahboom ROSMASTER M3 Pro robot.
