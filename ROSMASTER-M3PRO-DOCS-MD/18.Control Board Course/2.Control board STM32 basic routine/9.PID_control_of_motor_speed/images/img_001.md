## Description
A top-down photograph of the Yahboom ROSMASTER M3 Pro Mecanum wheel robot chassis with annotated labels. The robot is shown without its top cover, exposing the internal electronics including the STM32 control board at the top, a Jetson Nano compute module with cooling fan in the center, and various connectors. Red arrows and labels identify the four Mecanum wheel motors: M1 (front-left), M2 (rear-left), M3 (rear-right), and M4 (front-right). A USB-TypeC port on the STM32 board is also labeled, which is used for programming and communication. This annotated photo serves as a hardware reference for the PID motor speed control tutorial, helping users identify which motor corresponds to which designation on the control board.
