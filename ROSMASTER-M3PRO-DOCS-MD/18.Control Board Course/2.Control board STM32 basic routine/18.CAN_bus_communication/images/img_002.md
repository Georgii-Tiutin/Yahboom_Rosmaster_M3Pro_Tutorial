## Description
The image shows a configuration panel from STM32CubeMX IDE for setting up FDCAN (Flexible Data-rate CAN) peripheral basic parameters. The panel displays several configuration fields:
- Frame Format: set to 'Classic mode'
- Mode: highlighted with a red border, currently set to 'Normal mode' with a dropdown expanded showing available options: Normal mode, Restricted operation, Bus Monitoring mode, Internal LoopBack mode, and External LoopBack mode
- Auto Retransmission
- Transmit Pause
- Protocol Exception
- Nominal Sync Jump Width
- Data Prescaler

The dropdown menu for Mode is the focal point, illustrating the different CAN bus operating modes available for configuration. This is part of a tutorial on CAN bus communication, demonstrating how to configure the STM32 microcontroller's FDCAN peripheral modes in the STM32CubeMX graphical configuration tool.
