## Description
The image shows the STM32CubeMX IDE Parameter Settings tab for configuring an FDCAN (Flexible Data-rate CAN) peripheral. The top of the panel has tabs for Parameter Settings, User Constants, NVIC Settings, and GPIO Settings. Below is a list of Basic Parameters including: Frame Format set to 'Classic mode', Mode set to 'Internal Loopback mode' (highlighted in blue), Auto Retransmission set to Disable, Transmit Pause set to Disable, Protocol Exception set to Enable, Nominal Sync Jump Width set to 1, Data Prescaler set to 3, Data Sync Jump Width set to 10, Data Time Seg1 set to 29, Data Time Seg2 set to 0, Message Ram Offset set to 0, Std Filters Nbr set to 1, Ext Filters Nbr set to 0, Rx Fifo0 Elmts Nbr set to 0 with 8 bytes data field size, Rx Fifo1 Elmts Nbr set to 0 with 8 bytes data field size, Rx Buffers Nbr set to 0 with 8 bytes buffer size, Tx Events Nbr set to 0, Tx Buffers Nbr set to 0, Tx Fifo Queue Elmts Nbr set to 1 with FIFO mode and 8 bytes data field element size. This configuration page is part of the CAN bus communication tutorial, demonstrating how to set up the FDCAN peripheral parameters in STM32CubeMX for testing CAN communication in loopback mode on the STM32 control board.
