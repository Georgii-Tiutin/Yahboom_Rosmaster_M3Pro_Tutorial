## Caption
STM32CubeMX SPI4 configuration for driving an RGB LED strip via DMA, showing mode, clock, and advanced parameter settings.

## Description
The image shows the STM32CubeMX IDE configuration interface for the SPI4 peripheral, used to drive an RGB light strip. On the left side is the peripheral category tree with 'Connectivity' expanded, showing SPI4 selected (checked). The top area displays tabs for User Constants, NVIC Settings, DMA Settings, GPIO Settings, and Parameter Settings. A DMA request is configured: SPI4_TX on DMA1 Stream 0, Memory To Peripheral direction, Low priority. The right panel shows SPI4 Mode and Configuration: Mode is set to 'Transmit Only Master' with Hardware NSS Signal disabled. Below, the Parameter Settings section lists Basic Parameters (Frame Format: Motorola, Data Size: 8 Bits, First Bit: MSB First), Clock Parameters (Prescaler for Baud Rate: 32, Baud Rate: 3.75 MBits/s, Clock Polarity CPOL: Low, Clock Phase CPHA: 1 Edge), and Advanced Parameters (CRC Calculation: Disabled, NSSP Mode: Enabled, NSS Signal Type: Software, various initialization patterns). This configuration is part of the STM32 control board tutorial for setting up SPI-based communication to control WS2812-style RGB LED strips using DMA transfers.
