## Caption
STM32CubeMX SPI2 configuration interface and corresponding initialization code for reading IMU data.

## Description
The image shows the STM32CubeMX IDE configuration panel for SPI2 peripheral setup. The left sidebar displays the peripheral categories (System Core, Analog, Timers, Connectivity) with the Connectivity section expanded showing various interfaces (ETH, FDCAN1/2, I2C1-4, LPUART1, MDIOS, QUADSPI, SDMMC1/2, SPI1-6, USART1-3, UART4-5). SPI2 is selected and highlighted. The main panel shows SPI2 Mode set to Full-Duplex Master with Hardware NSS Signal Disabled. The Configuration section has tabs for NVIC Settings, DMA Settings, and GPIO Settings, with Parameter Settings active. Basic Parameters show Frame Format as Motorola, Data Size as 8 Bits, and First Bit as MSB First. Clock Parameters show Prescaler set to 256, Baud Rate of 750.0 KBits/s, Clock Polarity (CPOL) as High, and Clock Phase (CPHA) as 2 Edge. Advanced Parameters include CRC Calculation Disabled, NSSP Mode Enabled, and NSS Signal Type as Software. Below the configuration panel is the corresponding C initialization function (MX_SPI2_Init) showing the HAL SPI configuration code with matching parameter values. This is part of the STM32 control board tutorial for configuring SPI2 to communicate with an IMU sensor.
