## Caption
Serial terminal (Uart Assistant) displaying real-time IMU sensor data including accelerometer, gyroscope, and magnetometer readings over COM4 at 115200 baud.

## Description
The image shows a Windows 'Uart Assistant' serial monitor application connected to an IMU sensor via COM4 at 115200 baud. The left panel contains COM configuration settings (Channel: COM4, Baudrate: 115200, Paritybits: NONE, Databits: 8, Stopbits: 1, Flowctrl: NONE) and receive options (ASCII mode, Log display mode, Auto linefeed enabled). The right panel ('Data log' tab) displays timestamped IMU data packets received in ASCII format. Each packet contains three lines of sensor readings:
- Axises Accel: three-axis accelerometer values (in g)
- Axises Gyro: three-axis gyroscope values (in rad/s or deg/s)
- Axises Mag: three-axis magnetometer values (in microtesla)
Multiple timestamped readings are shown from 2025-07-03 20:39:09, demonstrating continuous streaming of IMU data from the STM32 control board. This screenshot illustrates how to verify IMU data output by reading raw serial data in a tutorial about reading IMU sensor data on the ROSMASTER M3 Pro robot platform.
