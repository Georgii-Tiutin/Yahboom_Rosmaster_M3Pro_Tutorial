STM32 microcontroller pin mapping diagram showing IMU and SPI2 interface connections for reading IMU sensor data.

## Description
The image shows a pinout diagram of an STM32 microcontroller highlighting the specific GPIO pins used for IMU (Inertial Measurement Unit) data communication. On the left side, a vertical row of pins is labeled with their port designations and functions:
- PD11 (unlabeled function)
- PD10 — IMU_INT (IMU interrupt signal, highlighted in red)
- PD9 — USART3_RX (serial receive)
- PD8 — USART3_TX (serial transmit)
- PB15 — S1
- PB14 — S2
- PB13 — SPI2_SCK (SPI clock, highlighted in red)
- PB12 — SPI2_NSS (SPI chip select, highlighted in red)

On the right side, additional pins are shown:
- PC1 — LED_SW (LED switch)
- PC2 — SPI2_MISO (SPI data in)
- PC3 — SPI2_MOSI (SPI data out)
- VSSA (analog ground)

The red-highlighted pins (PD10, PB13, PB12) indicate the key connections for the IMU sensor interface. The diagram shows that the IMU communicates with the STM32 via the SPI2 bus (using SCK, NSS, MISO, MOSI signals) with an additional interrupt line (IMU_INT). This is part of a tutorial on reading IMU data from the STM32 control board on the ROSMASTER M3 Pro robot platform.
