## Description
A top-down photo/render of the Yahboom YB-ERF02-V1.0 STM32 control board used in the ROSMASTER M3 Pro robot. The board features various labeled connectors and components including: charging port, CAN bus header, SWD debug pins, IMU sensor, RGB LED header, SBUS receiver pins, voltage selection jumper (5V/3.3V), motor output connectors, 5VOUT1 and 5VOUT2 power output ports, and a buzzer. A red rectangle highlights the USB HOST port on the lower-right area of the board, indicating where a USB game controller should be connected for remote control functionality. The board is black with white silkscreen labels and the Yahboom branding is printed in the center.
