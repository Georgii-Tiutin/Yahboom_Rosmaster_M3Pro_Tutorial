## Caption
Serial terminal displaying real-time battery voltage readings from the STM32 control board over UART at 115200 baud.

## Description
The image shows a UART serial monitor application with two panels. The left panel contains COM configuration settings (Channel: COM4, Baudrate: 115200, Paritybits: NONE, Databits: 8, Stopbits: 1, Flowctrl: NONE) and receive options (ASCII mode, Log display mode, Auto linefeed enabled). The right panel ('Data log') displays timestamped serial output lines received from the STM32 microcontroller. Each line follows the format 'voltage:<raw_ADC_value>, <single_cell_voltage>, <total_battery_voltage>' — for example 'voltage:3914, 3.154980, 12.708078'. The raw ADC reading is approximately 3912–3916, the calculated single-cell voltage is around 3.15 V, and the total 4-cell battery pack voltage is approximately 12.7 V. A red arrow annotation in the lower-right corner highlights the latest voltage reading. This screenshot demonstrates how to verify battery voltage detection output from the STM32 control board in the Yahboom ROSMASTER M3 Pro tutorial.
