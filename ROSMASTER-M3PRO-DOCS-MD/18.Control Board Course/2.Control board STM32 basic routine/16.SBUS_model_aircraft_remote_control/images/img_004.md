## Caption
STM32CubeMX USART2 peripheral configuration showing asynchronous mode settings for SBUS remote control communication.

## Description
Screenshot of the STM32CubeMX IDE showing the USART2 Mode and Configuration panel. The left sidebar displays the Connectivity category expanded, listing various peripherals (ETH, FDCAN1/2, FMC, I2C1-4, LPUART1, MDIOS, QUADSPI, SDMMC1/2, SPI1-4/6, SWPMI1, UART4/5/7/8, USART1-3) with LPUART1 and USART2 checked/enabled (green checkmarks). The right panel shows USART2 configured in Asynchronous mode with Hardware Flow Control (RS232) disabled, Hardware Flow Control (RS485) unchecked, and Slave Select (NSS) Management disabled. Below, the Configuration section has tabs for NVIC Settings, DMA Settings, GPIO Settings, Parameter Settings, and User Constants. The Basic Parameters show: Baud Rate 100000 Bits/s, Word Length 9 Bits (including Parity), Parity Even, Stop Bits 2. Advanced Parameters include Data Direction set to Receive and Transmit, Over Sampling 16 Samples, Single Sample Disable, ClockPrescaler 1, FIFO Mode Disable, TxFIFO Threshold and RxFIFO Threshold both set to 1 eighth full configuration. These UART settings (100000 baud, 8E2 framing) correspond to the SBUS protocol used by model aircraft remote controllers.
