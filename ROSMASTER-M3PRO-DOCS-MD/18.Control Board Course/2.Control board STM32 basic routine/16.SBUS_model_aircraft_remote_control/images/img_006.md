## Caption
Serial terminal (Uart Assist) displaying decoded SBUS channel values from a model aircraft remote control receiver.

## Description
The image shows a Windows serial terminal application called 'Uart Assist' connected via COM4 at 115200 baud (8N1, no flow control). The left panel contains COM configuration settings (Channel: COM4, Baudrate: 115200, Parity: NONE, Databits: 8, Stopbits: 1, Flowctrl: NONE) and receive/send options set to ASCII mode with auto linefeed and log display mode enabled. The right 'Data log' panel displays repeating lines of eight comma-separated SBUS channel values: 992, 976, 984, 984, 992, 1792, 992, 992. Each line represents a parsed SBUS frame with 8 channel readings. Most channels hover near their center value (~992), while channel 6 reads 1792, indicating one control input (likely a switch) is in a non-center position. This demonstrates the STM32 board successfully decoding SBUS protocol data from the RC receiver and outputting parsed channel values over UART for debugging.
