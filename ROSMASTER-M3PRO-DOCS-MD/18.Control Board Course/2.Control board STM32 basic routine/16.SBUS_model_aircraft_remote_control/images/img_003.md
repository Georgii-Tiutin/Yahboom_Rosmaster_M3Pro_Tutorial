## Description
The image shows an STM32CubeMX IDE configuration panel for USART2. At the top, the USART2_TX pin is assigned to PA2 and USART2_RX is assigned to PA3, displayed with green pin indicator blocks. Below is a tabbed settings interface with tabs for NVIC Settings, DMA Settings, GPIO Settings, Parameter Settings, and User Constants. The NVIC Settings tab is currently selected, showing the NVIC Interrupt Table with a single entry: 'USART2 global interrupt' which is enabled (checked), with Preemption Priority set to 0 and Sub Priority set to 0. This configuration is part of setting up USART2 for SBUS receiver communication on the STM32 control board, enabling the interrupt-driven reception of remote control data from a model aircraft transmitter.
