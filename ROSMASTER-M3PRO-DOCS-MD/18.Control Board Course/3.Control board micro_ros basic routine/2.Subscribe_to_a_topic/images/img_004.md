## Caption
STM32CubeMX USART1 configuration interface showing asynchronous serial communication settings at 2000000 baud.

## Description
The image shows the STM32CubeMX IDE configuration screen for USART1 (Universal Synchronous/Asynchronous Receiver-Transmitter 1). On the left side is a peripheral navigation tree listing categories such as Analog, Timers, Connectivity (expanded to show ETH, FDCAN1, FDCAN2, FMC, I2C1-I2C4, USART1, etc.). The main panel displays the USART1 Mode and Configuration. The Mode section sets the interface to Asynchronous with Hardware Flow Control disabled for both RS232 and RS485. The Configuration area is organized into tabs: Parameter Settings, User Constants, NVIC Settings, DMA Settings, and GPIO Settings. Under Basic Parameters: Baud Rate is set to 2000000 Bits/s, Word Length to 8 Bits (including Parity), Parity to None, and Stop Bits to 1. Under Advanced Parameters: Data Direction is Receive and Transmit, Over Sampling is 16 Samples. Additional advanced fields show Single Sample as Disable, ClockPrescaler as 1, Fifo Mode as Disable, and TX/RX FIFO Threshold values. At the bottom, the DMA Settings tab is visible showing DMA requests for USART1_RX (DMA1 Stream 0, Peripheral To Memory, Low priority) and USART1_TX (DMA1 Stream 1, Memory To Peripheral, Low priority). This configuration is part of the STM32 control board setup for serial communication used in the robot's topic subscription tutorial.
