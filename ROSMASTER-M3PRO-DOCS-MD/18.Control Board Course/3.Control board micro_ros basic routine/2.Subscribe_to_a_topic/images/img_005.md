## Caption
STM32CubeMX UART configuration interface showing UART5 peripheral settings including baud rate, word length, parity, and advanced parameters.

## Description
The image shows the STM32CubeMX IDE configuration screen for a UART peripheral (UART5). On the left side is a navigation tree listing various connectivity peripherals including ETH, FDCAN1/2, FMC, I2C1-4, LPUART1, MDIOS, QUADSPI, SDMMC1/2, SPI1-4/6, SWPMI1, UART4, UART5, and USART interfaces. UART5 is selected and highlighted. The center panel shows the mode configuration with 'Asynchronous' mode selected, Hardware Flow Control (RS232) set to 'Disable', and Hardware Flow Control (RS485) with a checkbox. The right panel displays the 'Parameter Settings' tab with Basic Parameters (Baud Rate: 115200 Bits/s, Word Length: 8 Bits including Parity, Parity: None, Stop Bits: 1), Advanced Parameters (Data Direction: Receive and Transmit, Over Sampling: 16 Samples, Single Sample: Disable, ClockPrescaler, Fifo Mode: FIFO mode disable, TxFifo Threshold: 1/8th fifo configuration, RxFifo Threshold: 1/8th fifo configuration), and Advanced Features section with Auto BaudRate and other options set to Disable. This is part of the STM32 control board tutorial for configuring UART communication used in micro-ROS topic subscription.
