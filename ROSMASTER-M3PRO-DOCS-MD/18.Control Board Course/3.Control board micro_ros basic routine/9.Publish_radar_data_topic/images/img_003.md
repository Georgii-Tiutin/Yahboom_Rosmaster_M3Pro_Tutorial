## Caption
RViz2 interface showing LiDAR laser scan data visualization with the Displays panel configured for a LaserScan topic.

## Description
The image shows the RViz2 visualization tool with two main areas. On the left is the Displays panel containing configuration options: Global Options (Fixed Frame, Background Color, Frame Rate), a RobotModel display with Status OK, and a LaserScan display configured with style 'Flat Squares', size 0.01m, Alpha 1, and subscribed to a sensor_msgs/msg/LaserScan topic. The LaserScan display uses rainbow color transform based on intensity. On the right is the 3D viewport showing scattered white/colored dots representing LiDAR point data against a dark background, depicting the radar scan output from the robot's LiDAR sensor. A red highlight box appears around the LaserScan entry in the Displays panel, indicating this is the key configuration step being demonstrated in the tutorial.
