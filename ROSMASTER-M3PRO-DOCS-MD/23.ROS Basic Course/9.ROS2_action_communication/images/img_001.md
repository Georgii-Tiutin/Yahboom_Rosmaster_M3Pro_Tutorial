## Caption
ROS2 Action communication architecture showing the interaction between an Action Client node and an Action Server node through Goal Service, Feedback Topic, and Result Service.

## Description
The diagram illustrates the ROS2 Action communication mechanism with two main nodes enclosed in blue circles on opposite sides. On the left is the Action Client NODE containing three components: Goal Service Client (green), Feedback Subscriber (yellow), and Result Service Client (orange). On the right is the Action Server NODE containing three corresponding components: Goal Service Server (green), Feedback Publisher (yellow), and Result Service Server (orange). In the center, a gray rectangular area labeled 'Action' shows the three communication channels connecting them: a Goal Service (top) with Request and Response arrows, a Feedback Topic (middle) carrying feedback data, and a Result Service (bottom) also with Request and Response arrows. The Goal Service and Result Service use the service (request/response) pattern, while Feedback uses the topic (publish/subscribe) pattern. This diagram serves as a conceptual overview of how ROS2 actions combine services and topics to support long-running tasks with progress feedback.
