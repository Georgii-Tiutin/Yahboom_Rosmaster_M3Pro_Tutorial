## Caption
RViz2 interface displaying the ROSMASTER M3 Pro robot model with LiDAR scan data visualization.

## Description
The screenshot shows the ROS2 RViz2 visualization tool with the ROSMASTER M3 Pro robot's URDF model rendered in the 3D viewport. On the left panel, the Displays section shows configured visualization plugins including a LaserScan display (Topic: /scan) with settings for style (Flat Squares), size, alpha, and color transform (Intensity with rainbow coloring), and a RobotModel display showing status, visual/collision enabled options, and links. The right side contains the 3D view showing the robot's Mecanum wheel chassis with its mechanical structure visible, surrounded by red LiDAR scan points forming a horizontal ring pattern around the robot. The top toolbar shows camera interaction controls (Interact, Move Camera, Select, Focus Camera). At the bottom, the Description Topic field indicates where the URDF filepath is published. The Views panel on the right shows the current camera view settings.
