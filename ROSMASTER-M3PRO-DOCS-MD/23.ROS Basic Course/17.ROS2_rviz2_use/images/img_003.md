## Caption
RViz2 'Create visualization' dialog showing available display type plugins for adding to the 3D view.

## Description
Screenshot of the ROS2 RViz2 application with the 'Create visualization' dialog open in the center. The left panel shows the Displays sidebar with Global Options (Fixed Frame set to 'map', Background Color as dark gray 48;48;48, Frame Rate 30) and a Global Status warning about 'No tf data'. The main 3D viewport behind the dialog shows an empty dark scene with a grid floor.

The dialog itself is titled 'Create visualization' and offers two tabs: 'By display type' (selected) and 'By topic'. It lists available display plugins from rviz_default_plugins including: Axes, Camera, FluidPressure, Grid, GridCells, Illuminance, Image, InteractiveMarkers, LaserScan, Map, Marker, MarkerArray, Odometry, and Path. Each plugin has a colored icon. At the bottom of the dialog is a Description area and a 'Display Name' field. This dialog is used to add new visualization components to the RViz2 scene.
