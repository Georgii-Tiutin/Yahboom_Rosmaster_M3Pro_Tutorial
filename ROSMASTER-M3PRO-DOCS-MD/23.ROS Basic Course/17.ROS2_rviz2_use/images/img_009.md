## Caption
RViz2 'Create visualization' dialog showing available display types that can be added to the 3D visualization window.

## Description
The image shows the RViz2 'Create visualization' dialog box in a Linux desktop environment. The dialog has two tabs at the top: 'By display type' and 'By topic', with 'By display type' currently selected. A tree view lists available visualization plugins organized by package: octomap_rviz_plugins, rtabmap_rviz_plugins, rviz_common, and rviz_default_plugins (which is expanded). Under rviz_default_plugins, various display types are listed with icons: Axes, Camera, FluidPressure, Grid, GridCells, Illuminance, Image, InteractiveMarkers, LaserScan, Map, and Marker. The bottom of the dialog has a 'Description' area, a 'Display Name' text field, and Cancel/OK buttons. This screenshot demonstrates how users add visualization displays in RViz2 as part of a ROS2 tutorial on using the RViz2 tool.
