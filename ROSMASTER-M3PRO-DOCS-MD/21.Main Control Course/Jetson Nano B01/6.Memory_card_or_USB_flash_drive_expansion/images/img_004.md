## Description
The screenshot shows the GParted Partition Editor running on a Linux desktop (likely Jetson with MAXN mode indicated in the top bar). The main window displays the partition layout for /dev/mmcblk0 (29.72 GiB eMMC storage) with a single partition /dev/mmcblk0p1 taking up 29.71 GiB. A confirmation dialog box is overlaid in the center, warning 'Are you sure you want to apply the pending operations?' with a caution that editing partitions has the potential to cause LOSS of DATA and advising to backup data before proceeding. Two buttons are shown: 'Cancel' and 'Apply' (highlighted with a red border in the tutorial). The bottom status bar shows a pending operation to grow /dev/mmcblk0p1 from 26.57 GiB to 29.71 GiB. This is part of a tutorial on expanding storage on the Jetson's memory card or eMMC.
