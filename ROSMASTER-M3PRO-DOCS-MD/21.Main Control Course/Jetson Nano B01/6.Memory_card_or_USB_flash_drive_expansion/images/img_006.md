## Description
The image shows a Linux desktop environment on a Jetson (NVIDIA Jetson Nano/Orin) running the Yahboom robot platform. A terminal emulator window is open displaying the output of the 'df -h' command, which lists all mounted filesystems with their sizes, used space, available space, and usage percentages. The main partition /dev/mmcblk0p1 (the eMMC/SD card) shows 30G total with 19G used (68% usage), indicating limited remaining storage space. Other standard Linux virtual filesystems (tmpfs, udev, /dev/shm, /run, etc.) are also listed. The top bar shows system stats including CPU at 16%, memory at 31%, and network transfer rates. This screenshot serves as a 'before' reference in the tutorial context of expanding storage via memory card or USB flash drive, demonstrating the need for additional storage space on the Jetson board.
