## Description
Screenshot of the GParted Partition Editor running on a Jetson Linux desktop (MAXN mode visible in the top bar). The main window displays the disk layout for /dev/mmcblk0 (29.72 GiB total), showing two regions: a primary ext4 partition (/dev/mmcblk0p1) occupying approximately 20.57 GiB, and an unallocated region of about 9.14 GiB. A right-click context menu is open over the partition with options including Unmount, Resize/Move (highlighted with a red arrow indicating this is the next step), Name Partition, Manage Flags, and Information. The partition table at the bottom lists the partition details including filesystem type (ext4), size (1.14 GiB used), and flags. This screenshot demonstrates how to use GParted to expand the root partition on the Jetson's eMMC or SD card to utilize all available storage space, which is a common setup step after flashing the system image.
