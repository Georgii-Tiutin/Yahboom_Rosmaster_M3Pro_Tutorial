## Description
Screenshot of the jtop (Jetson TOP) terminal-based system monitoring tool running on an NVIDIA Jetson Nano Developer Kit with Jetpack 4.6.3 (L4T 32). The interface displays real-time system metrics in a color-coded terminal layout:

- **Top bar**: Shows MAX_N power mode, CPU usage at 11.9%, and GPU usage at 14.2%.
- **CPU cores**: Four CPU cores are listed with individual utilization bars and frequencies (cores at 825MHz–1.3GHz, usage ranging from ~19–30%).
- **Memory (mem)**: A horizontal bar showing RAM usage, which appears nearly full (indicated by a long filled bar).
- **Swap (swp)**: The swap space bar appears minimal or empty, which is the key observation for this tutorial — the swap space needs to be increased.
- **EMC**: Shows RUNNING status.
- **Fan**: 0.0% speed. Jetson Clocks shown as inactive. NV Power mode indicator visible.
- **GPU**: 14.2% utilization at 153MHz.
- **Disk**: Shows 31.7G used out of 57.0G total storage.
- **Process list**: Bottom section shows running processes including jetson user GUI processes consuming memory.

This screenshot serves as the "before" state in the tutorial, demonstrating the system's limited swap space that motivates the need to increase it for better performance during resource-intensive robotics tasks.
