## Caption
PuTTY security alert dialog warning that the server's SSH host key does not match the previously cached key, prompting the user to accept or reject the new key.

## Description
The image shows a PuTTY Security Alert dialog box on Windows. The dialog displays a warning icon (yellow triangle with exclamation mark) and the heading 'WARNING - POTENTIAL SECURITY BREACH!'. The body text explains that the server's host key does not match the one PuTTY has cached in the registry, meaning either the server administrator changed the host key or the user has connected to a different computer pretending to be the server. It displays the new RSA2 key fingerprint (ssh-rsa 2048 a4:3b:6e:d4:3f:24:7c:2a:55:69:48:67:2d:75:69:12). The dialog offers three buttons at the bottom: '是(Y)' (Yes), '否(N)' (No), and '取消' (Cancel). In the tutorial context of SSH remote login, this dialog appears when reconnecting to a robot or development board whose SSH host key has changed, such as after a system reinstall, and the user is instructed to click Yes to accept the new key and continue connecting.
