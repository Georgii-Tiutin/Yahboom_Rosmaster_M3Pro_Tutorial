## Caption
Screenshot of editing the extlinux.conf boot configuration file on a Jetson device, showing how to change the root filesystem path from eMMC to an external SSD (/dev/sda1).

## Description
The image shows a Linux terminal text editor (likely nano or gedit) open on an Ubuntu desktop, displaying the contents of the extlinux.conf boot configuration file used on NVIDIA Jetson devices. The file contains boot parameters including TIMEOUT, DEFAULT, MENU TITLE for L4T boot options, and a LABEL section with kernel path (LINUX /boot/Image), initrd path (INITRD /boot/initrd), and an APPEND line with boot arguments specifying the root device. A prominent annotation/callout with red/orange text indicates 'Change to /dev/sda1', pointing to the root device parameter in the APPEND line, instructing the user to modify the root filesystem path from the default eMMC partition (/dev/mmcblk0p1) to an external SSD (/dev/sda1). Below the file content, there are numbered instructions about backing up the original kernel and creating a new boot entry. This is part of a tutorial on burning/flashing the system image to boot from an external storage device on the Yahboom ROSMASTER robot's Jetson controller.
