## Caption
VMware dialog prompting the user to connect a detected NVIDIA APX USB device to a virtual machine named Ubuntu18 for system image burning.

## Description
The image shows a VMware USB device connection dialog that appears when an NVIDIA device in APX (recovery) mode is plugged in. The dialog is titled 'New USB device detected' with the subtitle 'Select where you want to connect the NVIDIA APX'. Two radio button options are shown: 'Connect to host' (unselected) and 'Connect to virtual machine' (selected, highlighted with a red rectangle). Below is a 'VM name' dropdown field showing 'Ubuntu18', also highlighted with a red rectangle. The red rectangles indicate the correct selections the user should make: connecting the NVIDIA APX device to the Ubuntu18 virtual machine rather than the host system. This is a step in the system image burning process where the Jetson board in recovery mode must be passed through to the Linux VM for flashing.
