## Description
Screenshot of the SD Card Formatter desktop application on Windows. The window shows:
- Select card dropdown highlighted with a red rectangle, set to 'I:\ - boot'
- Card information section displaying Type: SDHC, Capacity: 29.72 GB, with the SDHC logo
- Formatting options with 'Quick format' selected (radio button), 'Overwrite format' unselected, and 'CHS format size adjustment' unchecked
- Volume label field showing 'boot'
- A 'Format' button at the bottom right highlighted with a red rectangle, indicating the user should click it to proceed
- The red rectangles serve as tutorial annotations guiding the user to select the correct card drive and then click Format
This step is part of the system image burning tutorial, where the SD card must first be formatted before writing the OS image for the robot's controller board.
