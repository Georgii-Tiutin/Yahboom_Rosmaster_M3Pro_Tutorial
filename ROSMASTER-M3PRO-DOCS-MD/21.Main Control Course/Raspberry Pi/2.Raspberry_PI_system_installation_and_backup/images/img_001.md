## Description
Screenshot of the Raspberry Pi Imager application, window title "树莓派镜像烧录器 v1.8.1", with a white header showing the Raspberry Pi logo and text "Raspberry Pi" and a crimson body. Three columns each with a label above a white button: "Raspberry Pi Device" with button "CHOOSE DEVICE"; "请选择需要写入的操作系统" (choose the OS to write) with button "选择操作系统" (Choose OS); and "储存卡" (storage card) with button "选择SD卡" (Choose SD card). At the bottom right is a greyed-out "NEXT" button (disabled until selections are made). This is the first step in flashing the Raspberry Pi system image to an SD card in the installation tutorial.
