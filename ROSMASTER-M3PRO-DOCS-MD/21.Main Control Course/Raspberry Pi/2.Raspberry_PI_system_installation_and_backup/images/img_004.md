## Description
Screenshot of the Raspberry Pi Imager "OS Customization" window (Chinese-localized) with three tabs: GENERAL, SERVICES (active, highlighted in pink), OPTIONS. On the SERVICES tab: a checked checkbox "开启SSH服务" (Enable SSH service); below it two radio buttons: "使用密码登录" (Use password authentication, selected) and "只允许使用公匙登录" (Allow public-key authentication only, unselected). Under that is grayed hint text "设置pi用户的登录密匙:" (Set the authorized_keys for user pi), an empty text field, and a disabled "RUN SSH-KEYGEN" button. At the bottom is a pink "保存" (Save) button. Behind the dialog is the main Raspberry Pi Imager window (title "树莓派镜像...") with a raspberry logo and maroon background. In the tutorial, this step enables SSH with password login before writing the Raspberry Pi system image, then clicking Save.
