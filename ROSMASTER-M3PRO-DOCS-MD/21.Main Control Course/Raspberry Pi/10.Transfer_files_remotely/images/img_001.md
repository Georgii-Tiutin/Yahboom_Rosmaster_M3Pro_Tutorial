## Description
The image shows a WinSCP login/session configuration dialog window (in Chinese). The left panel has a 'New Site' tree node selected. The right panel shows session settings: the file protocol is set to SFTP, the hostname is 192.168.2.93 (highlighted with a red box), port number is 22, the username is 'pi' and the password field is filled with dots (both highlighted with red boxes). At the bottom, the 'Login' button is also highlighted with a red box, indicating the user should click it to connect. This demonstrates how to set up a remote file transfer session to the robot's Raspberry Pi or Jetson board using SFTP via WinSCP.
