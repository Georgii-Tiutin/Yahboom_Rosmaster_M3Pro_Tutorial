## Description
Screenshot of the Raspberry Pi Software Configuration Tool (raspi-config) terminal-based UI, displaying the Localisation Options submenu. The menu lists four options: L1 Locale (Configure language and regional settings, currently highlighted in red), L2 Timezone (Configure time zone), L3 Keyboard (Set keyboard layout to match your keyboard), and L4 WLAN Country (Set legal wireless channels for your country). The interface has the characteristic raspi-config blue-gray background with a bordered dialog box, and navigation buttons <Select> and <Back> at the bottom. This screenshot is used in the tutorial to guide users through configuring regional settings on a Raspberry Pi controller for the ROSMASTER M3 Pro robot platform.
