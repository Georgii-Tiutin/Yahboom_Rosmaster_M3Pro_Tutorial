## Description
This screenshot shows the Raspberry Pi Software Configuration Tool (raspi-config) running in a terminal-based ncurses interface. The screen displays the 'Interface Options' submenu with seven numbered entries:

I1 SSH - Enable/disable remote command line access using SSH
I2 VNC - Enable/disable graphical remote desktop access
I3 SPI - Enable/disable automatic loading of SPI kernel module
I4 I2C - Enable/disable automatic loading of I2C kernel module
I5 Serial Port - Enable/disable shell messages on the serial connection
I6 1-Wire - Enable/disable one-wire interface
I7 Remote GPIO - Enable/disable remote access to GPIO pins

At the bottom are <Select> and <Back> navigation buttons. This is a standard configuration screen used in Raspberry Pi setup tutorials to enable hardware interfaces (such as I2C and SPI) required for communication with the robot's sensors and control board.
