## Description
The image shows an Ubuntu GNOME Settings application open to the Network section. The left sidebar displays various settings categories (Network, Bluetooth, Background, Appearance, etc.). A WiFi connection configuration dialog named 'Yahboom2' is open, showing the IPv4 tab selected. The IPv4 Method is set to 'Automatic (DHCP)' with a 'Manual' option highlighted in red. Below, the Addresses section shows three fields highlighted with red boxes containing IP address (192.168.2.148), Netmask (255.255.255.0), and Gateway (192.168.2.1) values. Additional sections for DNS and Routes are visible below. This screenshot guides users through configuring a static IP address for the robot's WiFi connection to the 'Yahboom2' network, which is essential for reliable network communication with the ROSMASTER M3 Pro robot platform.
