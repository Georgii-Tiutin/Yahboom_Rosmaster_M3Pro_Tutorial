## Caption
Ubuntu Settings showing the Wi-Fi Hotspot configuration dialog with network name and password fields, and the Turn On button highlighted.

## Description
The image shows the Ubuntu GNOME Settings application open to the Network/Wi-Fi section. In the left sidebar, various settings categories are listed (Network, Bluetooth, Background, Appearance, Notifications, Search, Multitasking, Applications, Privacy, Online Accounts, Sharing, Displays, Mouse & Touchpad). The main panel shows Wi-Fi settings with Airplane Mode toggle visible. A modal dialog titled 'Turn On Wi-Fi Hotspot?' is displayed in the center, explaining that Wi-Fi hotspot allows others to share your internet connection. The dialog contains fields for Network Name and Password, with a 'Cancel' button and a 'Turn On' button. The 'Turn On' button is highlighted with a red rectangle to draw attention to it, indicating this is the step the user should click to enable the hotspot. This is part of a network configuration tutorial for the Yahboom ROSMASTER robot platform, showing how to set up a Wi-Fi hotspot on the robot's Ubuntu-based controller.
