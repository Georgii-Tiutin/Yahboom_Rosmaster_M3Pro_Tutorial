## Caption
DiskGenius partition management tool showing the process of writing changes to a USB disk for factory image restoration.

## Description
The image contains two stacked screenshots of DiskGenius v5.6.1.1500 x64, a Windows partition management and data recovery utility. Both screenshots show the same 119.2GB USB disk (Adapter USB, Model jms583) selected in the left panel, with partition details visible in the right panel including volume label, file system, and sector information. The top screenshot shows the disk layout with a single free/unallocated partition spanning the full 119.2GB. The bottom screenshot shows a confirmation dialog box asking 'Are you sure you want to write all changes to disk? The change will take effect immediately.' with Yes and No buttons, where 'Yes' is highlighted. This is part of a tutorial on restoring the factory image system for the Yahboom ROSMASTER robot, demonstrating the disk preparation step using DiskGenius before flashing the system image.
