## Caption
DiskGenius partition management software showing the disk layout of a 119.2GB USB drive (jms583) used for restoring the robot's factory image system.

## Description
Screenshot of DiskGenius V5.6.1.1580 (x64) partition management and data recovery software running on Windows. The left panel shows a disk tree with four drives: HD0 (Seagate 932GB), HD1 (WDC 932GB), HD2 (WDC 466GB), and HD3 (jms583 119GB USB adapter). HD3 is selected, revealing its partition table in GPT format. The main table area displays multiple partitions on the selected disk with columns for partition name, file system type, type, status, capacity, used space, and other attributes. Several partitions are listed including labeled partitions (E:, H:, I:) and others. The bottom section shows detailed information about the selected disk including its capacity (119.2GB/122104MB), cylinder/head/sector geometry, and total sectors (250069680). This screenshot is from a tutorial on restoring the factory image system for the Yahboom ROSMASTER robot, demonstrating how to identify and manage the correct disk/partitions when writing the factory system image.
