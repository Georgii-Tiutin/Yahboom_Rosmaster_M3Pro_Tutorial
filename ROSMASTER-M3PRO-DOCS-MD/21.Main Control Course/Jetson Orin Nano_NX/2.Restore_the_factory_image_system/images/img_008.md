## Caption
DiskGenius partition management tool showing confirmation dialogs for writing changes to disk and formatting a partition on a USB-connected drive.

## Description
The image contains two stacked screenshots of the DiskGenius partition management software (Windows). Both screenshots show the same USB-connected drive (Disk 3, ~119.2GB capacity, USB adapter jms583).

Top screenshot: Shows the DiskGenius main interface with the partition table displayed on the left panel and partition details in the center. A confirmation dialog box is open asking 'Are you sure you want to write all changes to disk? This change will take effect immediately.' with 'Yes' and 'No' buttons, where the 'Yes' button appears highlighted.

Bottom screenshot: Shows a subsequent step where another confirmation dialog appears asking 'Do you want to format the following new partition(s) immediately?' referencing the newly created partition (Unformatted(E:)). The 'Yes' button is again highlighted.

These steps are part of the factory image restoration process for the Yahboom ROSMASTER robot, where the user prepares a USB/eMMC drive by partitioning and formatting it using DiskGenius before flashing the factory system image.
