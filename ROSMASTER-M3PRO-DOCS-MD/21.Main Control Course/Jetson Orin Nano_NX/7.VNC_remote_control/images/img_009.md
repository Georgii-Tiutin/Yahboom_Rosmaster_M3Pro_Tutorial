## Caption
Ubuntu Settings showing the Sharing panel with Remote Login enabled via SSH for remote access to the robot.

## Description
The image shows the Ubuntu GNOME Settings application open to the 'Sharing' section. The left sidebar lists various settings categories (Applications, Privacy, Online Accounts, Sharing, Sound, Displays, Mouse & Touchpad, Keyboard, Printers, Removable Media, Color, Region & Language, Users, Default Applications). The 'Sharing' category is selected and highlighted. In the main content area, the Computer Name is set to 'yahboom'. Below that are options for Remote Desktop, Media Sharing, and Remote Login. The Remote Login option is expanded showing a dialog/popup indicating that when remote login is enabled, remote users can connect using the Secure Shell command 'ssh yahboom-2.local'. The toggle is set to 'On' and shows 'Active' status. There is also a prominent orange 'Remote Login' button visible. This screenshot demonstrates how to enable SSH remote login on the Yahboom robot's Ubuntu system as part of the VNC remote control tutorial setup.
