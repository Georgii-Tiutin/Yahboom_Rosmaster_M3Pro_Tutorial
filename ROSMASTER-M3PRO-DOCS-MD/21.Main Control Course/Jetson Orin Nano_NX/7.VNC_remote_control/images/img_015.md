## Caption
Terminal session on Jetson showing installation of GNOME Shell Extension Manager and verification of GNOME Shell version.

## Description
Screenshot of an Ubuntu desktop on a Jetson device (hostname: jetson@yahboom) accessed via VNC. A terminal window is open showing two commands highlighted with red rectangles: first, 'sudo apt install gnome-shell-extension-manager -y' which installs the GNOME Shell Extension Manager package (already at newest version 0.3.0-0ubuntu2.1), and second, 'gnome-shell --version' which outputs 'GNOME Shell 42.9'. The terminal also displays a list of automatically installed packages no longer required. The desktop has NVIDIA Jetson branding with shortcuts to Jetson Developer Zone, Jetson Support Forums, L4T-README, NVIDIA Jetson Community Pro, Jetson Zoo, and Home visible on the right side. The top bar shows 'MAXN' power mode and the date Dec 26 15:21.
