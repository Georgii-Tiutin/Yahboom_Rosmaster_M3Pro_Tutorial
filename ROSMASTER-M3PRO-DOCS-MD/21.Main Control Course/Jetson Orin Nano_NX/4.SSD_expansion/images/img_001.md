## Caption
Terminal session on a Jetson board running sudo apt update followed by installing the gparted partition editor.

## Description
The image shows an Ubuntu desktop environment on an NVIDIA Jetson board (jetson@yahboom). A terminal window is open displaying two commands: first 'sudo apt update' which refreshes package lists from Ubuntu Ports (jammy) and NVIDIA Jetson repositories (r36.4), and then 'sudo apt install gparted -y' which installs gparted and its dependencies (including related partition tools like kpartx, mtools, reiserfsprogs, udftools, xfsprogs, exfatprogs). The desktop has NVIDIA-branded shortcut icons on the right side for Jetson Support Forums, Terminal, Jetson Zoo, NVIDIA Jetson Community Pro, Jetson Developer Zone, and Home. The taskbar shows the date (1月10 20:38) and system indicators. This step is part of the SSD expansion tutorial, preparing the system by installing gparted to partition and format an SSD drive.
