GParted partition editor showing an SSD disk partition resize operation in progress on Ubuntu.

## Description
The image shows the GParted (GNOME Partition Editor) application running on an Ubuntu desktop. The main window displays the partition layout of a disk (sdb, approximately 38.47 GiB). A dialog box in the center shows 'Applying pending operations' with a progress indicator for shrinking a partition (dev/sdb5) from 257.02 GiB to 12.49 GiB. The partition table lists multiple partitions (sdb1 through sdb6) with columns for Partition, Name, File System, Size, Used, Unused, and Flags. Several partitions are marked with 'msftdata' flags. This screenshot is from a tutorial on backing up the SSD system, demonstrating how to use GParted to resize partitions before creating a system backup image.
