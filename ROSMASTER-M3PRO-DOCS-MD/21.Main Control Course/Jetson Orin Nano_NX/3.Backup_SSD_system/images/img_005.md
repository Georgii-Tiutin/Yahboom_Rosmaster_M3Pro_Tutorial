## Caption
GParted partition editor showing the partition layout of an SSD (/dev/sdb) on an Ubuntu system used for the Yahboom robot.

## Description
The image shows a screenshot of the GParted (GNOME Partition Editor) application running on an Ubuntu desktop. The main window displays the partition table of /dev/sdb, a 238.47 GiB SSD drive. The partition list shows approximately 15 partitions (sdb1 through sdb15) with various labels including 'A_kernel', 'B_kernel', 'A_reserved_on_user', 'B_reserved_on_user', 'recovery', 'recovery_alt', 'esp', 'esp_alt', and 'reserved'. Each partition entry shows its filesystem type (mostly ext4), size, and flags. The partitions correspond to the NVIDIA Jetson system partition scheme, which uses an A/B redundancy layout for kernel and system partitions. A top bar shows the View, Device, Partition, and Help menus. The Ubuntu desktop environment is visible in the background with a terminal window. This screenshot is from the 'Backup SSD system' tutorial, illustrating the SSD partition structure that users need to understand before performing a system backup.
