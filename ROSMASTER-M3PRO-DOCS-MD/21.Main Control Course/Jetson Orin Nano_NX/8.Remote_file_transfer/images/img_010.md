MobaXterm SFTP session configuration dialog for connecting to a Jetson board at IP 192.168.2.199.

## Description
The image shows two stacked screenshots of the MobaXterm terminal application on Windows. The top portion displays the 'Session settings' dialog box open with the SFTP tab selected. The dialog shows Basic SFTP settings with a remote host field populated with an IP address (192.168.2.199), along with options for username and port configuration. Connection protocol tabs are visible at the top including SSH, Telnet, Rsh, Xdmcp, RDP, VNC, FTP, SFTP, File, Shell, Browser, Mosh, AwsS3, and WSL. The bottom portion shows MobaXterm after establishing the connection, with a file browser panel on the left showing the remote directory structure and a password authentication prompt. The left sidebar lists a saved session for 192.168.2.199 (Jetson). A yellow unregistered version banner appears at the bottom. This demonstrates how to set up an SFTP file transfer session from a Windows PC to the robot's Jetson board for remote file management.
