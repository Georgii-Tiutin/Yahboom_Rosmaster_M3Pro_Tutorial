## Description
Screenshot of the jtop system monitoring tool running in a terminal on a Jetson Orin Nano Engineering Reference Developer Kit Super with Jetpack 6.2 (L4T 36.4.3). The top bar shows the device is in MAXN SUPER power mode with overall CPU usage at 16.4% and GPU at 0.0%. Below, six individual CPU core panels (numbered 1–6) are displayed in a 2x3 grid layout. Each panel shows a real-time usage history graph (with time axis spanning roughly 8 seconds) and identifies the processor as ARMv8 Processor rev 1 (v8l) running at a frequency of 1.7 GHz. The graphs show low, fluctuating CPU utilization across all cores. This screenshot is from the CPU monitoring tab of jtop, a popular Jetson system monitoring utility, used in the tutorial to teach users how to monitor hardware resource usage on the NVIDIA Jetson platform.
