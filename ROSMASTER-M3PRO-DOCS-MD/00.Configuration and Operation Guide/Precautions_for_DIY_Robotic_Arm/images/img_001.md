## Description
Photograph of the robotic arm's gripper (claw) viewed from the front, with a servo mounted on top and two linkage arms ending in black rounded fingertip pads, secured with nuts and screws. A red double-headed horizontal arrow spans the gap between the inner sides of the two fingertips. Red text above the arrow reads "物体长度" (Chinese for "object length") and "Object length". The image shows that the object to be grasped must fit within this opening, i.e. the gripper's maximum opening width limits the size of objects it can pick up. Background is a blurry workbench with the arm's lower servo, base, cables and a monitor.
