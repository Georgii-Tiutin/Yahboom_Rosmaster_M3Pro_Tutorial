## Caption
Raspberry Pi terminal showing the exec_m3pro command entering the Docker container, printing MY_DOMAIN_ID: 30 and a root prompt.

## Description
Screenshot of a terminal window titled "root@raspberrypi: ~" (inner title bar: "root@raspberrypi: ~ 80x24"). The terminal shows: "pi@raspberrypi:~ $ exec_m3pro", then "MY_DOMAIN_ID: 30", then the new prompt "root@raspberrypi:~#". This demonstrates that running the command `exec_m3pro` on a Raspberry Pi 5 enters the Docker container for the ROSMASTER M3 Pro. The prompt changes from user pi to root, and the ROS domain ID is reported as 30.
