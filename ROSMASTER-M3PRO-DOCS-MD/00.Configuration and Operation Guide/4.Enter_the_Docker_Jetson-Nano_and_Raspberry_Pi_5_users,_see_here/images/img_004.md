## Description
Screenshot of a terminal window titled "pi@raspberrypi: ~ 80x24" (red title bar). The prompt is "pi@raspberrypi:~ $". The user ran the command `shut_m3pro`. Output: "[+] stop 1/1" and then a line "ter-m3pro Stopping" with a timer "10.5s" at the right. This demonstrates how to stop/shut down the M3 Pro Docker container on a Raspberry Pi using the shut_m3pro command.
