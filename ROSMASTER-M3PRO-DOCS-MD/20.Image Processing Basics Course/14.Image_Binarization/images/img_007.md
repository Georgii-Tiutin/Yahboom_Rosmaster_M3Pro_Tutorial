## Caption
Comparison of OpenCV image thresholding methods applied to a grayscale image, showing BINARY, BINARY_INV, TRUNC, TOZERO, and TOZERO_INV results.

## Description
The image displays a 2x3 grid of six versions of the same still-life photograph (appears to be objects on a table or shelf). The top row shows, from left to right: 'Gray Image' (the original grayscale input), 'BINARY' (pixels above threshold become white, others black), and 'BINARY_INV' (inverse of BINARY, pixels above threshold become black, others white). The bottom row shows: 'TRUNC' (pixels above threshold are truncated to threshold value, others unchanged), 'TOZERO' (pixels below threshold are set to zero, others unchanged), and 'TOZERO_INV' (pixels above threshold are set to zero, others unchanged). Each sub-image is labeled with its corresponding OpenCV thresholding type. This figure illustrates the five basic cv2.threshold() methods in OpenCV, serving as a visual reference for understanding how each thresholding mode transforms pixel intensity values differently.
